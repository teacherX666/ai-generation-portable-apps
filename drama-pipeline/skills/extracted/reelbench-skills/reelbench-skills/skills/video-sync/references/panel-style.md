# 面板设计约定

改样式前先读这份，别凭感觉发挥。

## 三个文件

| 文件 | 管什么 |
| --- | --- |
| `scripts/panel.css` | **面板的布局与长相本身**。改它就能改版式，不用碰别的 |
| `scripts/panel.html` | 骨架 + 渲染逻辑：填数据、算滚动位置、切高亮 |
| `scripts/video-sync.mjs` | 算几何、下发数据、截图、合成。**改版式不用动它**——除非你要让**新的一块也动起来**（那得在 `composeArgs` 里加一层按时间位移的滤镜） |

`panels` 命令会把这三样拼成 `panels/panel.html`（单文件、CSS 内联、数据内嵌）。
**用浏览器打开它就能预览**，地址后面加 `#S07` 换镜头。改完 CSS 重跑 `panels` 就是新版面。

## 两种版式共用一份 HTML

`.landscape` / `.portrait` 挂在**面板元素**上（不是 `body`），要给某一版式单独改样式就用它们起头。
**目前两种版式的网格是同一套**——上下三段：

```
listhead    表头
list        镜头表（滚动区）
strip       进度条
```

**同一套 DOM，两种版式想分就分**——不写第二份模板，也就不会改了一边忘了另一边。
面板横向还是纵向由合成端决定（`vstack` / `hstack`），CSS 不必操心。

## 字号跟着面板尺寸走

导出的是**视频**，不是网页：屏幕上舒服的 13px 在手机上播就是一团糊。
所以 `panel.html` 按面板尺寸算一个根字号：

```
base = clamp(12, min(面板宽/38, 面板高/26), 26)
```

1280×576 的面板 → 22px；972×1080 的竖版面板 → 26px。

**所以 CSS 里一律用 `rem`**，写死 `px` 的只有边框和圆角。加一行 `font-size:14px` 就等于
在小面板上正常、在大面板上小得看不清。

## 两块内容

1. **镜头表**：整张表都渲出来，靠 `transform: translateY()` 滚动——
   当前行钉在列表高度 28% 的位置，前后不够就贴边，**不留空白**。
   表头与行**共用一套列宽**（`8.6rem 7.4rem 1.15fr 1fr`），改列宽必须两处一起改。
   行高由内容决定（描述长了行就高），合成端按量到的每行高度分层画高亮条，
   所以 `.rdesc` / `.rbeat` 可以随便长，**别加 `-webkit-line-clamp`**。
2. **进度条**：一镜一段，宽度 = 时长占比，颜色 = 景别色阶

## 进度条的两个导出态

一镜到底的片子没有切点 → 镜头表的滚动与高亮都无从谈起，**唯一会动的就是进度条**。
它靠两张图配合：底板整条「已播」（`#static` 模式 → `.strip-lit`）、
遮罩整条「未播」（`#strip-dim` 模式 → `.strip-dim`），合成时遮罩从右往左滑，
左边露出来的长度就是已播比例。

**所以改进度条的样式要改三处**：`.seg` 本身、`.panel.strip-lit .seg`、`.panel.strip-dim .seg`。
后两个必须把 `.seg` / `.seg.on` / `.seg.done` 三种都写全——导出时进度条要**整条同态**，
留一个「当前段」的斑，进度条就会有一截永远亮着。

`.panel.strip-dim .rows{visibility:hidden}` 是有意的：遮罩只用得到进度条那一行，
镜头表不用渲（`visibility` 而非 `display`，布局保住，进度条位置不动）。

## 配色

深底（`#12160f`）+ 嫩绿高亮（`#dceba7`）。深底是为了贴在画面旁边不抢戏——
浅色面板在暗调片子旁边会像个灯箱。

景别色阶（`--color` 由数据下发，与 `video-shots` 报告同一套）：越近的景别越深。

## 别做的事

- **别在 CSS 里加动画**。面板是**截图**出来的（四张静态图），`transition` / `animation`
  只会被截到某个中间状态。要让东西动，一律做成「静态图 + ffmpeg 按时间位移」——
  滚动、高亮、进度条推进、播放头全是这么来的。
  `.panel.live .rows{transition:…}` 只服务于浏览器预览，导出走 `.panel.tall/.static` 分支把它关掉
- **别用外链资源**（网络字体、CDN 图标）。截图是离线跑的，加载不到就是空白
- **别让内容溢出**。`body` 的宽高被脚本钉死成面板尺寸，溢出的部分直接被截掉。
  长内容靠 `overflow-wrap:break-word` 换行、**把行撑高**（合成端按量到的行高分层的），
  **不要用 `-webkit-line-clamp` 截断**——截断等于把这一镜的信息扔掉，也别指望滚动条
- **别把关键信息放最下面**。镜头表底部有一层渐隐遮罩（提示还有更多），压在上面会看不清
