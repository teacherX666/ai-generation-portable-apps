## 案例 C-20260926-00 · 方法论验证（龙形火焰流体冲击城墙）

| 项 | 内容 |
|---|---|
| 输入类型 | L1 创意（教程原始案例复刻） |
| 用途 | **渠道与脚本端到端验证** + 方法论基准图 |
| 槽位 | B8 龙形流体 · C1 火星粒子 + C2 黑烟粒子 · D? 高空向下冲击 · E2 城墙 · F1+F3 碎砖崩裂 + 不规则形状 · G1 写实电影级 + 体积光 · H1 单人（无人物） |
| 模型 | Seedance 2.0 素材（8s / 16:9） |
| 出图渠道 | 贞贞 ai 工坊 · `zhenzhen-image-g-v2.5-lowprice` · `size=16:9` · `resolution=1k`（¥0.0446 实测） |

**实际使用的提示词：**
```
电影级仰拍冲击镜头，巨型龙形火焰流体自百米高空向下冲击，撞击中心为古城墙，
迸溅红色火星粒子与黑烟粒子，城墙大面积碎砖崩裂扬尘，碎块形状不规则，
写实渲染，体积光，主体清晰可读，粒子不遮挡主体
```

**结果**：✅ 一次成功。流体主体明确（龙形火焰流体而非实体龙）、高度视角明写（百米高空 + 仰拍）、撞击位置明确（古城墙）、双粒子迸溅、碎砖不规则崩裂、体积光到位。

**本次发现（已回写进 references）：**
1. **出图提示词必须带负向**：本条没写「无文字无水印」→ 画面里冒出了城门匾额文字（可读汉字）。**出图提示词一律加「无文字无水印」。**（已在 `image-prompts.md` §五 记为必做项）
2. **`resolution=1k` 实测成本 ¥0.044624**，与文档口径（4.46 单位 = ¥0.0446）完全一致。
3. **状态枚举实测为 `QUEUED` / `IN_PROGRESS` / `SUCCESS`**（大写），脚本按「非终态即继续轮询」处理，兼容 `FAILED`/`FAILURE` 两种终态写法。
4. **单张实测耗时约 40s**（8 次轮询 × 5s），落在文档给的 43s~253s 区间内。

## 案例 C-20260926-01 · 一男一女 · 红龙 × 白虎 · 法术对轰

| 项 | 内容 |
|---|---|
| 输入类型 | L1 创意：「3d国风动漫，一男一女打斗，技能特效，一个红色的龙，一个白色的虎」 |
| 槽位 | B8 龙形流体（赤红火焰）+ 虎形流体（银白流光）· C1 火星粒子 + C4 银白能量光点 · **D7 双锚点**（男掌心结印 / 女双掌合十）· **E6 法术对轰** · F1+F3+F6 碎块崩裂 + 不规则形状 + 地面龟裂 · G2 国漫 CG + 冷暖对撞 · H2 双人对打（对角构图 / 相距百米） |
| 时长 / 画幅 | 10s / 16:9（另出 2.0 版 8s） |
| 输出 | 方案一 Seedance 2.0 11 字段版 · 方案二 Seedance 2.5 时间戳版（纯文字模式，未生图） |
| 用户反馈 | 待回填 |
| 可复用模式 | ①**双人对轰的冷暖对冲**：一方火焰流体（热/涌）+ 一方灵光流体（冷/锐），色温差是最直观的视觉记忆点；②**双锚点写法**：两个锚点分别锁定两人，撞击点落在两人中线上——这样两股流体才会"撞"而不是各打各的；③**同题材双版本交付**：2.0 版按教程标准参数（8s），2.5 版多给 2 秒补「蓄能」与「余波」各一拍 |

**本次沉淀的规则**：同题材出多版本时，**只改模型/时长/格式，不重写设计**——设计层（锚点/撞击/反馈）是共享的，这样用户对比的是模型差异，不是设计差异。
