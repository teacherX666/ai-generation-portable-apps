## 第 01 · 主控台（原 SKILL.md） 部分

# 打斗特效提示词生成器 · 流体 × 粒子 × 锚点法 V1.0

> **一句话定位**：用户给一段创意/剧本/主角图 → 你出一张**选择卡**让他一次选完 → 你输出**可直接复制**的打斗特效视频提示词（缺图可自动生成）。
>
> **与同类 skill 的分工**（避免重复劳动，别越界）：
> - `fight-prompt-master` / `seedance-2.5-fight-prompter` 管**动作编排**（谁打谁、招式链、因果交锋、强度档位）。
> - `h3-jackie-chan-fight-director` 管**H3 一打多的调度**。
> - **本 skill 只管「技能特效本身」的物理逻辑**：流体怎么成形、粒子在哪迸溅、技能从哪个锚点冒出来、撞在什么上、反馈成什么样。**换装成"铁匠铺打铁"就贴到 `fight-prompt-master`。**
> - 两者可叠加使用：先由本 skill 定特效，再把特效段落交给动作 skill 嵌进完整编排。

## 一、两条核心方法论（背下来，这是全部底层逻辑）

### 1. 流体做主体，粒子做反馈

| | **流体 Fluid** | **粒子 Particle** |
|---|---|---|
| 本质 | **连续的形态** | 离散的、可崩解的碎片/颗粒 |
| 典型形态 | 能量洪流、能量屏障、光丝、剑气刀气、火焰流体 | 固体碎片、气态烟雾、光点能量 |
| 画面表现 | 连贯、可塑性、动态流动感 | 碎石崩裂、烟尘扩散、光点迸溅 |
| 分工 | **做主体**（大招本体、拖尾主体） | **做反馈**（撞击崩裂、氛围点缀） |

**三条实测结论：**
1. **主体必须带材质词**：写「巨型火龙」→ 模型给**实体火龙**；写「巨型龙形**火焰流体**」→ 才是想要的流体大招。**这一步写错，整条提示词报废。**
2. **拖尾优先用流体**：同场景对比，粒子拖尾和流体拖尾观感差异明显，流体更顺。
3. **想提质感**：流体做主体 + 粒子做点缀（例：「火焰流体」为主体，周围「火焰粒子」点缀）。

### 2. 锚点 + 撞击位置 + 物理反馈（最小三要素）

```
锚点（技能从哪出来） + 撞击位置（打在哪） + 物理反馈（打完变成什么样）
```

- **锚点**：掌心 / 刀剑武器 / 双掌合十 / 地面涌出 / 身后浮现。它**优先级最高**——不写锚点，技能会从人物手里或其他地方**乱冒出来**，稳定性骤降。
- **撞击位置**极灵活：地面 / 城墙 / 树林 / **敌方身体部位** / **敌方护盾** / **敌方技能（法术对轰）** / 兽群。它让"两个人的打斗"产生**连接**。
- **物理反馈最容易忘，但决定打击感**：不写反馈 = 没有打击感。补法：坍塌 + 飞射 + **不规则形状**（规则形状显假）。

**要分清两种"打"：**

| 类型 | 例子 | 反馈写法 |
|---|---|---|
| **撞击位置** | 龙形流体砸向地面/城墙 | 撞击中心 + 碎石/碎砖崩裂（粒子） |
| **接触位置** | 毒雾笼罩古城废墟（覆盖，不是砸） | 接触面出现**被腐蚀脱落**效果 |

### 3. 六要素结构公式（写完整条提示词的骨架）

```
镜头机位 + 流体 + 粒子 + 光效 + 撞击/接触位置 + 物理反馈
```

- **必写**：流体、粒子（缺一个就没有特效）
- **建议写**：撞击/接触位置、物理反馈（决定准确度和打击感）
- **可加**：光效（写好流体+粒子+环境氛围词，色彩效果其实已自动出来）
- **可不写但必须懂**：镜头机位——不写模型也会给合理景别，但**要精确控制就得自己写**

### 4. 通用动作四件套（强推固定搭配）

```
压缩 → 蓄能 → 膨胀 → 吞吐
```

写火焰流体、写强光提质感，通用性极强。**变身/大招类的动作节奏就靠这四个词。**

## 二、第一步永远是出「选择卡」（菜单式，不做开放式追问）

**铁律：**
- 用户**已经明确的**项 → 在卡里标 ✅ 并附他的原话，**不再重复问**。
- 用户**没明确的**项 → 在卡里给出**选项 + ★推荐默认**，让他回编号。
- **禁止**问「你想要什么样的特效？」「你的主角长什么样？」这类开放式问题。**永远给选项。**
- 用户说「按推荐 / 你定 / 随便」→ 直接采用所有 ★ 项，**不再追问第二次**，立刻开工。

**回复方式写清楚**：只回编号，例 `B2 C1+C3 D1 E2 F1+F3`；整组跳过就说「按推荐」。

## 三、工作流（7 步）

```
①判断已知信息 → ②出选择卡 → ③收卡（图片分支） → ④定特效设计表
→ ⑤写提示词（按所选模型封装）→ ⑥自检 → ⑦交付 + 归档
```

1. **判断已知信息**：用户给了什么？创意/剧本/小说/分镜属于哪一级（见 §六 输入分级）？已明确了哪些卡项？
2. **出选择卡**：已明确项标 ✅，其余给选项 + ★推荐。
3. **收卡 → 图片分支**（见 §五）：需要图且用户没图 → 用贞贞工坊生成；用户有图 → 直接进下一步。
4. **定特效设计表**（内部完成，不输出给用户）：
   - 锚点位置 + 技能形态（流体）
   - 撞击/接触位置 + 粒子种类
   - 物理反馈（3-5 项，含"不规则形状"）
   - 动作节奏：压缩→蓄能→膨胀→吞吐
   - 单人可不写景别；**双人/多人必写景别 + 构图 + 距离**
5. **写提示词**：按 §四 的模型格式封装。
6. **自检**：过 §八 清单，**发现问题先改再交付**。
7. **交付 + 归档**：附一句设计说明 + 诊断要点；案例写入 `case-library.md`。

## 四、输出格式规范

### 4.1 三种模型的核心差异（选哪个用哪个）

| | Seedance 2.0 | Seedance 2.5 | MiniMax H3 |
|---|---|---|---|
| 时长 | 8-15s | 4-30s（超长 30-180s） | 10-20s |
| 时间控制 | 连续整秒粗时间段 | **时间戳钉死每一拍** | `[Shot N] At MM:SS.mmm` |
| 语言 | 中文 | 中文 | **英文** |
| 结构 | **11 字段** | **三段式 + 时间戳** | **六段式** |

**详细模板与字段硬规则见 `references/engine-formats.md`。写之前必须读对应的那一节。**

### 4.2 交付形态（每个方案统一）

```
## 方案〔N〕｜〔流体主体〕×〔撞击位置〕·〔一句话看点〕
说明：〔模型〕·〔时长〕·〔画幅〕·〔素材状态〕
自检：✅ 通过（修正：〔本次改了什么，无则写"无"〕）
〔一句设计说明：锚点在哪、撞击在哪、反馈成什么样〕

```text
〔可直接复制的完整视频提示词〕
```
```

**提示词本身必须是「可直接复制粘贴」的一整块**，不带任何解释性文字、不带 markdown 语法、不带「以下为提示词」之类的话。

### 4.3 特效段落写作规范（本 skill 的核心产出）

不管哪个模型，**特效部分必须写满这 5 句**：

| # | 必写句 | 反例（禁） | 正例 |
|---|---|---|---|
| 1 | **主体形态** | 「巨型火龙」 | 「巨型龙形**火焰流体**」 |
| 2 | **锚点位置** | 「释放技能」 | 「自**掌中心**凝出雷球」「技能自**身后**浮现」 |
| 3 | **撞击/接触位置** | 「打出去」 | 「撞击中心为**城墙**」 |
| 4 | **粒子迸溅** | 「很炫酷」 | 「迸溅**红色火星粒子**与**黑烟粒子**」 |
| 5 | **物理反馈** | 「被击飞」 | 「城墙**大面积碎砖崩裂扬尘**，**形状不规则**」 |

**另有两条距离参数必须明写**（踩过的坑）：**高度/方位要写**——「悬于**百米高空画面左上方**」+「**仰视视角**」，不写就翻车（技能位置太低）。

### 4.4 字数与篇幅

- 单条提示词 300-800 字（特效为主时 300-500 字足够）
- 不堆形容词。**每个强度词都要能落到具体载体 + 接触点物理现象 + 环境后果**

## 五、图片资产分支（缺图时）

### 5.1 三条路，让用户挑（写在卡里，别问）

| 路 | 做法 | 适用 |
|---|---|---|
| **1. 用户上传** | 直接用 `@图片1` | 已有立绘/参考图 |
| **2. 贞贞工坊自动生成** | 跑 `scripts/gen_image.py` | 没图、要快、要统一 |
| **3. 纯文字不用图** | 特效类**纯文本就能出效果**，不上传任何资产 | 只要特效/巨兽形态 |

> 教程实测：**纯文本就能达到演示效果**，不必一开始就上传参考图。要统一形象（固定的龙 / 加人物）再用参考内容。

### 5.2 用贞贞工坊生成（默认走这条）

**渠道口径（铁律，不许换通道）：**
- 端点：`POST https://api.seedance.nz/v1/image/generations`（**路径是单数 `image`**，写复数 404）
- 默认模型：`zhenzhen-image-g-v2.5-lowprice`（带 `size` + `resolution` 两个顶层入参）
- 档位：**测试 1k（¥0.0446）· 默认 2k（¥0.105）· 正式大场景 4k（¥0.1575）**
- 凭证：四级自动读取（`--api-key` > 环境变量 > 项目 `.env` > `~/.workbuddy/credentials/mv-auto-pipeline/keys.env`）——**永远不问用户要 key**

**调用命令（自己拼，别让用户跑）：**

```bash
# PY = 你的 Python 解释器路径（自行替换；用 WorkBuddy 托管版本的形如
#      <runtime>/binaries/python/envs/default/Scripts/python.exe）
PY="<python 解释器路径>"
env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY "$PY" \
  ~/.workbuddy/skills/fight-fx-anchor-prompter/scripts/gen_image.py \
  --prompt-file char.txt --output ./fx_assets/char.png --size 3:4 --resolution 2k
```

- 主角图 `--size 3:4`（半身正面纯白底）· 场景图 `--size 16:9` · 道具 `--size 1:1`
- 批量：`--batch assets.json --output-dir ./fx_assets`（支持断点续跑）
- 出图提示词模板见 `references/image-prompts.md`（含**四视图转身参考**写法——人物与背景割裂、质感不行，往往是缺三视图）

**排障（都踩过）：**
- **HTTP 403 先挖 body**：`insufficient_user_quota` = **额度不足** → 告诉用户充值，**不许换通道**。
- 一批图前面成功、后面全 403 → 额度见底，不是限流。
- 连接重置 10054 / `EOF in violation` / Cloudflare 1010 → **先怀疑代理**，命令前加 `env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY`。
- 单张耗时 43s~253s 波动大，轮询给足（脚本已内置 5s × 90）。

**生成后必须用 `present_files` 把图给用户看**，再继续写提示词。

### 5.3 参考图怎么进提示词

- Seedance：`@图片1` = 主角、`@图片2` = 对手、`@图片3` = 场景
- H3：`<Subject 1> whose appearance comes from <Picture 1>`（**不给图片单独开一行**）
- **最小资产只要人物主视图**；要质感再补场景图 + 三视图

## 六、输入分级（怎么处理用户给的文字）

| 级别 | 输入 | 处理策略 |
|---|---|---|
| **L1 创意** | 一句话 | 补全题材/场景/角色/2-3 个特效节点 |
| **L2 剧本** | 有角色+对抗 | 直接生成，补外观锚点、武器、场景、特效链、结尾 |
| **L3 小说** | 长叙事中的打斗段 | **抽骨架**（胜负与转折）→ **去修辞**（删"气势如虹/天地变色"等不可拍内容）→ **建奇观**（选 2-3 个最具视觉冲击的画面做节点）。**不逐句翻译** |
| **L4 锁定分镜** | 带时间轴/动作链 | 剧情结果、顺序、视觉锚点、出口为**硬约束**，只补衔接和物理反馈 |

> **原作用户文字绝不删改**：台词、动作结果、角色名一律保留原样。

## 七、失败诊断（单变量排错）

用户拿翻车结果回来 → **每轮只改一类变量**，改完复测再定下一步。

| 症状 | 真因 | 修法 |
|---|---|---|
| 技能位置太低/贴地 | 没写高度与视角 | 补「悬于**百米高空画面左上方**」+「**仰视视角**」 |
| 出来的是实体（火龙/龙）而非流体 | 主体没带材质词 | 「巨型火龙」→「巨型龙形**火焰流体**」 |
| 技能从人物身前乱冒 | 锚点没写或位置写错 | 明确「锚点锁定**掌心**」「自**身后**浮现」 |
| 没有打击感 | 缺物理反馈 | 补「坍塌 + 碎石飞射 + **不规则形状**」 |
| 特效很假/像贴图 | 缺光效与环境氛围词 | 补体积光 / 环境漫射 / 自发光（可加英文 `volumetric fog`） |
| 双人镜头"低智"、两人没距离感 | 没写景别构图 | 补「两人位于画面两端相距百米」+「对角构图：一人在左下地面，一人在右上角」 |
| 人物与背景割裂、细节差 | 缺三视图 | 补四视图转身参考图 |
| 蓄力幅度不够 | 动作没写起手 | 补「抬手再向前伸出」 |
| 语病导致的偏差 | 用词不当 | 「不规则雷球」→「**不规则的形状**」 |
| 偶发异常（模型抽风） | **不是提示词问题** | **直接再生成一遍**，别改提示词 |

> **判据：失败是提示词问题，不是模型问题**——先查这 10 条，再考虑重生成。

## 零、一句话核心

> **AI 打斗特效的提示词，核心只有两个词：流体 和 粒子。**
> 主体用**流体**做连续形态，冲击/崩裂处用**粒子**做物理反馈——这就是这类视频的全部底层逻辑。

以及第二期补上的第三个核心概念：**锚点**——让技能与人物、环境**发生关系**。

---

## 一、流体 vs 粒子

| 维度 | 流体（Fluid） | 粒子（Particle） |
|---|---|---|
| 本质 | **连续的形态** | 离散的、可崩解的碎片/颗粒 |
| 典型形态 | 能量洪流、能量屏障、光丝、剑气刀气 | 固体碎片、气态烟雾、光点能量 |
| 画面表现 | 连贯、可塑性、动态流动感 | 碎石崩裂、烟尘扩散、光点迸溅 |
| 分工 | **做主体**（大招本体、拖尾主体） | **做反馈**（撞击崩裂、氛围点缀） |
| 使用频率 | 拖尾/大招场景更常用 | 提质感时作为补充 |

**UP 主实测经验：**
- 人物奔跑拖尾对比：左侧人物用**银白粒子**、右侧人物用**流体**——两者观感差异明显，**拖尾优先用流体**。
- 想提升质感：**流体做主体 + 粒子做点缀**。例：「火焰流体」为主体，周围「火焰粒子」做点缀。
- 开场那条龙的视频：**龙形主体 = 流体，冲击点位崩裂 = 各种粒子**。一句话概括核心。

---

## 二、提示词结构公式（六要素）

UP 主手写板书：

```
镜头机位 + 流体 + 粒子 + 光效 + 撞击/接触位置 + 物理反馈
```

| 要素 | 说明 | 是否必写 |
|---|---|---|
| 镜头机位 | 景别 + 机位角度 + 运镜 | 可不写（Seedance 会自行安排合理景别），但**必须学习**，是提升画面控制力的关键 |
| 流体 | 主体形态：能量洪流/屏障、光丝、剑气刀气、火焰流体 | ✅ 核心 |
| 粒子 | 固体碎片、气态烟雾、光点能量 | ✅ 核心 |
| 光效 | 体积光、环境氛围词（AI 生成下色彩效果基本自动出来） | 可加，进阶 |
| 撞击/接触位置 | 撞击中心是什么（地面/城墙），或毒雾等「接触面」 | 建议写，提高准确度 |
| 物理反馈 | 撞击后物体发生什么变化（碎石/碎砖崩裂、腐蚀脱落） | 建议写 |

## 三、锚点（Anchor）——技能与人物发生关系的关键

### 3.1 为什么需要锚点

目标效果：人物释放光剑 → 光剑**撞击树林区域** → 产生烟尘、光点粒子。

这类特效不是凭空放的，**流体碰到撞击位置才会迸溅为各种粒子**。想让"释放的技能"与人物、环境产生关联，就需要一个东西——**特效锚点**。

### 3.2 定义

UP 主把"释放位置"改称为 **特效锚点**——它更精确，也更有"锚定"的含义。

**锚点可以出现在任何位置：**

| 锚点位置 | 说明 |
|---|---|
| 掌中心、掌心 | 最常见的手持释放 |
| 刀剑 | 武器释放 |
| 非手部（地面涌出、从别处过来） | "灵体虚影"、此前的"法天象地"都是这种做法 |

> **为什么叫"锚点"不叫"释放位置"**：锚点的**优先级是高的**——它能避免技能从人物手中或其他地方**乱冒出来**，**大幅提高生成稳定性**。

### 3.3 最小三要素

```
锚点 + 撞击位置 + 物理反馈
```

只要这三个要素确定好，哪怕只发给 AI 一句最简单的描述，AI 也能给出很不错的结果。

**撞击位置（接触位）非常灵活，可以写：**
- 地面 / 城墙
- 兽群
- 敌方某个身体部位
- 撞击在**敌方的技能**上
- 撞击在**护盾**上

## 五、实战案例 B：单人·掌心雷球（锚点法）

### 最小可执行提示词（按视频讲解重构）

```
场景：雨夜，镜头低角度仰拍（效果很不错）
特效锚点：锁定掌心
动作：闪电汇聚成雷球，将雷球释放
撞击：撞击位置迸溅各种粒子、黑暗与光点粒子
电弧：在雷球周围闪烁游走

```

把人物的**主视图图片 @ 进来**，只添加主视图、不写场景图也能生成。

### 必补的「物理反馈」（最容易被忘）

> 撞击的物理反馈太弱了，就没有打击感。因为我没写物理反馈，应该加上墙面的坍塌。

补法：**墙面的坍塌 + 碎石的飞射，并且改成不规则的形状**（规则形状会显假）。

### 出错了怎么调

| 问题 | 调法 |
|---|---|
| 模型生成偶发异常 | 提示词没问题，直接**再生成一遍** |
| 人物开头景别太远 | 写"视觉主导"更稳定；明确景别如"人物中近景" |
| "不规则雷球"语病 | 改成"**不规则的形状**" |
| 流体从人物身前冒出（应在身后） | 属于生成问题，再生成一遍即可 |

## 六、光效：让 AI 帮你生成

在 AI 生成方向，光效比传统制作简单很多：**写好流体和粒子 + 基本的环境氛围词，色彩效果就已经出来了**。想进一步写光效，可以直接问 AI。

### 操作方式

给 AI 的提问示例：**「我想要一个阴冷毒雾山谷绿色感，用什么光效？」**

AI 返回的结构化光效清单（OCR 复原）：

```
阴冷毒雾 · 幽暗绿色光效组合（适配 AI 图 / AI 视频，国漫 CG 风格）

核心基调：低亮度、暗部主导，绿光不作为主照明，而是环境漫射 + 毒雾自发光

一、核心光效清单（直接复制可用）
主环境光
1. 毒雾体积光
   - 亮度低，不照亮物体亮面，只浸润空气
   - 关键词：volumetric fog, poison mist ambient glow, dim sick green diffuse glow
2. 荧绿次表面微光
   - 物体边缘、岩石、雾气颗粒有薄薄的荧绿轮廓光
   - 不是描边，是毒雾侵染出来的微弱冷光，亮度低，只在阴影区域显现
补光 / 氛围光 …
```

### 实际写入视频提示词

```
我想要一个仰拍的冲击镜头，毒雾以暗黑幽绿为主体，笼罩古城废墟
```

- 用**体积雾 + 环境漫射**（原词可能有出入）。
- 可用英文关键词直接补强：`volumetric fog` / `poison mist ambient glow` / `dim sick green diffuse glow`。

### 撞击位置 vs 接触位置

| 类型 | 例子 | 反馈写法 |
|---|---|---|
| **撞击位置** | 龙形流体砸向地面 / 城墙 | 撞击中心 + 碎石/碎砖崩裂（粒子） |
| **接触位置** | 毒雾笼罩古城废墟（不是砸下去，是覆盖接触） | 接触面出现**被腐蚀脱落**的效果 |

> 写提示词时要分清「冲击撞击」还是「覆盖接触」，两者的物理反馈完全不同。

## 七、双人打斗与固定搭配

**通用动作四件套（强推固定搭配）：**

> **压缩 → 蓄能 → 膨胀 → 吞吐**

这组词通用性极强——写火焰流体可以这么写，写强光（提升质感的好写法，让光影有质感）也可以这么写。

### 构图与景别（防止"低智镜头"）

| 场景 | 建议 |
|---|---|
| **单人** | 可以不写景别和人物主导权重，生成还算稳定 |
| **双人** | **必写**景别和构图，否则不约束时一个场景会直接冒出两个人、且没有距离感，镜头看起来很"低智" |

**景别写法参考：**
- **中近景**：画面内容为人物腰部以上
- **远景**：两人位于画面两端，距离上百米
- **对角构图**：一个人物在左下地面，另一个在右上角

> 练习建议：UP 主前面用单人演示是为了讲得简单，**实际练习建议都加上双人并写明景别**。

## 九、撞击位置进阶用法

| 撞击对象 | 效果示例 |
|---|---|
| 护盾（气盾） | 护盾破碎、被吞没 |
| 接触位=毒/黑雾 | 碰到敌人使其昏迷，或石化 |

> 纯光效类的（毒物、龙形流体、灰光、体积光、体积雾等技能）可以和 AI 多对话，让它帮你细化。

## 十、用 AI 对话复刻提示词（三步法）

| 步骤 | 做法 |
|---|---|
| **① 给结构** | 把「镜头机位 + 流体 + 粒子 + 光效 + 撞击/接触位置 + 物理反馈」这个结构发给 AI，告诉它你要相关的提示词 |
| **② 给样例** | 效果不好时，把上面的 3 条提示词一起发过去，让 AI**参考这些提示词进行复刻** |
| **③ 对话微调** | 哪点不满意就针对性说，例如「撞击做得不够好」→ 让它改；**风格（卡通等）、镜头机位、撞击/接触位置、主体**都可以用对话改 |

### 让 AI 帮你写提示词的正确姿势（第二期补充）

1. 先把**最小可执行**的要素（锚点 / 撞击 / 物理反馈）确定好；
2. 把上面的结构发给 AI，再把你的提示词发过去，让 AI 了解你要的效果；
3. 有错的地方，让 AI 总结原因，**自己也要多写多练**。

> ⚠️ UP 主提醒：**直接让 AI 帮你写提示词，效果并不好。** 结构和最初那几条提示词是他手写 + 试错总结出来的，这套方法帮大家省的是时间和抽卡成本。
> 判据：**你有一个精确的目标，AI 给出的结果才会非常不错。**

## 十一、UP 主反复强调的 5 个要点

1. **流体和粒子是这类视频的全部核心**，先手写一遍才能真正理解提示词。
2. **纯文本就能生成**，不必一开始就上传参考图；要统一形象（龙/人物）再用参考内容。
3. **时长 8 秒**即可，Seedance 2.0 模型能力很强，不写镜头也会给合理景别，但**镜头机位一定要学**——它是提高画面控制力的重要部分。
4. **失败是提示词问题，不是模型问题**：V2 那次模型理解得很合理，是自己没写清「流体」。
5. AI 打斗特效目前机会很大：**很多漫剧的打斗水平都不高**，吃透这套方法找相关工作不难。

### ⚠️ 撞击 vs 接触（必分清）

| 类型 | 例子 | 反馈逻辑 |
|---|---|---|
| **撞击位置** | 龙形流体砸向地面/城墙 | 撞击中心 + 碎石/碎砖崩裂（粒子） |
| **接触位置** | 毒雾笼罩古城废墟（覆盖） | 接触面**被腐蚀脱落** |

> 写提示词时先问自己：**这是"打下去"还是"盖上去"？**两者的物理反馈完全不同。

## 通用动作节奏四件套

```
压缩 → 蓄能 → 膨胀 → 吞吐
```

- 火焰流体：火焰向内压缩 → 蓄能发光 → 骤然膨胀 → 向前吞吐成洪流
- 强光提质感：光体压缩成核 → 蓄能变色 → 膨胀炸开 → 吞吐成冲击波

> 这组词**通用性极强**，写流体、写强光都能套。

## 一、即梦 Seedance 2.0（11 字段格式）

适用：I1。时长 8-15s（**教程演示用 8s**，16:9，720P）。

### 字段（名字与顺序固定）

```
【整体风格】"整体风格:"开头；调性词×3 + 特效通过具体物理现象呈现 + 排除跨题材污染词；主体清晰可读优先于特效
【角色卡】- @图片1作为[主角]: 外观锚点+武器/能力+动作倾向
          文生模式（无角色图）必须写全5-8项锚点：性别年龄段/脸型发型发色/体型/服装逐件/配色/武器/能量颜色形态
【场景设定】地点+光线+空间结构+4-6个可被动作影响的环境元素（城墙/树林/石柱/废墟）
【画面坐标】开场主体位置+威胁进入方向+纵深/退路
【起幅】开场画面+第一威胁（技能起手/锚点显现）
【过程】4-6个节点，每节点：动作→对手反应→环境反馈→镜头反馈→衔接
【结尾】终段动作+结果爆发+空间位置；不写慢收势/能量渐熄/定格摆姿态
【特效细节】★本 skill 主战场：
    锚点锁定位置 → 流体主体形态 → 撞击/接触位置
    → 迸溅粒子（A与B） → 物理反馈（坍塌/飞散/不规则形状）
    能量只沿武器/碰撞点/攻击轨迹，粒子不遮主体
【音效】10-14个，逗号分隔，只取本题材声音（含技能音：凝结/轰鸣/爆裂/电弧）
【禁止项】文字/UI/水印/Logo/角标/可读文字
【强制声明】无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;

## 三、MiniMax H3（英文六段式）

适用：I3。时长 10-20s。**输出必须全英文。**

### 六段（顺序固定）

```
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

### 特效相关的写法要点

**subject_definitions**：给可复用可见内容定义 `<Subject N>`（人物/环境/道具/风格）。
图片只用来定义形象时，写在 `<Subject N>` 定义里——"whose appearance comes from `<Picture N>`"，**不给图片单独开一行**。

**summary**：以方括号任务类型前缀开头，如 `[reference generation]`。

**detailed_description**：先写风格句（E），再 `[Shot 1]`（不带时间戳），然后 `[Shot N] At MM:SS.mmm, ...`。
**风格句模板**：
```
The target video uses a [STYLE] set in [ENVIRONMENT], with [LIGHTING] and [MOOD].
```

**特效写入 detailed_description 的英文模板**：
```text
[Shot 1] The [flu id subject] condenses at her [palm / blade tip], compressing into a
glowing core, then surges forward as a continuous torrent. The camera [pushes in / tracks].
[Shot 2] At 00:04.000, the torrent slams into the [city wall / ground / enemy shield].
Sparks and black smoke particles burst outward from the contact point; the [wall] collapses
into irregular shattered bricks and billowing dust. Energy erupts only from the impact point,
never floating free. [Shot 3] At 00:08.000, ...
```

**关键风控（H3 特有两坑）：**
1. **能量只从接触点爆发**，不能是自由漂浮的光束或常驻光环。能量是**命中的结果**，不是命中的替代品。
2. 写实街战模式下**完全没有能量**——冲击纯粹物理（灰尘、碎屑、闷哼）。

**overall_soundscape**：氛围 + 物理声（凝结嗡鸣、流体轰鸣、撞击轰响、碎砖落地）。
**non_diegetic_music**：观众侧配乐（无则写 `N/A`）。

### 可选：调性兜底块（六段之外，单独附）
H3 容易漂（比如武侠片渲染出西式铠甲、或僵住成静态对峙）时，在六段提示词**之后**附一段中文约束（**不属于提示词正文**）：
```
1. 严禁出现西式铠甲骑士造型，必须为[角色正确调性]。
2. 严禁原地互殴，每秒必须有空间位移（突进/腾跃/翻转/滑行/坠落/交错）。
3. 严禁动作停顿或对峙空镜，技能命中与碰撞必须立刻给出沉重受力反馈。
```

## 六、排障速查

| 症状 | 真因 | 修法 |
|---|---|---|
| HTTP 403 | **先挖 body**：`insufficient_user_quota` = 额度不足 | 告诉用户充值，**不许换通道** |
| 一批图前成功后全 403 | 额度见底 | 同上 |
| 连接重置 10054 / `EOF in violation` / 1010 | **代理**拦截 | 命令前加 `env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY` |

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
贞贞 ai 工坊 · 生图脚本（自包含 · 纯标准库）

用途：为打斗特效提示词生成主角图（半身正面 / 四视图）与场景图。

★ 渠道铁律（不可绕过）
  **生图只走「贞贞 ai 工坊」** → POST {BASE}/v1/image/generations（路径是**单数** `image`）
  · 默认模型 `zhenzhen-image-g-v2.5-lowprice`（带 `size` + `resolution` 两个**顶层**入参）
  · 档位口径：测试 1k（¥0.0446）· 默认 2k（¥0.105）· 正式大场景 4k（¥0.1575）
  · 对照：老默认 `qwen-image-3.0-pro-t2i` = ¥0.45，且**不认** size/resolution
  **换通道必须先得到用户明确同意 ——「没同意」就是「不许」。**

鉴权：四级自动读取（本脚本自包含，不依赖其它 skill）
  ① --api-key 参数
  ② 环境变量 SEEDANCE_API_KEY
  ③ <当前目录>/.env
  ④ ~/.workbuddy/credentials/mv-auto-pipeline/keys.env   ← 用户级兜底，跨项目永久生效
  **永远不问用户要 key。**

用法：
  # 单张
  python gen_image.py --prompt-file char.txt --output ./fx_assets/char.png --size 3:4 --resolution 2k
  # 批量（资产清单 JSON，支持逐条 size + 断点续跑）
  python gen_image.py --batch assets.json --output-dir ./fx_assets --resolution 2k

排障：
  HTTP 403 先挖 body：{"code":"insufficient_user_quota"} = 额度不足 → 让用户充值，不许换通道
  连接重置 10054 / EOF in violation / 1010 → 先怀疑代理，命令前加
    env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY
"""

import argparse
import json
import os
import sys
import time
import urllib.error
import urllib.parse
import urllib.request
from pathlib import Path

# Windows 控制台中文输出
try:
    sys.stdout.reconfigure(encoding="utf-8")
    sys.stderr.reconfigure(encoding="utf-8")
except Exception:
    pass

# ---------------------------------------------------------------- 常量

DEFAULT_BASE = "https://api.seedance.nz"
DEFAULT_MODEL = "zhenzhen-image-g-v2.5-lowprice"
MODEL_NEEDS_SIZE_RES = ("zhenzhen-image-g-v2.5",)   # 按模型名前缀判定，不写死全名
RES_CHOICES = ("1k", "2k", "4k")
SIZE_CHOICES = ("3:4", "16:9", "1:1", "9:16", "4:3")
DEFAULT_RES = "2k"

POLL_INTERVAL = 5
POLL_MAX_ATTEMPTS = 90          # 5s × 90 = 7.5 分钟（单张实测 43s~253s 波动大）

# 2026-09-12 实测：Cloudflare 拦截 Python 默认 UA → 403 code 1010
DEFAULT_UA = ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
              "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36")

KEY_NAME = "SEEDANCE_API_KEY"
CRED_CANDIDATES = [
    Path.home() / ".workbuddy" / "credentials" / "mv-auto-pipeline" / "keys.env",
    Path.home() / ".workbuddy" / "credentials" / "keys.env",
]


# ---------------------------------------------------------------- 凭证

def _parse_env_file(path):
    """极简 .env 解析：KEY=VALUE，忽略注释与引号。"""
    out = {}
    try:
        for raw in Path(path).read_text(encoding="utf-8", errors="replace").splitlines():
            line = raw.strip()
            if not line or line.startswith("#") or "=" not in line:
                continue
            k, v = line.split("=", 1)
            out[k.strip()] = v.strip().strip('"').strip("'")
    except Exception:
        pass
    return out


def mask(val):
    if not val:
        return "(空)"
    return val[:4] + "*" * max(0, len(val) - 8) + val[-4:] if len(val) > 8 else "***"


def resolve_key(cli_key=None):
    """四级读取链，返回 (value, source)。"""
    if cli_key:
        return cli_key, "命令行参数"
    v = os.environ.get(KEY_NAME)
    if v:
        return v, "环境变量"
    local_env = Path.cwd() / ".env"
    if local_env.exists():
        v = _parse_env_file(local_env).get(KEY_NAME)
        if v:
            return v, f"项目 .env（{local_env}）"
    for cand in CRED_CANDIDATES:
        if cand.exists():
            v = _parse_env_file(cand).get(KEY_NAME)
            if v:
                return v, f"用户级凭证（{cand}）"
    return None, None


def missing_key_hint():
    return (
        "❌ 未找到 %s。请任选其一：\n"
        "   ① 写入 %s（推荐，一次性永久生效）：\n"
        "        SEEDANCE_API_KEY=你的key\n"
        "   ② 当前目录建 .env 写入同一行\n"
        "   ③ 命令行传 --api-key\n"
        "   （生图通道为「贞贞 ai 工坊」，不改用其它通道。）" % (KEY_NAME, CRED_CANDIDATES[0])
    )


# ---------------------------------------------------------------- HTTP

def _normalize_base(base):
    """统一成不带 /v1 的主机名，路径里再拼 /v1/...（只给主机名会打错端点是踩过的坑）。"""
    base = (base or DEFAULT_BASE).strip().rstrip("/")
    if base.endswith("/v1"):
        base = base[:-3]
    return base


def api_call(base, method, path, api_key, body=None, retry=3):
    """带指数退避的 API 调用。4xx 不重试。"""
    url = f"{base}{path}"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
        "User-Agent": DEFAULT_UA,
    }
    data = json.dumps(body).encode("utf-8") if body else None

    last_err = None
    for attempt in range(retry):
        try:
            req = urllib.request.Request(url, data=data, headers=headers, method=method)
            with urllib.request.urlopen(req, timeout=60) as resp:
                return json.loads(resp.read().decode("utf-8"))
        except urllib.error.HTTPError as e:
            err_body = e.read().decode("utf-8", errors="replace")
            last_err = f"HTTP {e.code}: {err_body}"
            if e.code == 403 and "insufficient_user_quota" in err_body:
                raise RuntimeError(
                    "HTTP 403：**用户额度不足**（insufficient_user_quota）。\n"
                    "  → 请充值后再试。**不许擅自改用其它生图通道。**\n"
                    f"  原始响应：{err_body}"
                )
            if 400 <= e.code < 500:
                raise RuntimeError(last_err)
        except (urllib.error.URLError, TimeoutError, ConnectionError) as e:
            last_err = f"{type(e).__name__}: {e}"
            if any(s in str(e).lower() for s in ("proxy", "reset", "eof", "10054")):
                print("  ⚠️ 疑似本机代理拦截 —— 命令前加："
                      "env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY",
                      flush=True)
        wait = 2 ** attempt
        print(f"  [retry {attempt + 1}/{retry}] {last_err}，{wait}s 后重试", flush=True)
        time.sleep(wait)
    raise RuntimeError(f"重试 {retry} 次仍失败：{last_err}")


# ---------------------------------------------------------------- 生图

def needs_size_res(model):
    return any(k in (model or "") for k in MODEL_NEEDS_SIZE_RES)


def submit_image(base, prompt, api_key, model, resolution, size, width=None, height=None,
                 output_format="jpeg"):
    body = {"model": model, "prompt": prompt}
    if needs_size_res(model):
        if size:
            body["size"] = size
        if resolution:
            body["resolution"] = resolution
        if width and height:
            body["width"] = width
            body["height"] = height
    else:
        if size:
            print(f"  ⚠️ 模型 {model} 不认顶层 `size`（只有 {'/'.join(MODEL_NEEDS_SIZE_RES)} 认）"
                  f"—— `size={size}` 不会被发送，别以为改了画幅。", flush=True)
        body["metadata"] = {"output_format": output_format}
        if width and height:
            body["metadata"]["width"] = width
            body["metadata"]["height"] = height
        elif resolution:
            body["metadata"]["resolution"] = resolution

    resp = api_call(base, "POST", "/v1/image/generations", api_key, body)
    task_id = resp.get("task_id") or resp.get("id")
    if not task_id:
        raise RuntimeError(f"提交响应缺 task_id：{resp}")
    return task_id


def extract_url(data):
    """结果 URL 字段名不固定 → 多路径兜底（含递归）。"""
    if isinstance(data, str) and data.startswith("http"):
        return data
    if isinstance(data, dict):
        for k in ("result_url", "url", "image_url", "fileUrl", "output",
                  "outputs", "urls", "images", "result", "results", "content", "data"):
            if k in data:
                got = extract_url(data[k])
                if got:
                    return got
        for v in data.values():
            got = extract_url(v)
            if got:
                return got
    if isinstance(data, list):
        for item in data:
            got = extract_url(item)
            if got:
                return got
    return None


def poll_task(base, task_id, api_key, max_attempts=POLL_MAX_ATTEMPTS):
    for attempt in range(1, max_attempts + 1):
        resp = api_call(base, "GET", f"/v1/image/generations/{task_id}", api_key)
        data = resp.get("data", resp)
        status = data.get("status")
        print(f"  [poll {attempt}] status={status} progress={data.get('progress', '?')}",
              flush=True)
        if status == "SUCCESS":
            return data
        # 终态两个枚举都认（接口在不同版本下回过 FAILED 与 FAILURE）
        if status in ("FAILED", "FAILURE"):
            reason = (data.get("fail_reason") or data.get("failedReason")
                      or data.get("message") or "未知")
            raise RuntimeError(f"任务失败（status={status}）：{reason}")
        time.sleep(POLL_INTERVAL)
    raise RuntimeError(f"轮询 {max_attempts} 次仍未完成"
                       f"（{(max_attempts * POLL_INTERVAL) // 60} 分钟）")


def download_file(url, dest_path, retry=3):
    dest_path = Path(dest_path)
    dest_path.parent.mkdir(parents=True, exist_ok=True)
    last_err = None
    for attempt in range(retry):
        try:
            safe_url = urllib.parse.quote(url, safe=":/?#[]@!$&'()*+,;=%")
            req = urllib.request.Request(safe_url, headers={"User-Agent": DEFAULT_UA})
            with urllib.request.urlopen(req, timeout=120) as resp:
                dest_path.write_bytes(resp.read())
            return dest_path
        except Exception as e:
            last_err = e
            wait = 2 ** attempt
            print(f"  [download retry {attempt + 1}/{retry}] {e}，{wait}s 后重试", flush=True)
            time.sleep(wait)
    raise RuntimeError(f"下载失败：{last_err}")


def generate_one(base, prompt, output_path, api_key, model=DEFAULT_MODEL,
                 resolution=DEFAULT_RES, size=None, width=None, height=None):
    print(f"[submit] model={model} resolution={resolution} "
          f"size={size or '（不传，用服务端默认）'}", flush=True)
    print(f"  prompt: {prompt[:80]}{'...' if len(prompt) > 80 else ''}", flush=True)
    task_id = submit_image(base, prompt, api_key, model, resolution, size, width, height)
    print(f"  task_id: {task_id}", flush=True)

    data = poll_task(base, task_id, api_key)
    url = extract_url(data)
    if not url:
        raise RuntimeError(f"SUCCESS 但未取到图片 URL：{data}")

    usage = data.get("usage", {}) or {}
    amount = usage.get("amount", "?")
    print(f"  [done] 消耗 {amount} {usage.get('currency', '')}", flush=True)

    download_file(url, output_path)
    print(f"  [saved] {output_path}", flush=True)
    return {"task_id": task_id, "url": url, "path": str(output_path), "cost": amount}


def batch_generate(base, assets_file, output_dir, api_key, model, resolution, global_size):
    assets = json.loads(Path(assets_file).read_text(encoding="utf-8"))
    output_dir = Path(output_dir)
    output_dir.mkdir(parents=True, exist_ok=True)
    state_path = output_dir / "_state.json"
    state = json.loads(state_path.read_text(encoding="utf-8")) if state_path.exists() else {}

    total_cost = 0.0
    for asset in assets:
        aid = asset["asset_id"]
        if state.get(aid, {}).get("status") == "done":
            existing = state[aid].get("path")
            if existing and Path(existing).exists():
                print(f"[skip] {aid} 已完成：{existing}", flush=True)
                continue

        prompt = asset["prompt_text"]
        out_path = output_dir / f"{aid}.png"
        a_size = asset.get("size") or global_size      # 逐条优先，其次命令行

        last_err = None
        for attempt in range(3):
            try:
                print(f"\n=== [{aid}] {asset.get('name', '')}（尝试 {attempt + 1}/3）===",
                      flush=True)
                result = generate_one(base, prompt, out_path, api_key, model, resolution, a_size)
                state[aid] = {"status": "done", **result}
                try:
                    total_cost += float(result.get("cost") or 0)
                except (TypeError, ValueError):
                    pass
                break
            except Exception as e:
                last_err = e
                print(f"  [fail attempt {attempt + 1}] {e}", flush=True)
                time.sleep(5)
        else:
            state[aid] = {"status": "failed", "error": str(last_err)}
            print(f"  [FAILED] {aid} 重试 3 次仍失败", flush=True)

        state_path.write_text(json.dumps(state, ensure_ascii=False, indent=2),
                              encoding="utf-8")

    done = sum(1 for v in state.values() if isinstance(v, dict) and v.get("status") == "done")
    failed = sum(1 for v in state.values() if isinstance(v, dict) and v.get("status") == "failed")
    print("\n=== 批量完成 ===", flush=True)
    print(f"  成功：{done} / 失败：{failed} / 总成本：¥{total_cost:.4f}", flush=True)
    print(f"  状态文件：{state_path}", flush=True)
    return state


# ---------------------------------------------------------------- CLI

def main():
    ap = argparse.ArgumentParser(description="贞贞 ai 工坊生图（自包含）")
    ap.add_argument("--prompt", help="单张生图的提示词")
    ap.add_argument("--prompt-file", help="从文件读提示词（中文推荐）")
    ap.add_argument("--output", help="单张生图的输出路径")
    ap.add_argument("--batch", help="批量模式：资产清单 JSON 路径")
    ap.add_argument("--output-dir", help="批量模式：输出目录")
    ap.add_argument("--api-key", help="API Key（四级链最高优先）")
    ap.add_argument("--api-base", default=os.environ.get("SEEDANCE_API_BASE") or DEFAULT_BASE,
                    help=f"网关（默认 {DEFAULT_BASE}）")
    ap.add_argument("--model", default=DEFAULT_MODEL, help=f"模型（默认 {DEFAULT_MODEL}）")
    ap.add_argument("--resolution", default=DEFAULT_RES, choices=RES_CHOICES,
                    help="1k 测试（¥0.0446）/ 2k 默认（¥0.105）/ 4k 正式大场景（¥0.1575）")
    ap.add_argument("--size", default=None, choices=SIZE_CHOICES,
                    help="画幅：主角图 3:4 / 场景图 16:9 / 道具 1:1；不传＝服务端默认（不猜）")
    ap.add_argument("--width", type=int, help="自定义宽（老模型口径）")
    ap.add_argument("--height", type=int, help="自定义高")
    args = ap.parse_args()

    base = _normalize_base(args.api_base)

    key, src = resolve_key(args.api_key)
    if not key:
        sys.exit(missing_key_hint())
    if src != "命令行参数":
        print(f"[key] {KEY_NAME} 来源：{src}（{mask(key)}）", flush=True)

    if args.batch:
        if not args.output_dir:
            sys.exit("❌ 批量模式必须指定 --output-dir")
        batch_generate(base, args.batch, args.output_dir, key,
                       args.model, args.resolution, args.size)
        return

    prompt = args.prompt
    if args.prompt_file:
        prompt = Path(args.prompt_file).read_text(encoding="utf-8").strip()
    if not prompt:
        sys.exit("❌ 必须指定 --prompt 或 --prompt-file")
    if not args.output:
        sys.exit("❌ 单张模式必须指定 --output")
    generate_one(base, prompt, args.output, key, args.model,
                 args.resolution, args.size, args.width, args.height)


if __name__ == "__main__":
    main()
