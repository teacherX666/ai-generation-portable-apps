## 零、一句话核心

> **AI 打斗特效的提示词，核心只有两个词：流体 和 粒子。**
> 主体用**流体**做连续形态，冲击/崩裂处用**粒子**做物理反馈——这就是这类视频的全部底层逻辑。

以及第二期补上的第三个核心概念：**锚点**——让技能与人物、环境**发生关系**。

---

## 一、流体 vs 粒子

| 维度 | 流体（Fluid） | 粒子（Particle） |
|---|---|---|
| 本质 | **连续的形态** | 离散的、可崩解的碎片/颗粒 |
| 典型形态 | 能量洪流、能量屏障、光丝、剑气刀气 | 固体碎片、气态烟雾、光点能量 |
| 画面表现 | 连贯、可塑性、动态流动感 | 碎石崩裂、烟尘扩散、光点迸溅 |
| 分工 | **做主体**（大招本体、拖尾主体） | **做反馈**（撞击崩裂、氛围点缀） |
| 使用频率 | 拖尾/大招场景更常用 | 提质感时作为补充 |

**UP 主实测经验：**
- 人物奔跑拖尾对比：左侧人物用**银白粒子**、右侧人物用**流体**——两者观感差异明显，**拖尾优先用流体**。
- 想提升质感：**流体做主体 + 粒子做点缀**。例：「火焰流体」为主体，周围「火焰粒子」做点缀。
- 开场那条龙的视频：**龙形主体 = 流体，冲击点位崩裂 = 各种粒子**。一句话概括核心。

## 二、提示词结构公式（六要素）

UP 主手写板书：

```
镜头机位 + 流体 + 粒子 + 光效 + 撞击/接触位置 + 物理反馈
```

| 要素 | 说明 | 是否必写 |
|---|---|---|
| 镜头机位 | 景别 + 机位角度 + 运镜 | 可不写（Seedance 会自行安排合理景别），但**必须学习**，是提升画面控制力的关键 |
| 流体 | 主体形态：能量洪流/屏障、光丝、剑气刀气、火焰流体 | ✅ 核心 |
| 粒子 | 固体碎片、气态烟雾、光点能量 | ✅ 核心 |
| 光效 | 体积光、环境氛围词（AI 生成下色彩效果基本自动出来） | 可加，进阶 |
| 撞击/接触位置 | 撞击中心是什么（地面/城墙），或毒雾等「接触面」 | 建议写，提高准确度 |
| 物理反馈 | 撞击后物体发生什么变化（碎石/碎砖崩裂、腐蚀脱落） | 建议写 |

## 三、锚点（Anchor）——技能与人物发生关系的关键

### 3.1 为什么需要锚点

目标效果：人物释放光剑 → 光剑**撞击树林区域** → 产生烟尘、光点粒子。

这类特效不是凭空放的，**流体碰到撞击位置才会迸溅为各种粒子**。想让"释放的技能"与人物、环境产生关联，就需要一个东西——**特效锚点**。

### 3.2 定义

UP 主把"释放位置"改称为 **特效锚点**——它更精确，也更有"锚定"的含义。

**锚点可以出现在任何位置：**

| 锚点位置 | 说明 |
|---|---|
| 掌中心、掌心 | 最常见的手持释放 |
| 刀剑 | 武器释放 |
| 非手部（地面涌出、从别处过来） | "灵体虚影"、此前的"法天象地"都是这种做法 |

> **为什么叫"锚点"不叫"释放位置"**：锚点的**优先级是高的**——它能避免技能从人物手中或其他地方**乱冒出来**，**大幅提高生成稳定性**。

### 3.3 最小三要素

```
锚点 + 撞击位置 + 物理反馈
```

只要这三个要素确定好，哪怕只发给 AI 一句最简单的描述，AI 也能给出很不错的结果。

**撞击位置（接触位）非常灵活，可以写：**
- 地面 / 城墙
- 兽群
- 敌方某个身体部位
- 撞击在**敌方的技能**上
- 撞击在**护盾**上

## 四、实战案例 A：龙形火焰流体冲击（4 次迭代）

生成设置：**即梦 Seedance 2.0 VIP，8 秒，16:9，720P，纯文本生成、不上传任何参考图/资产。**

> UP 主特意说明：**不用图、不加资产，纯文本就能达到演示效果。**
> 想统一形象（固定的龙 / 加人物），再点「参考内容」上传。

### 迭代对照表

| 版本 | 关键改动 | 结果 | 问题诊断 |
|---|---|---|---|
| **V1** | 电影级分镜镜头 + 巨型龙形火焰流体大招向前冲击 + 撞击中心迸溅红色火星粒子与黑烟粒子 + 地面大面积碎石崩裂扬尘 + 写实渲染 + 体积光 | ❌ 翻车 | **龙的位置太低**。改为仰视视角、或写明高度米数 |
| **V2** | 加「**巨型火龙悬于百米高空画面左上方**」 | ❌ 不是想要的 | 模型理解成**实体火龙** + 后面喷出的火焰流体——理解其实合理，但**因为没写「火焰流体」是龙本身**，所以跑偏 |
| **V3** | 主体明确写成「**巨型龙形火焰流体**从百米高空向下冲击」 | ✅ 没问题 | **主体必须是流体**，不能只写「巨型火龙」 |
| **V4** | 撞击中心改为**城墙**；碎石改为**碎砖**；写清城墙发生什么变化 | ✅ 可控 | 撞击中心可任意指定 |

### V1 提示词原文（OCR 复原，约 2:08）

```
电影级分镜镜头，巨型龙形火焰流体大招向前冲击，撞击中心迸溅红色火星粒子与黑烟粒子，
地面大面积碎石崩裂扬尘，写实渲染，体积光，动……
```

### V3/V4 提示词原文（OCR 复原，约 3:45）

```
巨型火龙悬于百米高空画面左上方，巨型龙形火焰流体大招向前冲击，
撞击中心迸溅红色火星粒子与黑烟粒子，地面大面积碎石崩裂扬尘，写实渲染，体积光，动……
```

### 三条可直接复用的经验

1. **主体必须带材质词**：写「巨型火龙」→ 模型给实体；写「巨型龙形**火焰流体**」→ 才是想要的流体大招。
2. **高度/视角要明写**：低空会翻车，写「百米高空」+「仰视视角」才稳。
3. **撞击中心可改**：不写模型也能理解撞击与地面的关系；要精确控制就写清「撞击中心是 XX + XX 发生了什么变化（粒子的崩裂）」。

## 五、实战案例 B：单人·掌心雷球（锚点法）

### 最小可执行提示词（按视频讲解重构）

```
场景：雨夜，镜头低角度仰拍（效果很不错）
特效锚点：锁定掌心
动作：闪电汇聚成雷球，将雷球释放
撞击：撞击位置迸溅各种粒子、黑暗与光点粒子
电弧：在雷球周围闪烁游走
人物：中近景；若蓄力幅度不够，写"抬手再向前伸出"
```

把人物的**主视图图片 @ 进来**，只添加主视图、不写场景图也能生成。

### 必补的「物理反馈」（最容易被忘）

> 撞击的物理反馈太弱了，就没有打击感。因为我没写物理反馈，应该加上墙面的坍塌。

补法：**墙面的坍塌 + 碎石的飞射，并且改成不规则的形状**（规则形状会显假）。

### 出错了怎么调

| 问题 | 调法 |
|---|---|
| 模型生成偶发异常 | 提示词没问题，直接**再生成一遍** |
| 人物开头景别太远 | 写"视觉主导"更稳定；明确景别如"人物中近景" |
| "不规则雷球"语病 | 改成"**不规则的形状**" |
| 流体从人物身前冒出（应在身后） | 属于生成问题，再生成一遍即可 |

## 六、光效：让 AI 帮你生成

在 AI 生成方向，光效比传统制作简单很多：**写好流体和粒子 + 基本的环境氛围词，色彩效果就已经出来了**。想进一步写光效，可以直接问 AI。

### 操作方式

给 AI 的提问示例：**「我想要一个阴冷毒雾山谷绿色感，用什么光效？」**

AI 返回的结构化光效清单（OCR 复原）：

```
阴冷毒雾 · 幽暗绿色光效组合（适配 AI 图 / AI 视频，国漫 CG 风格）

核心基调：低亮度、暗部主导，绿光不作为主照明，而是环境漫射 + 毒雾自发光

一、核心光效清单（直接复制可用）
主环境光
1. 毒雾体积光
   - 亮度低，不照亮物体亮面，只浸润空气
   - 关键词：volumetric fog, poison mist ambient glow, dim sick green diffuse glow
2. 荧绿次表面微光
   - 物体边缘、岩石、雾气颗粒有薄薄的荧绿轮廓光
   - 不是描边，是毒雾侵染出来的微弱冷光，亮度低，只在阴影区域显现
补光 / 氛围光 …
```

### 实际写入视频提示词

```
我想要一个仰拍的冲击镜头，毒雾以暗黑幽绿为主体，笼罩古城废墟
```

- 用**体积雾 + 环境漫射**（原词可能有出入）。
- 可用英文关键词直接补强：`volumetric fog` / `poison mist ambient glow` / `dim sick green diffuse glow`。

### 撞击位置 vs 接触位置

| 类型 | 例子 | 反馈写法 |
|---|---|---|
| **撞击位置** | 龙形流体砸向地面 / 城墙 | 撞击中心 + 碎石/碎砖崩裂（粒子） |
| **接触位置** | 毒雾笼罩古城废墟（不是砸下去，是覆盖接触） | 接触面出现**被腐蚀脱落**的效果 |

> 写提示词时要分清「冲击撞击」还是「覆盖接触」，两者的物理反馈完全不同。

## 七、双人打斗与固定搭配

**通用动作四件套（强推固定搭配）：**

> **压缩 → 蓄能 → 膨胀 → 吞吐**

这组词通用性极强——写火焰流体可以这么写，写强光（提升质感的好写法，让光影有质感）也可以这么写。

### 构图与景别（防止"低智镜头"）

| 场景 | 建议 |
|---|---|
| **单人** | 可以不写景别和人物主导权重，生成还算稳定 |
| **双人** | **必写**景别和构图，否则不约束时一个场景会直接冒出两个人、且没有距离感，镜头看起来很"低智" |

**景别写法参考：**
- **中近景**：画面内容为人物腰部以上
- **远景**：两人位于画面两端，距离上百米
- **对角构图**：一个人物在左下地面，另一个在右上角

> 练习建议：UP 主前面用单人演示是为了讲得简单，**实际练习建议都加上双人并写明景别**。

## 八、图片资产与三视图

| 阶段 | 做法 |
|---|---|
| 最小资产 | 只上传**人物主视图**图片即可生成（身形、衣服不要求） |
| 进阶质感 | 图片资产很重要，决定画面质感；后续要补**场景图 + 三视图** |

> 人物与背景割裂、细节质感不行，看似问题很多，**其实是缺少三视图**的原因。

## 九、撞击位置进阶用法

| 撞击对象 | 效果示例 |
|---|---|
| 护盾（气盾） | 护盾破碎、被吞没 |
| 接触位=毒/黑雾 | 碰到敌人使其昏迷，或石化 |
| 敌方身体破绽 | 对打过程中找到别人的破绽 |
| 护盾攻防 / 法术对轰 | 高端打斗连接 |

> 纯光效类的（毒物、龙形流体、灰光、体积光、体积雾等技能）可以和 AI 多对话，让它帮你细化。

## 十、用 AI 对话复刻提示词（三步法）

| 步骤 | 做法 |
|---|---|
| **① 给结构** | 把「镜头机位 + 流体 + 粒子 + 光效 + 撞击/接触位置 + 物理反馈」这个结构发给 AI，告诉它你要相关的提示词 |
| **② 给样例** | 效果不好时，把上面的 3 条提示词一起发过去，让 AI**参考这些提示词进行复刻** |
| **③ 对话微调** | 哪点不满意就针对性说，例如「撞击做得不够好」→ 让它改；**风格（卡通等）、镜头机位、撞击/接触位置、主体**都可以用对话改 |

### 让 AI 帮你写提示词的正确姿势（第二期补充）

1. 先把**最小可执行**的要素（锚点 / 撞击 / 物理反馈）确定好；
2. 把上面的结构发给 AI，再把你的提示词发过去，让 AI 了解你要的效果；
3. 有错的地方，让 AI 总结原因，**自己也要多写多练**。

> ⚠️ UP 主提醒：**直接让 AI 帮你写提示词，效果并不好。** 结构和最初那几条提示词是他手写 + 试错总结出来的，这套方法帮大家省的是时间和抽卡成本。
> 判据：**你有一个精确的目标，AI 给出的结果才会非常不错。**

## 十一、UP 主反复强调的 5 个要点

1. **流体和粒子是这类视频的全部核心**，先手写一遍才能真正理解提示词。
2. **纯文本就能生成**，不必一开始就上传参考图；要统一形象（龙/人物）再用参考内容。
3. **时长 8 秒**即可，Seedance 2.0 模型能力很强，不写镜头也会给合理景别，但**镜头机位一定要学**——它是提高画面控制力的重要部分。
4. **失败是提示词问题，不是模型问题**：V2 那次模型理解得很合理，是自己没写清「流体」。
5. AI 打斗特效目前机会很大：**很多漫剧的打斗水平都不高**，吃透这套方法找相关工作不难。
