# 出图提示词模板（缺图时用）

> 走贞贞 ai 工坊（`scripts/gen_image.py`）。**画幅按资产类型定**：主角图 `3:4`、场景图 `16:9`、道具 `1:1`。
> 档位：**测试 1k · 默认 2k · 正式大场景 4k**。
>
> ⚠️ **出图提示词一律以「无文字无水印」收尾。**
> 2026-09-26 实测：一条没写负向的提示词，城门上冒出了可读汉字匾额 —— 出图模型会自己编文字。
> 场景图尤其要注意（建筑、招牌、旗帜最容易被写满字）。

## 二、主角图 · 四视图转身参考（T2）★最重要

**为什么必须做**：教程明确指出——人物与背景割裂、细节质感不行，**其实是缺少三视图**的原因。

**版式（严格照写）**：单张白底纸，左右分栏——
- **左三分之一 = 面部大特写**
- **右三分之二 = 同一角色的三个全身视图，从左到右依次：正面 / 左侧面 / 背面**
- **每个视图都要完整可见全身**（含脚）

```
角色设定四视图，纯白背景，单张画面左右分栏构图。

左三分之一：角色面部大特写，清晰展示【脸型/眉眼/发型细节/发色/耳饰】。

右三分之二：同一角色的三个全身视图，从左到右依次为 正面 / 左侧面 / 背面，
三个视图服装、发型、配饰、鞋履完全一致：
【完整服装逐件描述：上衣/外袍/下装/腰带/护腕/鞋靴】，
【发型的正面与背面形态分别描述，含发饰位置】，
【配饰：耳饰/项链/腰佩/纹样】，
【鞋履】，【武器及悬挂位置】，
配色以【主色 + 点缀色】为主。

三个视图均为站姿自然、四肢完整可见、比例一致、光影统一，
【质感词】，高清细节，无文字无水印，无背景元素。
```

> **一致性铁律**：四视图提示词、半身正面照提示词、最终视频提示词里的角色描述**必须逐字一致**，否则模型会漂脸。

## 四、批量生成（一次出齐主角图 + 场景图）

写资产清单 JSON：

```json
[
  {"asset_id": "char_main",  "name": "主角四视图", "size": "3:4",  "prompt_text": "……"},
  {"asset_id": "char_half",  "name": "主角半身",   "size": "3:4",  "prompt_text": "……"},
  {"asset_id": "scene_01",   "name": "古城废墟",   "size": "16:9", "prompt_text": "……"}
]
```

```bash
# PY = 你的 Python 解释器路径（自行替换）
PY="<python 解释器路径>"
env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY "$PY" \
  ~/.workbuddy/skills/fight-fx-anchor-prompter/scripts/gen_image.py \
  --batch assets.json --output-dir ./fx_assets --resolution 2k
```

- **逐条 `size` 优先**，没写才用全局 `--size`
- 支持**断点续跑**：已成功的会 skip，失败的重试 ≤3 次
- 状态写在 `./fx_assets/_state.json`

## 六、排障速查

| 症状 | 真因 | 修法 |
|---|---|---|
| HTTP 403 | **先挖 body**：`insufficient_user_quota` = 额度不足 | 告诉用户充值，**不许换通道** |
| 一批图前成功后全 403 | 额度见底 | 同上 |
| 连接重置 10054 / `EOF in violation` / 1010 | **代理**拦截 | 命令前加 `env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY` |
| 405 / 404 | 路径写错（写成复数 `images`） | 必须是 **`/v1/image/generations`**（单数） |
| 轮询一直没结果 | 单张耗时 43s~253s 波动 | 等满（脚本内置 5s × 90 = 7.5 分钟） |
| 三人视图不一致 | 描述不一致 | 三个视图的描述**逐字复用**同一段 |
| 全身被裁掉脚 | 版式没写清 | 明写「三个全身视图，四肢完整可见含脚」 |
