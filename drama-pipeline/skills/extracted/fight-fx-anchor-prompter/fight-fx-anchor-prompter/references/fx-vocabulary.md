# 打斗特效槽位词库（写提示词前必读）

> 按选择卡的槽位组织。挑词 → 按 §四 的 5 句写法组装 → 按目标模型封装。
> 原则：**流体做主体，粒子做反馈**；每个强度词都要能落到具体载体。

## D 组 · 锚点（技能从哪出来，必选）

| 编号 | 锚点 | 中文写法 | 说明 |
|---|---|---|---|
| D1 | 掌中心 | **特效锚点锁定掌中心**，雷球自掌心凝聚 | ⭐最常见的手持释放 |
| D2 | 刀剑/武器 | 锚点锁定刀锋，剑气自刀身延展 | 武器释放 |
| D3 | 双掌合十 | 双掌合十，能量自掌缝压缩成型 | 蓄力型 |
| D4 | 地面涌出 | 技能自地面裂缝中涌出 | "非手部"做法 |
| D5 | 身后浮现 | 技能自人物身后浮现成型 | "非手部"做法，教程推荐的灵体虚影用法 |
| D6 | 额头/天眼 | 自额头天眼射出 | 仙侠、玄幻 |
| D7 | 双锚点（对轰） | 双方各自掌心锚点，两个技能在同一点相撞 | ⭐双人/法术对轰必用 |

> **为什么叫"锚点"而不是"释放位置"**：锚点优先级最高——它能避免技能从人物手中或其他地方**乱冒出来**，大幅提高生成稳定性。
> **写法要点**：不是在描述里提一句，而是写成**锁定语句**——「特效锚点锁定掌中心」。

## E 组 · 撞击 / 接触位置（打在哪，必选）

| 编号 | 位置 | 中文写法 | 对应物理反馈 |
|---|---|---|---|
| E1 | 地面 | 撞击中心为地面 | 地面裂纹下陷、碎石飞射、扬尘 |
| E2 | 城墙/建筑 | 撞击中心为古城墙 | 碎砖崩裂、墙面坍塌 |
| E3 | 树林/植被 | 撞击点在树林区域 | 树木拦腰折断、木屑飞散、叶片炸开 |
| E4 | 敌方身体部位 | 命中敌方胸口/肩甲 | 身体后仰、护甲凹陷、衣料撕裂 |
| E5 | 敌方护盾 | 撞击在敌方气盾上 | **护盾破碎**、被吞没、涟漪扩散 |
| E6 | 敌方技能 | 两股流体在同一点相撞 | **法术对轰**、双向压力、界面爆闪 |
| E7 | 兽群/敌群 | 撞击在兽群中央 | 群体被犁开、翻飞 |
| E8 | 接触面（覆盖） | 毒雾笼罩古城废墟 | **腐蚀脱落**（不是崩裂！） |

### ⚠️ 撞击 vs 接触（必分清）

| 类型 | 例子 | 反馈逻辑 |
|---|---|---|
| **撞击位置** | 龙形流体砸向地面/城墙 | 撞击中心 + 碎石/碎砖崩裂（粒子） |
| **接触位置** | 毒雾笼罩古城废墟（覆盖） | 接触面**被腐蚀脱落** |

> 写提示词时先问自己：**这是"打下去"还是"盖上去"？**两者的物理反馈完全不同。

**进阶用法（撞击对象）**：护盾（攻防）、接触位=毒/黑雾（碰到敌人使其昏迷或石化）、敌方身体破绽。

## H 组 · 景别与构图（双人/多人必写）

| 景别 | 写法 |
|---|---|
| 中近景 | 画面内容为**人物腰部以上** |
| 远景 | 两人位于画面两端，**距离上百米** |
| 对角构图 | 一个人物在**左下地面**，另一个在**右上角** |
| 仰拍 | 低位仰视，天空占画面大部 |
| 俯拍 | 高位俯视，地面纹理清晰 |
| 跟随运镜 | 镜头贴住主体动作路径跟拍 |

> **单人可以不写景别（生成还算稳定）；双人/多人必写**——不约束时一个场景会直接冒出两个人、且没有距离感，镜头看起来很"低智"。

## 通用动作节奏四件套

```
压缩 → 蓄能 → 膨胀 → 吞吐
```

- 火焰流体：火焰向内压缩 → 蓄能发光 → 骤然膨胀 → 向前吞吐成洪流
- 强光提质感：光体压缩成核 → 蓄能变色 → 膨胀炸开 → 吞吐成冲击波

> 这组词**通用性极强**，写流体、写强光都能套。
