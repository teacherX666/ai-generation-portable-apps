# 三种模型的输出格式模板（封装时读对应一节）

> 本 skill 的产出是**打斗特效提示词**。格式跟着用户在 I 组选的模型走。
> 本文件只讲**特效怎么嵌进去**；动作编排的完整规范见 `fight-prompt-master` / `seedance-2.5-fight-prompter`。

---

## 一、即梦 Seedance 2.0（11 字段格式）

适用：I1。时长 8-15s（**教程演示用 8s**，16:9，720P）。

### 字段（名字与顺序固定）

```
【整体风格】"整体风格:"开头；调性词×3 + 特效通过具体物理现象呈现 + 排除跨题材污染词；主体清晰可读优先于特效
【角色卡】- @图片1作为[主角]: 外观锚点+武器/能力+动作倾向
          文生模式（无角色图）必须写全5-8项锚点：性别年龄段/脸型发型发色/体型/服装逐件/配色/武器/能量颜色形态
【场景设定】地点+光线+空间结构+4-6个可被动作影响的环境元素（城墙/树林/石柱/废墟）
【画面坐标】开场主体位置+威胁进入方向+纵深/退路
【起幅】开场画面+第一威胁（技能起手/锚点显现）
【过程】4-6个节点，每节点：动作→对手反应→环境反馈→镜头反馈→衔接
【结尾】终段动作+结果爆发+空间位置；不写慢收势/能量渐熄/定格摆姿态
【特效细节】★本 skill 主战场：
    锚点锁定位置 → 流体主体形态 → 撞击/接触位置
    → 迸溅粒子（A与B） → 物理反馈（坍塌/飞散/不规则形状）
    能量只沿武器/碰撞点/攻击轨迹，粒子不遮主体
【音效】10-14个，逗号分隔，只取本题材声音（含技能音：凝结/轰鸣/爆裂/电弧）
【禁止项】文字/UI/水印/Logo/角标/可读文字
【强制声明】无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

### 时间块
- 8s：约 2-3 段（0-3 / 3-6 / 6-8）
- 15s：约 4 段（0-4 / 4-8 / 8-11 / 11-15）
- 用**连续整秒粗时间段**，单条提示词只用这一种时间格式

### 特效段落模板（直接套）

```text
特效锚点锁定【掌心/刀锋/地面】，【流体主体】自锚点压缩蓄能后向前吞吐成洪流，
撞击中心为【城墙/地面/敌方护盾】，迸溅【粒子A：红色火星粒子】与【粒子B：黑烟粒子】，
【撞击位置】发生【大面积碎砖崩裂扬尘】，碎块形状不规则，
【光效：写实渲染，体积光】，【环境氛围词】，
能量只沿【流体轨迹/碰撞点】流动，粒子不遮挡人物主体。
```

## 二、即梦 Seedance 2.5（三段式 + 时间戳）

适用：I2。时长 4-30s（超长 30-180s）。

### 骨架

```
【整体风格】
整体风格: [调性词1 + 调性词2 + 调性词3],
[特效/速度/力量] 通过 [具体物理现象A]、[具体物理现象B] 呈现,
不出现 [跨题材污染词]。
主体清晰可读优先于特效, 动作不断流, 命中不定格, 中段镜头稳定跟随, 高帧率流畅。

【素材描述】（多模态）
@图片1 = [主角]；@图片2 = [对手]；@图片3 = [场景]；@视频4 = [动作/白模参考]（无则写「无」）
多人同框时分别 @图片 锁定各自长相，防双胞胎。

【一句话概述】
[主体 + 地点 + 事件 + 题材/风格 + 特殊运镜]，单段 [X] 秒。

【时间戳剧本分镜】（★2.5 核心，每拍必须钉死秒数）
0-2秒：[起幅] 锚点显现 + 第一威胁 + 空间关系
2-7秒：[过程节点1] 蓄能膨胀 → 流体吞吐 → 撞击 → 粒子迸溅 → 环境反馈 → 镜头反馈
7-12秒：[过程节点2] ...
12-18秒：[过程节点3] ...
18-24秒：[过程节点4] ...
24-30秒：[结尾] 终段爆发 + 空间位置，不写慢收势

【特效细节】
锚点锁定【】；流体主体【】；撞击/接触位置【】；
迸溅【粒子A】与【粒子B】；物理反馈【坍塌/飞散/不规则形状】；
能量只沿武器/碰撞点/攻击轨迹，粒子不遮主体。

【音效】[10-14个，逗号分隔]

【全局补充】
[机位 + 环境 + 整体声音/氛围 + 光影；负向：不要字幕、不要BGM、不要水印、不要Logo、不要可读文字]

【强制声明】
无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

### 硬规则
- **【时间戳剧本分镜】是 2.5 核心**：每个攻防/特效节点必须 `X-X秒：`，不用时间戳 = 没用上 2.5 能力
- 【整体风格】必须保留 `整体风格:` 开头
- 【素材描述】必须按上传顺序编号 `@图片1/@视频2/@音频3`，无素材写「无」
- 字数 1100-1800（目标 1200-1500）
- **双版本输出**：多模态版（@图片占位）+ 纯文字版（可直接复制）

### 2.5 特效增强手段

| 手段 | 写法 |
|---|---|
| 慢镜局部 | 「第 7 秒流体撞击瞬间，该帧以 40% 速度呈现 0.5 秒后恢复正常速度」 |
| 多速度层次 | 「连续快攻（正常）→ 撞击瞬间（慢镜）→ 余波（突停 0.3 秒）」 |
| 镜头速度变化 | 「镜头随流体推进加速，撞击前 0.2 秒骤停，震动通过机位微晃呈现」 |
| 环境余波链 | 「上一拍碎裂的碎砖未落地，卷入下一拍的冲击波中」 |
| 时间戳断点 | 「3-5秒：流体压缩蓄能；5-7秒：吞吐撞击」 |

## 三、MiniMax H3（英文六段式）

适用：I3。时长 10-20s。**输出必须全英文。**

### 六段（顺序固定）

```
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

### 特效相关的写法要点

**subject_definitions**：给可复用可见内容定义 `<Subject N>`（人物/环境/道具/风格）。
图片只用来定义形象时，写在 `<Subject N>` 定义里——"whose appearance comes from `<Picture N>`"，**不给图片单独开一行**。

**summary**：以方括号任务类型前缀开头，如 `[reference generation]`。

**detailed_description**：先写风格句（E），再 `[Shot 1]`（不带时间戳），然后 `[Shot N] At MM:SS.mmm, ...`。
**风格句模板**：
```
The target video uses a [STYLE] set in [ENVIRONMENT], with [LIGHTING] and [MOOD].
```

**特效写入 detailed_description 的英文模板**：
```text
[Shot 1] The [flu id subject] condenses at her [palm / blade tip], compressing into a
glowing core, then surges forward as a continuous torrent. The camera [pushes in / tracks].
[Shot 2] At 00:04.000, the torrent slams into the [city wall / ground / enemy shield].
Sparks and black smoke particles burst outward from the contact point; the [wall] collapses
into irregular shattered bricks and billowing dust. Energy erupts only from the impact point,
never floating free. [Shot 3] At 00:08.000, ...
```

**关键风控（H3 特有两坑）：**
1. **能量只从接触点爆发**，不能是自由漂浮的光束或常驻光环。能量是**命中的结果**，不是命中的替代品。
2. 写实街战模式下**完全没有能量**——冲击纯粹物理（灰尘、碎屑、闷哼）。

**overall_soundscape**：氛围 + 物理声（凝结嗡鸣、流体轰鸣、撞击轰响、碎砖落地）。
**non_diegetic_music**：观众侧配乐（无则写 `N/A`）。

### 可选：调性兜底块（六段之外，单独附）
H3 容易漂（比如武侠片渲染出西式铠甲、或僵住成静态对峙）时，在六段提示词**之后**附一段中文约束（**不属于提示词正文**）：
```
1. 严禁出现西式铠甲骑士造型，必须为[角色正确调性]。
2. 严禁原地互殴，每秒必须有空间位移（突进/腾跃/翻转/滑行/坠落/交错）。
3. 严禁动作停顿或对峙空镜，技能命中与碰撞必须立刻给出沉重受力反馈。
```

## 四、通用收尾（三种模型都要）

### 结尾三不写
- 不写「缓缓收势」「光芒渐熄」「镜头缓缓拉远」
- 不写定格摆姿势
- 不写"渐隐"式收尾
→ 改成：**最后一击 + 结果爆发 + 空间位置**

### 负向约束（默认都加）
不要字幕 / 不要 BGM / 不要水印 / 不要 Logo / 不要可读文字

### 跨题材污染词（按题材排除）
- 武侠/仙侠禁：机甲、警笛、赛博、霓虹广告
- 现代街战禁：灵气、法力、御剑、阵纹
- 机甲禁：刀气、掌法、内力

## 五、时长与节点数参考（特效向）

| 特效类型 | 建议时长 | 节点数 |
|---|---|---|
| 单个杀招/一击制敌 | 4-6s | 1 个特效节点 |
| 蓄力→释放→撞击→余波 | 8-12s | 2-3 个 |
| 完整大招 + 环境破坏 + 反应 | 12-20s | 3-4 个 |
| 双人对轰（法术互撞） | 12-30s | 4-6 个 |

**动作时间基准**：蓄力/凝结 1.5-3s · 粒子爆发/冲击波 1-2s · 环境破坏 1.5-3s · 变身/形态变化 1.5-3s
