这是什么？

这是 MiniMax 官方在 GitHub 开源的 Skills 技能包，配合 MiniMax H3 视频生成模型使用。每个 Skill 都是一套经过官方调优的提示词工程流程——你只需要用大白话描述创意，Skill 会自动完成卖点提炼、分镜规划、节拍设计、音画同步等专业工作，输出可直接喂给视频模型的标准化提示词。

核心亮点：① 官方出品、持续维护；② 8 个风格类 Skill 内置中文版说明（SKILL.cn.md）；③ 支持 T2VA / I2VA / FL2VA / L2VA / Ref2VA 五种 H3 生成模式。

核心：H3 提示词编写器

H3 提示词编写器

h3-prompt-writing
提示词工程仅英文
H3 模型的「翻译官」。把多模态请求改写为 H3 标准提示词结构（integrated_multimodal_description / overall_soundscape / non_diegetic_music），支持文生视频、图生视频、首尾帧、尾帧反推、全参考五种模式，自动对齐关键帧并定义图/视/音引用标签。
这样说就能触发
“用 H3 写一个猫咪在雨天窗台的视频提示词” · “帮我把这段创意转成 Ref2VA 格式”

3D 动画短片生成器

动画v0.5.4
从一个故事创意出发，走完完整制作流程：项目简报 → 故事大纲 → 角色与环境卡片 → 标准化分镜 → 故事板 → 逐镜头生成 → 合成 → BGM 匹配 → 终审。强调角色一致性与场景连续性，适合端到端叙事动画。
这样说就能触发

不适合：单张图片、简单剪辑、真人写实风格。

安装方法

下载分享包并解压，得到 9 个 skill 文件夹。
把整个文件夹复制到 AI 助手的 skills 目录（WorkBuddy 用户复制到 C:\Users\你的用户名\.workbuddy\skills\）。
开启新会话，直接用大白话描述需求即可自动触发对应 Skill。
官方安装方式：也可以通过 skills CLI 一键安装全部——
npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --skill '*'

使用小贴士

中英双语：8 个风格类 Skill 自带中文版说明（SKILL.cn.md），中文提问也能正常工作；仅「H3 提示词编写器」目前只有英文版，但它输出的提示词本就需要英文。
确认机制：多个 Skill 采用「先出预览 → 你确认 → 再生成」的两步流程，看到预览图后记得回复确认意见，成品质量会明显更好。
持续更新：官方仍在积极维护（WIP），想获取最新版本可访问 GitHub 仓库重新拉取覆盖。
