# 剧本转 MiniMax H3 分段视频提示词生成器（全自动化）

## 用途

把用户提供的**完整剧本 + 人物参考图**全自动切分为 5–15 秒的独立段落，为每段生成可直接粘贴进 MiniMax H3 视频生成工具的分段提示词。每段是独立可生成的完整短视频提示词，段间通过「气闸缓冲法」保证串联不崩坏。

## 运行模式

- **全自动模式（默认）**：用户提供剧本后，**一气呵成跑完全流程**——解析 → 切分 → 编写 → 校验 → 交付 TXT + HTML，中途不停下、不等待确认。适合批量生产与流水线串联。
- **确认模式（按需）**：仅当用户明确要求「先给我看切分方案」「切分后再确认」时，才在切分后暂停等待确认。默认不触发。

## 输入要求

### 硬约束（缺失必须索取，否则无法开工）
**剧本正文**，须包含：
- 总时长（如 30 秒）
- 风格设定（视觉风格、节奏、BGM 说明）
- 场景描述（地点、环境、氛围）
- 人物设定（每个人物的名字、身份、外貌描述、性格标签）
- BGM 说明（演进逻辑，如：前期轻蔑 SFX → 8 秒处切入 Trap 重低音）
- 画面与台词分解表（按时间区间标注画面描述、画外音、台词、剧情走向）

### 软约束（尽力获取，缺失时自动兜底，不打断流程）
- **人物参考图**：每个主要出场人物一张，标注为 `<Picture N>`。缺图时，用剧本中的人物外貌文字描述建档继续，并在交付时提示「未提供参考图，已按文字设定，建议补图增强一致性」。
- **时间区间标注**：若剧本缺「画面与台词分解表」的时间区间，**自动**根据台词量与叙事节拍补齐切分方案并直接生成，不等待确认。

## 工作流程（全自动，无人工确认）

按顺序一口气执行，每步的详细规范见对应 references 文件：

1. **解析输入**：提取总时长、场景、人物清单（外貌词汇原文建档，后续逐字复用）、BGM 时间轴、台词归属。
2. **自动切分**：按 `references/01-splitting-rules.md` 执行——以剧本标注的时间区间为基准，单段 5–15 秒，BGM 爆点优先，双人同框不腰斩，剧情密度随段长动态调整。**直接确定段数、段长与每段成片时间区间，随即进入编写，不停下确认。**
3. **逐段编写**：按 `references/02-output-format.md` 的格式规范逐段撰写 `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music` 三个必需字段；段标题 + `& 时长整数 &` 行缺一不可。写法对齐 MiniMax 官方 `h3-prompt-writing` skill 的规范要点（说话人身份短语放 `<d>` 外、复合 ID、`<scenetrans>`/`<cutoff>`、BGM 不用抽象情绪词等），见 `references/05-review-loop.md` 末节对照表。
4. **跨段一致性校验**：按 `references/03-consistency-airlock.md` 检查人物外观锚定、Speaker ID 全局统一、BGM 跨段演化、画外音人物，以及除首段外每段开头 2 秒的「气闸缓冲法」。
5. **双视角审核与打回重写循环**（V1.3 新增，必经关卡）：按 `references/05-review-loop.md` 对每段依次执行**导演视角**（道具状态连续、动作归属无歧义、相似物品区分、一次性动作链、状态跳变有交代、切点引入新信息、空间动线）→ **观众视角**（谁在做什么一看便知、状态突变不出戏、爆点清晰、台词对得上人）→ **音画同步**（口型约束、声源可见性、BGM 爆点对位、声事件不叠加）三道审核。发现 P0/P1 问题即打回该段重写，重写后**重新走完三道审核**，循环直到全部段落通过。审核未通过不得交付。
6. **自检后交付**：对照 `references/04-example-checklist.md` 的自检清单逐项确认，生成 TXT + HTML 双文件 + **审核结论摘要**（每段：通过 / 打回原因 → 修复说明），用 present_files 交付。

## 输出契约

- **正文格式**：段间用单独一行 `===` 分隔（前后各空一行），最后一段末尾无 `===`；每段结构为「段标题行 → `& 时长整数 &` 行 → 三个字段」。
- **逻辑铁律**（V1.3）：动作归属必须无歧义（谁的物品、谁的手在动）；道具状态段内连续、跨段跳变必须重新确立；相似物品（盖头 vs 纱巾）分别锚定归属；前置动作与开口说话分时序。违反即被审核打回。
- **语言**：画面描述、音效、BGM 全部用英文；台词保留原文用 `<d>[语言] ...</d>` 包裹；场内可见文字用英文双引号包裹并保留原文。
- **交付双文件**（铁律，不可省略其一）：
  1. 同名 `.txt` 纯文本版——仅含提示词原文（段标题 + 时长行 + 三字段 + `===` 分隔符），可直接整段复制进 H3；
  2. 同名 `.html` 排版版——每段一张卡片，含成片时间区间、时长、三字段高亮排版、一键复制按钮，移动端可读。
- 两个文件放入当前项目文件夹，完成后用 present_files 交付，并附审核结论摘要。
