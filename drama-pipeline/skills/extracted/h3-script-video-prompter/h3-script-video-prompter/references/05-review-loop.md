# 05 · 双视角审核与打回重写循环（V1.3 新增）

> 逐段编写完成后、交付之前，**必须**经过本审核循环。任何一段未通过审核即打回重写，重写后重新进入审核，**循环直到全部段落通过**才允许交付。跳过本步骤 = 交付无效。

## 审核顺序与角色

对每一段提示词依次执行三道审核，全部通过该段才算过审：

1. **导演视角**（现场可执行性）
2. **观众视角**（看片可理解性）
3. **音画同步**（声画对位正确性）

三道审核任一发现 P0/P1 级问题 → 该段打回，按「打回重写规则」修改后**重新走完三道审核**。

## 一、导演视角审核清单

以"这段提示词交给真人剧组/生成模型能否无歧义执行"为标准：

- [ ] **道具状态连续**：同一道具在同一段内的开/合、折/展、在桌/在手、完好/破损状态不得自相矛盾（典型翻车：前文"文件已展开在案上"，后文又"他缓缓展开它"）。道具从一个状态变到另一个状态，必须有明确的动作交代。
- [ ] **动作归属无歧义**：每个动作的主语和宾语必须清晰。当一句话里同时出现两个人物和一件贴身物品（如盖头、面纱、披风），必须明确该物品**戴在谁身上、由谁的手取下/盖上**。禁止把 A 的物品挂在 B 的长外貌描述之后，让模型误读为 B 持有/佩戴。
- [ ] **相似物品区分**：同段出现两种易混淆物品（如新娘红盖头 vs 新郎红纱软巾）时，必须分别锚定归属（"her red bridal veil covering her head" / "a red gauze scarf draped over his shoulder"），必要时显式排除（"distinct from her veil"）。
- [ ] **一次性动作链**：一个人在同一时刻只能做一件主责动作。咳嗽、转身、递物等前置动作必须与开口说话**分时序**描述（先"给出一声克制的咳嗽"，再"随即开口"），禁止边咳边说、边转身边念台词的叠加表述。
- [ ] **跨段状态跳变有交代**：若人物/道具状态在相邻两段间发生变化（盖头从"未戴"到"戴在头上"、服装更换、时间跳转），后段开场必须以画面语言重新确立新状态，不得默认观众已知。
- [ ] **切点引入新信息**：每次 `the camera cuts to` 必须切换景别/视点/主体/时间之一；若只是距离微调应改用镜头运动而非切镜。切镜时间戳严格递增且落在段时长内。
- [ ] **空间动线合理**：人物位置（门/桌/床/屏风）、走位方向、物件落点在段内自洽，不出现瞬移或穿模式描述。

## 二、观众视角审核清单

以"第一次看这段视频的观众能否看懂"为标准：

- [ ] **谁在做什么一看便知**：观众不会读提示词，画面必须自己讲清楚动作归属。若提示词的字面结构可能让模型生成"错误的人在执行动作"（如生成出男人盖着盖头），即 P0 打回。
- [ ] **状态突变不令观众困惑**：上一段结尾与下一段开头的道具/人物状态衔接，观众能靠画面自然理解（如时间跳转后新娘已盖上盖头属婚俗常识，可接受；但文件先展开后又展开会让观众出戏，不可接受）。
- [ ] **悬念/爆点清晰**：爆点段的核心视觉事件（揭盖头、逼宫、焚书）是本段最明确的画面焦点，不被次要动作稀释。
- [ ] **台词与说话人对得上**：每句台词观众都能从画面确认说话人（出镜开口者口型同步；画外音期间画面人物嘴唇闭合）。

## 三、音画同步审核清单

- [ ] **口型约束**：所有画外音 `<d>` 块后紧跟 `lips remain completely closed` 类声明；角色实开口段有口型动作描述。
- [ ] **每段音色锚齐全**：每个说话者在**每一段内的第一次开口**都带完整音色描述 + `(S#)` + `own on-screen character voice` / `off-screen voiceover`（H3 段间无记忆，缺锚会导致声线错配、台词错乱）。全片抽查：逐段 grep 每个开口角色的第一句，确认没有 `says; his/her voice (S#):` 这类省略音色的变体。
- [ ] **Speaker ID 全片恒定**：同一人物在所有段的 ID 一致（旁白恒 S1 等），无段内重新编号。
- [ ] **声源可见性**：描述的每个音效在画面中有对应来源或符合画外空间逻辑（门外喊话来自门的方向、轿外脚步声闷）。
- [ ] **BGM 爆点对位**：剧本标注的 BGM 爆点时刻与画面动作（首帧冲击/关键动作）一一对齐；`non_diegetic_music` 中的时间点与 `integrated_multimodal_description` 中的切镜/动作时间点不冲突。
- [ ] **同一时刻不叠加冲突声事件**：同一段时间轴上的声音事件（咳嗽、说话、音效）时序化排布，不重叠冲突。

## 问题分级

- **P0（必须打回）**：动作归属歧义（错误人物执行关键动作）、道具状态自相矛盾、音画对位错误（旁白配口型/爆点错位）、角色外观与锚定档案不符。
- **P1（必须打回）**：状态跳变无交代、边做复杂动作边说话、切点无新信息、声源无着落。
- **P2（顺手修复）**：措辞冗余、情绪形容词堆砌、次要细节欠精确。P2 可当场修掉，不打回。

## 打回重写规则

1. 打回时**只重写被点名的段落**，其他段落不动；但重写若改变段尾构图/道具状态，必须同步检查下一段的气闸缓冲描述并联动修正。
2. 重写遵循 `02-output-format.md` 全部格式规范，且保持 Speaker ID、外观锚定词、BGM 衔接关系与全片一致。
3. 重写后该段**重新从导演视角开始走三道审核**，不得只补审出问题的那一道。
4. 交付物中需附**审核结论摘要**（每段：通过 / 打回原因 → 修复说明），供用户复核。

## 参考：MiniMax 官方 h3-prompt-writing 规范要点（生成与审核时对照）

- 三字段顺序与名称固定：`integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music`。
- 说话人身份短语、ID、动作、语气一律放在 `<d>` **之外**；`<d>` 内只有语言标签和逐字原文。
- 多人同说用复合 ID（如 `(S1,S2)`）；不发声的角色不分配 ID；同一说话人跨镜头跨段 ID 恒定。
- 台词跨切镜用 `<scenetrans>` 并声明音频跨切镜连续；被片尾截断用 `<cutoff>`。
- 普通切镜用 `the camera cuts to / transitions to / switches to`；仅景别微调优先用镜头运动而非切镜。
- 场内可见文字用英文双引号包裹原文，逐字保留。
- `overall_soundscape`：1–4 句连续段落，只写环境音/物理动作音/非语言人声，不重复台词。
- `non_diegetic_music`：只写乐器、速度、节奏、动态变化，**不用抽象情绪词、不解释配乐的情感功能**（"tense and mournful" ❌ → "erhu sustained bow against plucked guzheng at a moderate tempo" ✅）。
- 每个细节都必须对应画面可见或耳朵可听的内容，不写剧情梗概式总结。
