# 03 · 跨段一致性规则与气闸缓冲法

## 人物外观锚定

- 每段首次出现人物时，必须用**与用户提供的人物设定一致的词汇**描述外观。不得用同义词替换（用户说「银发」就不用「白发」，「灰色 T 恤」就不用「浅灰上衣」）。
- 每段人物描述顺序保持一致：头发 → 脸型（可选）→ 上装 → 下装 → 鞋履 → 配饰 → 体态/神情。

## Speaker ID 连续性（跨镜头全局统一）

> ⚠️ 重要：早期版本曾错误写成「每段独立编号、段间不共享 ID」，这会让旁白（女声）与女主（同为年轻女声）的 Speaker ID 撞车，导致 H3 把旁白直接分配给女主、让她动唇念出画外音。**必须按 H3 官方规范全局统一：**

- **全片唯一且固定**：`(S1)`、`(S2)`、`(S3)`… 每人一个，跨所有镜头与段落恒定不变，绝不按段重置。
- 常见分配：旁白 = `(S1)`、女主 = `(S2)`、男主 = `(S3)`。即使某角色在段1不发一声、段3才开口，其 ID 仍为 `(S2)`。
- 旁白与同性别角色必须靠**音色描述差异**区分（旁白偏沉稳讲述感、角色偏鲜活本色声），并配合下方画外音规则锁定口唇状态。

## BGM 跨段演化

- 每段的 `non_diegetic_music` 必须说明与上一段的衔接关系。
- 若剧本规定了 BGM 切换时间点（如 0:08），则切点前后两段的 BGM 必须分别描述「延续旧 BGM → 切换」和「新 BGM 开局」。

## 画外音人物

- 若某人物全程为画外音、不出镜（如大堂经理），则在每段中都标注 `off-screen`，且永远不描述其外貌。

## 气闸缓冲法（The Airlock）— 串联片段防崩坏

串联片段时，提示词的编写逻辑必须改变，否则会导致画面崩坏：

**模型是叠加而非替换**：如果上一个片段结束时是大特写，下一个片段提示词直接写"两人全景"，模型不会切镜头，而是会把两个画面杂糅（Union）在一起。

**"气闸"缓冲法（The Airlock）**：

1. **不要在同一时刻要求延续和改变**：新片段的开头应保持上一片段的精确构图约 2 秒钟（无对话），然后再切入新场景。
2. **保持微小运动**：不要让缓冲期的演员完全静止，否则画面看起来像卡顿。在提示词中加入"呼吸、重心转移、视线改变"等微小动作，让相机保持静止而演员在动。

## 分隔符规则

- 每两段提示词之间用单独一行 `===` 分隔。
- 最后一段末尾不额外加分隔符。
- `===` 前后各空一行。
