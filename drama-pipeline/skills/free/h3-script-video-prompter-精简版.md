# 剧本转 H3 分段视频提示词生成器 · 精简版

> **一句话定位**：把完整剧本 + 人物参考图**全自动**切分成 5–15 秒的独立段落，每段生成可直接粘贴进 MiniMax H3 的提示词，段间用「气闸缓冲法」保证串联不崩坏，一次交付五份文件。
>
> 本文件为**免费分享的精简版**（约完整版 1/4）。完整版（会员）含：7 份 references 全文（切分规则/输出格式/一致性气闸/示例自检/审核循环/定妆照/参考图绑定协议）、`h3_run_segment.py` 双模式循环脚本。

---

## 一、运行模式

- **全自动模式（默认）** — 用户提供剧本后一气呵成跑完全流程（解析 → 切分 → 编写 → 校验 → 交付），**中途不停下、不等待确认**。适合批量生产与流水线串联。
- **确认模式（按需）** — 仅当用户明确要求「先给我看切分方案」时才暂停。

---

## 二、输入要求

### 硬约束（缺失必须索取，否则无法开工）
剧本正文须包含：① 总时长 ② 风格设定 ③ 场景描述 ④ 人物设定（名字/身份/外貌描述/性格标签）⑤ BGM 说明（演进逻辑，如"前期轻蔑 SFX → 8 秒处切入 Trap 重低音"）⑥ 画面与台词分解表（按时间区间标注）。

### 软约束（缺失自动兜底，不打断流程）
- **人物参考图**：每个主要出场人物一张，标注 `<Picture N>`。缺图时用文字外貌建档继续，交付时提示"建议补图增强一致性"。
- **时间区间标注**：缺失时**自动**按台词量与叙事节拍补齐切分方案并直接生成。

## 三、七步工作流程

**1 · 解析输入与主角判定** — 提取总时长、场景、人物清单（**外貌词汇原文建档，后续逐字复用**）、BGM 时间轴、台词归属；自动判定主要角色（驱动剧情、反复出场、有专属外貌设定者），数量 **3–8 人且 ≤ H3 的 9 张参考图上限**。

**2 · 自动切分** — 以剧本标注的时间区间为基准，单段 **5–15 秒**，BGM 爆点优先，双人同框不腰斩，剧情密度随段长动态调整。直接确定段数/段长/成片时间区间，**不停下确认**。

**3 · 逐段编写** — 每段三个必需字段：

| 字段 | 内容 |
|---|---|
| `integrated_multimodal_description` | 多模态画面描述（八项写法规范） |
| `overall_soundscape` | 整体音效 |
| `non_diegetic_music` | 非叙事性音乐（无则 `N/A`） |

段标题 + `& 时长整数 &` 行缺一不可。

**3.5 · 同步生成主角定妆照 + 参考图绑定** — 为每个主要角色生成 3D 国漫风格正面半身定妆照提示词（中文 + English + Negative + 对齐说明），**外观字符串原样复用分段里的 canonical 外貌短语**；同时在每段 `& 时长 &` 行后写入【本段参考图】纯编号块，并在 `integrated_multimodal_description` 顶部注入 `Reference Image N = identity of X` 角色声明。

> 🔴 **V1.9 关键修正**：图片一次性固定上传到 `@image#1~#5` 后**槽位全局不变**，每段只用全局固定图号「选用」对应角色，**严禁每段从 1 重编号**。

**4 · 跨段一致性校验** — 人物外观锚定、Speaker ID 全局统一、BGM 跨段演化、画外音人物，以及**除首段外每段开头 2 秒的「气闸缓冲法」**。

**5 · 双视角审核 + 打回重写循环（必经关卡）** — 每段依次过三道审核：

| 视角 | 查什么 |
|---|---|
| **导演视角** | 道具状态连续、动作归属无歧义、相似物品区分、一次性动作链、状态跳变有交代、切点引入新信息、空间动线 |
| **观众视角** | 谁在做什么一看便知、状态突变不出戏、爆点清晰、台词对得上人 |
| **音画同步** | 口型约束、声源可见性、BGM 爆点对位、声事件不叠加 |

发现 P0/P1 问题即打回该段重写，重写后**重新走完三道审核**，循环直到全部通过。审核未通过不得交付。

**6 · 自检后交付** — 五份文件 + 审核结论摘要（每段：通过 / 打回原因 → 修复说明）。

## 四、输出契约

### 正文格式
段间用单独一行 `===` 分隔（前后各空一行），最后一段末尾无 `===`。每段结构：

```
段标题行
& 时长整数 &
【本段参考图】Image #N → 角色名
integrated_multimodal_description ...
overall_soundscape ...
non_diegetic_music ...
```

### 🔴 逻辑铁律（V1.3）
- **动作归属必须无歧义**（谁的物品、谁的手在动）
- **道具状态段内连续，跨段跳变必须重新确立**
- **相似物品分别锚定归属**（盖头 vs 纱巾）
- **前置动作与开口说话分时序**
- 违反即被审核打回

### 语言
画面描述、音效、BGM 全部**英文**；台词保留原文用 `<d>[语言] ...</d>` 包裹；场内可见文字用英文双引号包裹并保留原文。

### 五份交付文件（缺一不可）
1. 同名 `.txt` — 纯文本分段提示词，可直接整段复制进 H3
2. 同名 `.html` — 每段一张卡片，含时间区间/时长/三字段高亮/一键复制按钮/参考图绑定面板
3. `主角定妆照提示词_N人.txt` — 每个主要角色一张（中文/English/Negative/对齐说明）
4. `cast_manifest.json` — 角色 ID → Image #N 编号的**单一真值表**（`cloud_workflow_mode` / `image_order` / `segment_refs`）
5. `h3_run_segment.py` — V2 双模式循环脚本：默认**云模式**（零文件读取，输出角色声明 + `Image #N ↔ @image#X` 映射）；加 `--local` 切本地模式（读 PNG→base64→拼 H3 请求，可 `--submit` 直交）

## 五、关键设计：气闸缓冲法

**除首段外，每段开头 2 秒是"气闸"** —— 不立刻进入新动作，而是承接上一段的结束状态（人物位置、姿态、道具状态、光线），让观众有 2 秒重新建立空间感，再推进新内容。

**为什么必要**：H3 每段独立生成，若段首直接跳到新动作，串联播放时会出现"瞬移感"和状态断层。气闸用 2 秒换取整片连贯。
