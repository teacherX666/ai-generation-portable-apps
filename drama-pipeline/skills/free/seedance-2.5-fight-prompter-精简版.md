# Seedance 2.5 打斗/特效提示词生成器 · 精简版

> **一句话定位**：不管输入是创意、剧本还是小说，自动产出可直接喂给 **Seedance 2.5** 的工业级打斗分镜脚本 —— 时间戳钉死每一拍、单段 4-30s、超长 180s。
>
> 本文件为**免费分享的精简版**（约完整版 1/4）。完整版（会员）含：T1-T7 题材动作簇速查全文、五种压力曲线详表、镜头策略矩阵、时间测算表模板、案例库与进化日志。

## 一、2.5 相对 2.0 的关键能力跃迁

| 能力 | Seedance 2.0 | **Seedance 2.5** |
|---|---|---|
| 单段时长 | 10-15s | **[4, 30]s**（打斗建议 12-30s） |
| 超长打斗 | 不支持 | **30-180s 一次生成** |
| 视频延长 | 不支持 | **4-30s/次，套娃至最长 60s** |
| 时间戳控制 | 隐式描述 | **文本精准指定秒数**（`0-3秒：冲刺压近 / 3-7秒：连续交手`） |
| 参考素材 | 图片为主 | **图片≤30 / 视频≤10 / 音频≤10** |
| 音色参考 | 无 | **@音频 复刻吼叫/喘息/打斗台词音色** |
| 多人参考 | 易双胞胎 | **多人同框分别 @图片 锁定，防长相趋同** |
| 动作/白模 | 无 | **@视频 白模控制动作迁移** |
| 智能编辑 | 无 | **改已生成视频**（换武器/换服装/改速度/去失误动作） |
| 负向去杂质 | 靠禁止项 | **默认补「不要字幕、不要BGM」** |

## 二、系统架构

```
输入解析层 → 题材结构判定 → 动作设计引擎 → 2.5公式封装 → 输出规范化 → 案例归档与进化
  4级输入判断    T1-T7题材    压力曲线+       素材描述+      时间戳分镜     ✅ 案例库更新
  首尾帧思维     A/B/C结构    动作簇库+      一句话概述+    双版本输出      ✅ 反思改进
                             6变量因果链    时间戳分镜     +HTML+TXT
                             镜头策略      全局补充
```

### 四级输入判断

| Level | 类型 | 处理策略 |
|---|---|---|
| **L1 创意** | 一句话想法 | 补全题材、场景、角色、3-4 个核心动作节点 |
| **L2 剧本** | 有角色+对抗设定 | 直接生成完整 prompt，补全外观锚点、武器、场景、动作链和结尾 |
| **L3 小说** | 长篇叙事中的打斗段落 | **三步处理**：① 抽骨架（胜负结果、关键转折）② 去修辞（删"气势如虹""天地变色"等不可拍内容）③ 建奇观（选 2-3 个最具视觉冲击力的画面作锚点）。**不逐句翻译** |
| **L4 锁定分镜** | 有时间码/动作链/镜头表 | 剧情结果、动作顺序、视觉锚点、出口都是**硬约束**，只补衔接和物理反馈 |

**L4 锁定动作卡**（内部，不输出）：场景容器 / 角色与能力 / 4-6 个锁定动作节点 / 中段关键结果 / 单元出口 / 禁止新增。锁定外内容只能作微动作、环境余波、镜头遮挡或音效处理，**不得改变动作结果**。

## 三、输出格式（11 字段灵魂 + 官方公式融合版）

```
【整体风格】
整体风格: [调性词1 + 调性词2 + 调性词3],
[特效/速度/力量] 通过 [具体物理现象A]、[具体物理现象B] 呈现,
不出现 [跨题材污染词]。
主体清晰可读优先于特效, 动作不断流, 命中不定格,
中段镜头稳定跟随, 高帧率流畅。

【素材描述】（2.5 多模态）
@图片1 = [主角人物]；@图片2 = [对手人物]；@图片3 = [场景]；
@视频4 = [动作/白模参考]；@音频5 = [音色/氛围音参考]（无则写「无」）
多人同框时分别 @图片 锁定各自长相，防双胞胎。

【一句话概述】
[主体 + 地点 + 事件 + 题材/风格 + 特殊运镜]，单段 [X] 秒。

【时间戳剧本分镜】（核心）
0-2秒：[起幅] 开场画面 + 第一威胁，建立空间关系和压力方向
2-7秒：[过程节点1] 动作→对手反应→环境反馈→镜头反馈→衔接
7-12秒：[过程节点2] ...
12-18秒：[过程节点3] ...
18-24秒：[过程节点4] ...
24-30秒：[结尾] 终段动作 + 结果爆发 + 空间位置，不写慢收势

【特效细节】
[仅 T2/T4/T5/T6/T7 使用。约束：能量只沿武器/碰撞点/攻击轨迹，粒子不遮主体]

【音效】
[10-14 个音效，逗号分隔，只取本题材声音]

【全局补充】
[机位 + 环境 + 整体声音/氛围 + 光影；负向再强调：不要字幕、不要BGM、不要水印、不要Logo、不要可读文字]

【强制声明】
无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

### 字段硬规则
- 【整体风格】必须保留 `整体风格:` 开头
- 【素材描述】按上传顺序编号并写明每个素材用途；无素材写「无」
- 【时间戳剧本分镜】是 2.5 核心，**每个攻防节点必须用时间戳钉死秒数** —— 不用时间戳 = 没用上 2.5 能力
- 【角色卡】并入素材描述或分镜首段，必须 `- @图片1作为...` 格式说明**动作倾向**，即使用户没图也先占位
- 【特效细节】纯写实近战（T1/T3）可省略
- 【强制声明】原样输出，不改写

### 字数控制
目标 **1200-1500 字**，硬上限 1800，下限 1100（30s 超长可到 2200）。
压缩优先级：删修辞 → 删重复运镜 → 删低价值环境细节 → 合并角色描述。
**不删**：6 变量因果链、时间戳、题材一致性、末尾固定项。

## 四、动作设计引擎

### 6 变量因果链（每个命中点必写）

```
[打击者] 用 [载体: 拳脚/兵器/特效] 击中 [对手具体位置]
→ [受击反应] → [环境响应] → [镜头反馈] → [下一招衔接]
```

✗ 禁止写法：`两人激烈打斗`（无具体动作）、`女主快速反击`（无部位方式）、`敌人被击退`（无方式和环境反馈）

### 压力曲线（选 1 条，决定"起伏呼吸"）

| 曲线 | 适用 | 局势变化 |
|---|---|---|
| 压迫递增 | 强者逼弱者 | 还能躲→勉强挡→被逼退→空间封死→终段命中 |
| 反制失败 | 弱者有求生但力量差 | 被压制→短暂反击→对手硬吃→夺回→败退 |
| 诱敌反打 | 主角冷静技巧高 | 退让→暴露破绽→借位闪开→反打关键点 |
| 波峰波谷 | 双方实力接近 | A压制→B反压→A改招→B受挫→终段定局 |
| 蓄力爆点 | 变身/大招 | 低压铺垫→层层蓄势→环境预兆→单次爆发→余波 |

### 连招编排四规则（内部完成，不输出）
1. **连招方向链**：切入→折返→压进→横移/纵跃→终段
2. **每拍动作因果**：方向变化→招式载体→命中位置→接触点物理→身体/环境后果→衔接
3. **镜头贴附动作**：镜头贴住具体动作路径，说明被什么遮挡、如何接到下一招
4. **装饰词物理化**：抽象强度词 → 具体载体 + 接触点物理现象 + 身体/环境后果

### 角色卡规范
角色卡**不是外貌作文，是告诉模型动作偏好**：
```
- @图片1作为女主: 动作偏低扫、侧踢、快速步法、短促肘击，本段处于被压制后寻找脱身机会。
```
✗ 反面：「她很美，眼神坚定，气质冷艳，身材修长。」—— 不服务动作。

### 音效从画面提取
先写画面，再回头"听"画面：拳脚→闷响、格挡→格挡声、脚步→摩擦/踩水、环境→雨滴/霓虹/风声、特效→电弧/粒子/灵气（仅对应题材）。

## 五、双版本 + 自动交付

每个 prompt 段都输出：
- **多模态版** — 用 `@图片1/@视频2/@音频3` 占位，含素材描述
- **纯文字版** — 无 @ 引用，可直接复制到 Seedance 2.5

完成后必须同步输出：
- `seedance25-[风格简称]-prompts.html` — 移动端优先深色主题发布页
- `seedance25-[风格简称]-prompts.txt` — 纯文本，用 ═══ 分隔各组
