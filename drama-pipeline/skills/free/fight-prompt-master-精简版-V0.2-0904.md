## 固定选择卡（8 项，前期选项已固化）

| # | 选择项 | 选项 | 默认值 |
|---|-------|------|--------|
| 1 | 输入素材 | 文字/角色图/场景图/首帧/首尾帧/分镜/动作参考视频/运镜参考视频 | 自动判断 |
| 2 | 生成方式 | 文生 / 图生 / 参考生 | 有图→参考生，无图→文生 |
| 3 | 模型 | SD2.0 / **SD2.5** / H3 | SD2.5 |
| 4 | 时长 | 默认15秒 | 15s |
| 5 | 速度档位 | **标准版 / 极速版**（独立于强度的一轴） | 标准版 |
| 6 | 强度方案 | 高强度 / 中间型 / 慢节奏 | 默认三套全出供三选一 |
| 7 | 胜负结果 | 决出 / 指定赢家 / 平局 | 决出胜者 |
| 8 | 画幅 | 16:9 / 9:16 / 1:1 | 16:9 |

用户已给的参数不重复问；只补问会显著改变结构的缺失项（模型/时长/速度档位各补问一次）。

**极速版硬规则**：时间颗粒更短（15秒从约4段改为5-6段、每段2-3s）；微动作+30-40%；起手0.15s内；特写0.4-0.8s；默认不用慢动作；不用无来源闪切堆密度。

## 统一导演管线（9 步）

选择卡 → 素材职责拆分 → 动作设计表+角色档案 → 结构骨架 → 因果编排 → 时长分配 → 三套强度×速度档 → 镜头设计 → **模型引擎封装**。

- **素材职责**：角色图锁身份、场景图锁空间、首帧锁起点、首尾帧写因果、分镜按序读取、动作视频只继承轨迹、运镜视频只继承机位
- **动作设计表8项**：完成条件/角色差异/空间轴线/资源/主动权变化/连续状态/结束画面/速度档位
- **角色档案8项**：优势距离/起手姿态/移动方式/主要攻击/防守反制/武器资源/力量节奏/结束方式
- **时长分配**：4-8s一个闭环 / 9-18s四五阶段 / 19-30s五到七段中段一次反转

## 核心原理 · 导演三层铁律

1. **一攻一应（最重要）**：每拍6项——谁发起→打哪→接触/格挡/落空→回应→位置变化→下一拍接口。
2. **组合拳公式**：预兆→加速→接触点→材质变化→受力方向→位移结果→余波。坏写法"重重一拳"；好写法"拳头撞上前臂，镜头短震一次，对方肩膀向右后方偏转，鞋底擦积水滑出半步"。
3. **连续性锁定**：武器唯一、数量不增减、破坏不复原、资源弹药连续；切镜只换观看位置，不重置事件。

**镜头句式6项**：景别/机位高度角度/速度/方向/跟随对象/本镜职责。8职责：建立空间、追随位移、看清接触、表达反制、表达失衡、展示弹道、揭示结果、稳定收尾。

## 七种结构骨架

单人突围 / 双人攻防 / 远程能量对抗 / 一人对多人（1-2人活跃）/ 人兽对决 / 单人演武 / 风格化材质动作。每类5步骨架，骨架只组织战局（怎么移动/怎么防守/怎么结束）。

## 三套强度方案

高强度（交锋密集，匹配切为主）/ 中间型（交锋与特写交替）/ 慢节奏（发力完整，长镜头，过程最完整）。三套共享角色身份、武器数量、能力边界、场景规则，攻防顺序与结束路径分别设计。速度档位同时作用于三套，不新增第四套。

## 模型优化速查

| 模型 | 时间格式 | 优化要点 |
|---|---|---|
| SD2.0 | 整秒粗时间段 | 11字段；标准4段3-4s/极速5-6段2-3s |
| SD2.5 | 文本时间戳钉死每拍 | 素材描述@引用+负向"不要字幕BGM"；单段4-30s、超长30-180s、延长至60s |
| H3 | 精确时间码首尾相接 | 英文六段式；15s=4-5镜（极速略增）；多参一致性最强 |

## 失败排错 · 单变量法

每轮只改**动作 / 镜头 / 参考素材**中的一类变量：
各打各的→补一攻一应；接触不清→侧向中景；左右互换→固定轴线；武器复制→素材变量+唯一声明；损伤复原→后续时段重复记录；特效无来源→绑定接触点。连续两轮无改善→重查变量归属。
