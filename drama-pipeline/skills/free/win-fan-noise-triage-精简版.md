# Windows 风扇异响排查与快速降温 · 精简版

> **一句话定位**：不靠猜、不靠"关一堆进程试试"，用 30 秒采样数据把风扇狂转的病因分成三类，只做对症且可完全还原的处置。
>
> 本文件为**免费分享的精简版**（约完整版 1/3）。完整版（会员）含：完整 PowerShell 采集脚本、清理清单 playbook、环境坑详解、`风扇排查与优化记录.md` 模板。

---

## 一、它解决什么问题

"风扇一直转"是个**症状**，不是病因。三类病因的处置方式完全不同，判断错了就白忙一场：

- 有人关了一堆进程，风扇照转 —— 最后发现是硅脂干了。
- 有人去清灰换硅脂，其实只是某个更新器在后台唤醒 CPU。

这个技能的价值：**先分诊，再动手**。

---

## 二、三类病因分诊表

| 病因 | 数据特征 | 处置方向 |
|---|---|---|
| **A 持续高负载** | CPU 采样均值 **> 30%** | 抓出高占用进程，关掉或限制 |
| **B 后台唤醒** | CPU 很闲（**< 10%**）但**间歇性**转 | 查 `powercfg /requests`，清常驻 + 更新器 + 自启动 |
| **C 散热硬件故障** | CPU 极闲（**< 5%**）**仍持续**狂转 | 与软件无关 — 开箱清灰 / 换硅脂，如实告知 |

> **铁律：绝对不要一上来就杀进程。**

## 三、铁律与工作流

### 铁律
1. **先分诊，再动手** — 采样数据说话，不凭用户描述猜。
2. **用户只说一句"风扇一直转"时走极速模式** — 自动采集 → 自动执行安全清单 → 只在遇到"需确认类"应用时才回头问。不要为了问而问。
3. **每次改动都要留下可逆路径**。

### 工作流（4 步）

**Step 0 · 采集（30 秒内，并行执行）**

Bash 侧：
```bash
typeperf "\Processor(_Total)\% Processor Time" -sc 3   # CPU 采样 3 次
nvidia-smi --query-gpu=temperature.gpu,utilization.gpu,fan.speed --format=csv
powercfg /requests      # 关键：谁在阻止系统睡眠
powercfg /waketimers
```

PowerShell 侧采集 5 组数据：① 系统概况（CPU 型号/核心数/LastBootUpTime/内存）② 进程 CPU 累计耗时 Top 30 ③ 内存占用 Top 25（含完整路径）④ 同名进程聚合 Top 25 ⑤ 自启动项 + 第三方服务 + 已启用计划任务。

**Step 1 · 分诊** — 按上表三类判定。

**Step 2 · 问诊**（极速模式可跳过）
1. 风扇时机：开机十几分钟就安静 / 一直转 / 间歇性转
2. 关闭范围（多选）：下载网盘类 / 远程控制保留一个 / Adobe 后台 / 其它杂项
3. 自启动：精简保留常用 / 只禁一部分 / 不动

**Step 3 · 执行（顺序不可颠倒）**
1. **先备份** — 导出 Run 项原始值到 `startup_backup.txt`，快捷方式移到 `startup_backup/`
2. 关进程 `Get-Process -Name X | Stop-Process -Force`，记录释放的内存
3. 服务改手动并停止 `Set-Service -StartupType Manual` + `Stop-Service -Force`
4. 禁用计划任务 `Disable-ScheduledTask`
5. 删注册表 Run 值 `Remove-ItemProperty`（**只删值，绝不删键**）

**Step 4 · 验证与交付**
- 复查 `powercfg /requests`（SYSTEM 应为"无"）
- 复查内存 / 进程数 / CPU 采样，给出**前后对比**
- 生成优化记录（病因结论 + 已关闭清单 + 已禁用清单 + **还原命令**）
- 明确告知：若清理后**开机 5–10 分钟内**风扇仍狂转 → 硬件散热问题

## 四、安全红线（违反即出事）

- ❌ 绝不终止系统进程：`System`、`csrss`、`lsass`、`smss`、`wininit`、`explorer`、`dwm`、`svchost`、`Memory Compression`
- ❌ 绝不动杀软与 EDR 进程/服务
- ❌ 绝不动显卡驱动容器与核显驱动任务（`StartCN` / `StartDVR`）
- ⚠️ 注册表只删 Run 下的**值**，不删键，删除前必须备份
- ⚠️ 遇到剪映 / Premiere / PS / Office / IDE 等高未保存风险应用，**先问再动**

## 五、环境坑（不知道会直接卡住）

| 坑 | 现象 | 解法 |
|---|---|---|
| PowerShell stdout 不回传 | 命令执行了但看不到输出 | 脚本写进 txt 文件，再用 Read 读回 |
| `.ps1` 被执行策略拦截 | 脚本无法运行 | 代码直接贴进工具执行，不落盘 `.ps1` |
| Bash 禁止调用 powershell | 报安全策略错误 | 用 `typeperf` / `tasklist` / `nvidia-smi` / `powercfg` 代替 |
