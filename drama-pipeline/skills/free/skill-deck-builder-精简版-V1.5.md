## 执行流程（7 步）

### 第 1 步：通读 Skill，抽内容

必须实际读 `SKILL.md` 全文 + `references/` 方法文件 + 可选 `scripts/`，提炼：是什么、解决什么问题、触发词、输入输出、硬性规范。**统计数字（"共 N 项"）必须实际清点后再引用**，不能沿用文档现成说法。

### 第 2 步：设计 12–18 屏结构

通用骨架（按 Skill 特点增删，复杂可到 20 屏、简单不少于 10 屏，**每屏只讲一件事**）：

```
01 封面 → 02 痛点 → 03 核心理念(旧VS新) → 04 全景总览 → 05 流程图
→ 06 模式/路径 → 07-08 核心详解(表格) → 09-11 王牌特性
→ 12 输出规范(含真实示例) → 13 使用流程 → 14 速查表
→ 15 文件结构 → 16 铁律/边界 → 17 结尾(一句召唤+可用的第一句话)
```

### 第 3 步：套模板

复制 `deck-template.html`，逐屏替换内容。模板已内置全部 CSS/JS：配色、背景氛围、翻页系统、7 级 stagger 入场动画、组件样式；交互含键盘 ←→/空格/滚轮/触屏、进度条、页码、圆点导航、目录面板（M）、全屏（F）、自动播放（P）。组件拼法查 `slide-patterns.md`。

### 第 4 步：自检（必须跑脚本，不肉眼赌）

```python
import re
s = open(文件路径, encoding='utf-8').read()
def eq(tag):
    return len(re.findall(r'<%s(?=[\s>])' % tag, s)) - s.count('</%s>' % tag)
print('slides:', len(re.findall(r'<section class="slide', s)))
for t in ['section','div','ul','li','table','tr','th','td','span','em','strong','b','p','h1','h2','h3','svg']:
    print('  %-8s %d' % (t, eq(t)))   # 全部必须为 0
print('CSS 花括号配平:', s.count('{') - s.count('}'))
print('span 内孤立闭合:', len(re.findall(r'<span[^>]*>[^<]*</(em|strong)>', s)))
print('data-title 数:', len(re.findall(r'data-title="([^"]*)"', s)))
```

⚠ **行内标签必须查**：曾写出 `<span ...>文字</em></span>`，div/section 配平全过，只有 em 是 -1，肉眼看不出来。另人工确认：目录标题数 == 屏数、页码一致、窄屏四列降两列。

### 第 5 步：打包 + 归档

用 Python `zipfile`（**绝不用 shell zip**，Windows 下中文名会变 GBK 乱码）：`zipfile.ZipFile(out,'w',ZIP_DEFLATED,compresslevel=9)`，打完 `testzip()` + 打印 namelist 确认中文名完好。旧版本归档到 `_legacy-V<旧版本>/`，不进新包。

### 第 6 步：用后复盘（强制，不可跳过）

交付后立刻在台账 `evolution-log.md` 最上面追加：做了什么 / 新增布局组件（类名、是否回写）/ 踩坑（现象→原因→解法）/ 下次注意 / 用户反馈原话。

### 第 7 步：登记画廊

把成品登记进 `gallery.md`：主题、屏数、用了哪些组件、亮点、待改进。

## 沉淀判定规则（复盘时对照）

| 情况 | 动作 |
|---|---|
| 手写了一个模板里没有的布局 | **必写**进 `slide-patterns.md`，命名新类名 |
| 同一自定义布局用到第 2 次 | **必写**进 `deck-template.html` CSS，成为正式组件 |
| 踩坑第 2 次 | **必写**进 SKILL.md 硬性要求 |
| 用户给了明确反馈 | **必写**进台账：正面提炼成规则、负面写成禁止项 |
| 用户主动说某版式好用 | **立即**抽进模板，判断权在用户 |

**沉淀时机由用户掌握**：不建定时自动化巡检，进化只靠"用后强制复盘 + 用户主动告知"。

## 硬性要求（防翻车核心）

1. 单文件零依赖：不引 CDN、外部字体、外部图片；图标用内联 SVG。
2. 目录标题**必须显式写 `data-title`**，JS 直接读属性——绝不用正则从标题文本剥前缀（会剥坏中文："AI 短剧"→"短剧"）。
3. 标签配平脚本用 `(?=[\s>])` 精确匹配，不要 `s.count('<div')`（会误伤 `<divider>` 之类）。
4. 深色影院视觉：三枚 blur 光晕 + 网格遮罩 + 噪点 + 暗角聚光；琥珀/青/品红/紫/绿/橙语义色。
5. 写完后重新读一遍自己的成品 HTML 再交付。
