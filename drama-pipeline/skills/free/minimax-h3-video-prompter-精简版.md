## 一、H3 是什么（理解这个才知道提示词为什么这么写）

H3 把**文本、图像、视频、音频当作同一个上下文统一理解**，一次生成即输出**原生双声道、带同步声音**的成片（24FPS）。

→ **提示词要承担全部导演职责**：锁定身份与观感、逐拍编排动作、指定镜头、调度音频、封死漂移。
→ **把音频直接写进提示词**，不要生成后再配音。
→ **想要主角脸一致，必须上传人物参考图并标注「人物参考」** —— 不传图 H3 无法锁定。

## 二、三种模式（写词前必须先定）

| 模式 | 触发条件 |
|---|---|
| **文生视频 T2VA** | 纯文字 / 剧本 / 台词 / 创意，无图 |
| **图生视频 I2VA** | 附 1 张图（首帧或尾帧）/ 附 2 张图（首 + 尾帧） |
| **参考生视频 Ref2VA** | 多张图 / 图 + 视频 / 图 + 音频 / 多素材混合 |

**Step 1 自动判定 → Step 2 用 AskUserQuestion 让用户确认**（推荐项放第一并标注 Recommended）。用户不选则按推荐，**绝不**在同一条提示词里混用两种模式。

## 三、官方三段式公式

```
完整提示词 = 【参考素材说明】+【核心创意】+【画面过程说明】
```
无素材则**第一段整段删除**。

**核心创意必须含五要素**：主体 + 地点 + 事件 + 风格 + 特殊运镜。

### 完整模板（中文）

```
【参考素材说明】
@图片1 是首帧参考图（锁这位女演员的脸/发型/服装/姿态/背景）。
@音频1 是音色参考（锁女主音色）。   ← 可选；无素材则整段删除

【核心创意】
一句话锁定全片：一位日本女演员在片场白色皮沙发上接受花絮采访（主体+地点+事件），
写实电影感、浅景深（题材/风格），单镜头缓慢推近（特殊运镜）。

【画面过程说明】
Shot 1（0–8秒）
想要：中景，女演员仍坐在白色皮沙发上（@图片1 保持一致）。她起初低头看手机滑动；
一支手持麦克风从画面左下缓缓入画。她放下手机、抬眼看向画外采访者。
男性采访者（画外，平静友好，(S1) 说）： <d>[日语] お疲れさまです。今日の撮影はいかがでしたか？</d>
  while no on-screen character's lips move
女演员（画内，温暖略带疲惫，她的 on-screen voice (S2) 说）： <d>[日语] とっても楽しかったです。</d>
  台词逐字保留原文，口型与语音精确同步。
运镜：基于首帧构图的单一连续中景，麦克风入画后做缓慢克制的推近至肖像式构图。
音效：安静棚内环境声（远处剧组走动、轻微器材触碰、低频空调嗡鸣）。无背景音乐。
不想要：字幕、水印、溶接转场、身份漂移、变装、文字叠加、夸张商业运镜。

[可选 · 整体要求补充]
非叙事性音乐: N/A
风格贯穿：写实电影感、浅景深、克制自然表演、稳定空间连贯。
```

## 四、通用铁律（三条模式都适用）

### 🔴 台词 `<d>` 标签铁律（V1.4，最重要）
所有台词**必须用 `<d>[语言] 台词原文</d>` 整体包裹**。H3 文本编码器依靠 `<d>` 与 `</d>` **整体标签**识别台词并驱动 TTS 与口型。

- 标签缺失（只写引号）或被拆成 `<` `d` `>` 三个字符 → **语音胡言乱语，或台词被渲染成画面文字**
- `<d>` 必须作为连续的 3 个字符原样写入，严禁拆分、加空格（`< d >`）、转义（`&lt;d&gt;`）或翻译
- **说话人身份短语、`(S#)` ID、动作、语气一律放在 `<d>` 之外**；`<d>` 内只放 `[语言标签] + 台词逐字原文`
- 画外音后跟 `while no on-screen character's lips move` 声明

### 其他铁律
- **少写比喻，多写看得见的画面** — H3 更擅长明确画面指令
- **台词长短与镜头长短对齐** — 口型问题大多源于"3 秒镜头说一大段话"
- **环绕运镜**用 `truck left + pan right`，不要只写"环绕"
- **一镜到底就不写多个分镜**；想切镜就明确写 `Shot 2`
- 切镜时明确写"切到什么景别、主体还是之前的哪个角色"，写清画内还是画外说话人

## 五、三种模式的差异化要领

### 3A 参考生视频（Ref2VA）
- 可同时上传「人物图 + 动作视频 + 场景图 + 音乐」，**每个素材必须写清角色**：
  - `@图片1` → 人物参考（锁脸）｜ `@视频1` → 动作参考（锁动作）
  - `@图片2` → 场景参考（锁场景）｜ `@音频1` → 情绪/节奏参考（古风配乐等）
- 画面过程说明中凡关联素材的元素，用 `@图片1` / `@视频1` 强调保持一致
- **合法性约束**：音频不能单独输入；`refers[]` 至少含一张图或一段视频；总文件 ≤ 12，图片 ≤ 9、视频 ≤ 3、音频 ≤ 3

### 3B 图生视频
- **仅 1 张图**：必须说明是**首帧**还是**尾帧**
- **2 张图（首 + 尾）**：H3 **不会自动加切镜**，只补两帧间的动作/光影/声音 → 提示词写"自然衔接，不要切镜"，不要写多个 Shot
- **比例由图推导，不要传 `aspect_ratio`**

### 3C 文生视频
- 文字要**更具体**：主体外观 + 场景细节 + 动作描述都写清
- 提倡「**大全景交代空间 + 中景承载动作 + 特写强调细节**」的分层写法
