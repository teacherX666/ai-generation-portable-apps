## 〇、步骤 0 · 素材门：先要图，再动笔（最高优先级）

**Ref2VA = 全参考模式。没有参考图 = 让模型自己发明主角。**

| 情况 | 动作 |
|---|---|
| 已提供图 | 立即走**读图校准三步法**，再进工作流 |
| 未提供图 | **先开口要图**，说清每张图锁什么；**不要先写提示词** |
| 明确不提供 | **必须发下方警告模板**，等用户确认 |
| 无图模式 | 每个 Subject 标注「无参考图，由文字描述定义」+ 交付补图清单 |

### 无图模式警告模板（逐字发给用户）

```text
⚠️ 无参考图 = 无图模式，后果先讲清：
1. 人物长相由模型随机生成，每次都不一样，无法复用于后续镜头 / 场次
2. 服装、妆造、道具细节不可控，跨场次必然漂移
3. 场景空间与光线方向只能靠文字描述，模型理解偏差很大
4. 若后续补图重做，之前生成的所有片段基本作废

确认继续吗？回复「继续无图」，我按纯文字定义出提示词，
并在交付时附一份「上线前必须补图」的清单。
```

### 读图校准三步法（有图时强制）

1. **读图** —— 逐张打开看清实际内容，**不看文件名，不采信剧本描述**
2. **列校准表** —— 文案描述 vs 图片实际，逐项对照，标出每一处不一致
3. **重写 Subject** —— 按**图片实际内容**写 `subject_definitions`；剧本文字只管动作与台词

**为什么强制**：模型只听提示词文字。剧本写「傍晚」而图片是夜景时，模型按文字生成黄昏，
而**校对文字的人看不出错**——因为剧本就是这么写的。
实测一场戏查出 10 处不一致，其中「傍晚 → 夜间」是致命项（光线、色温、车窗外景全跑偏）。

**无图模式三条硬要求**：① 保留标记只能用 `weak_reference`；
② 每个 Subject 末尾写「无参考图，由文字描述定义」；③ 交付附补图清单。

## 二、先判断：该不该用

**用中文模板** —— 全参考（有参考图/视频/音频）；单镜头或少量镜头；表演/微表情是卖点；中文叙述更顺手。

**整段切英文（官方语法）** —— T2VA/I2VA/FL2VA/L2VA；视频编辑/续写；需精确音画对齐；台词跨切镜（`<scenetrans>`）；需要 Zoom 变焦语义。
**带音色参考** —— V1.7 起默认混合版（中文叙述 + 英文音频骨架），交付时给用户三选：① 混合版（默认）② 整段英文官方版（最稳）③ 无音色中文版。

## 四、两种描述模式

| 模式 | 适用 | 记号 |
|------|------|------|
| **节拍模式** | 对白密集、动作是离散事件 | `→林浩看着唐糖。` |
| **时间码模式** | 表演 / 微表情 / 运镜是卖点 | `**0–1s：**` |

**判定**：这一镜里「说了几句话」比「表情怎么变的」更重要 → 节拍模式。

**默认值（V1.6.1 实测固化）**：镜头内 ≥2 句台词 → **默认纯节拍**（一句对话独立成行、行首 `→`），
一句一事件，模型解析单元清晰、不依赖切点秒数对齐。交付时给用户三选项：
**A 纯节拍（默认）/ B 纯时间码 / C 混合**，用户不回复按 A。混合模式的对白夹在时间码之间，
模型可能把前后时间码当一个连续动作块，节奏发飘——选 C 需用户明说。

**节拍模式要点**：一行一事件；台词写 `→角色名说"……"`；每句台词前后挂视线（谁看谁），否则站桩念稿；10 秒 4–6 句，每句 8–15 字。

**时间码模式要点**：运镜/位移 1.5–2s 一段，动作 0.5–1s，微表情 0.5s；8 秒建议 5–8 段。

## 四b、动作七要素 + 对白七要素（V1.3 新增）

### 动作：触发 → 准备 → **重心** → 发力 → 接触 → 反作用 → **收势**

| 要素 | 问自己 | 例：「他推开门」 |
|------|--------|-----------------|
| 触发 | 什么引起这个动作 | 脚步在门前停住 |
| 准备 | 身体如何蓄势 | 右手抬起，指尖触到门板 |
| **重心** | 重量压在哪只脚 | 重心移到前脚掌，左肩略沉 |
| 发力 | 哪块肌肉主导 | 肩膀前顶，手臂伸直 |
| 接触 | 与物体如何作用 | 掌心压满门板，门轴发出低响 |
| 反作用 | 惯性带来什么连带 | 身体因惯性前倾半步 |
| **收势** | 结束时停在什么姿态 | 收回手臂，跨过门槛，站定 |

**收势必须写出来**——它是下一段的起始姿态锚点。

### 对白：视线 / **呼吸** / **停顿** / **微表情** / 音色 / 原话 / **口型**

| 镜头权重 | 写哪几项 |
|---------|---------|
| 主镜/特写（卖这句台词） | 七项全写 |
| 过镜/反应镜 | 视线 + 微表情 + 口型 |
| 群戏背景台词 | 音色 + 原话 |

**口型是硬要求**：模型默认让人物说完张着嘴停住，必须显式交代嘴唇状态。
（官方 base-en §136 只在画外音场景要求，本套推广到所有对白。）

## 四c、多段拆分与转场（V1.3 新增）

### 切点只能落在可见变化上

✅ 合法：景别变化 / 视点变化 / 空间变化 / 时间变化 / 主体变化 / **动作完整结束**
❌ 严禁：同动作做到一半 / 同姿势保持中 / 同情绪递进中途 / 同一句台词说到一半

> 官方 base-en §4.2 已规定「A cut should introduce new information...」，
> 本套补的是反面清单和第 6 项「动作完整结束」。

### 每段都要写尾帧 + 切点

```text
【本段尾帧】唐糖站在门内，右手仍搭在门把上，侧脸朝向门外的光，嘴唇微张。
【下段切点】切到林浩正面特写，景别由中景变特写，视点转到林浩。
```

不写尾帧，下一段首帧全靠模型猜。多段项目开工前还要定死四锚点：
**角色 / 场景 / 声音 / 时间**，全程不改。

### 转场禁止空话

❌ `→丝滑转场到下一段。`（观感形容词，模型不知道做什么动作）
✅ `→接上同一个门把被压下的动作，切到室内。`

匹配元素六选一：**视线 / 动作 / 形状 / 色彩 / 运动方向 / 声音**。

## 六、四条高价值实战规则

### 1. 角色图必须进 Subject，不单独建 Picture

```
✅ <Subject 1>：唐糖，……。完全参照 <Picture 1> 外观。
❌ <Picture 1>：唐糖的全身照。
```
> 这条官方 §2.2 原文就有，不是本套独创。

### 2. 参考图有棚拍纯色背景，必须显式否定

```
<Picture 1> 不得展示灰色背景，实际场景替换为夜晚街头。
```
不写这句，棚拍灰底大概率被直接搬进成片。

### 3. 删内心独白，用可观察动作

| 禁用 | 替换为 |
|------|--------|
| 悲伤/伤心 | 嘴角微微下沉、下颌收紧、目光失焦 |
| 害羞 | 低头、目光落在自己脚上、脸颊泛红 |
| 紧张 | 喉结滚动、手指摩挲衣角、呼吸变浅 |
| 心跳加速/满脑子都是 | 删掉 |
| 用力一扔 | 引臂 → 肘部前送 → 手腕翻转 → 脱手 |

物理动作拆要素链见「四b、动作七要素」。

### 4. Negative「少而精」，≤10 个英文词

- ❌ 26+ 词堆同义词，关键指令被稀释
- ✅ `no other people, no exaggerated expression, no tears streaming, no sobbing, no text, no watermark, no camera static,`

只挑这次最可能翻车的 2–3 类（画面污染 / 多余人物 / 表情失控 / 机位失效 / 节奏异常）。

## 七、运镜：官方三维度

| 维度 | 写法 |
|------|------|
| 运动类型 | `Push In` / `Arc Shot` / `Pan Left` / `Zoom In` … |
| 幅度 | `with small amplitude` / `with large amplitude` |
| 速度 | `at slow speed` / `at fast speed` |

中等幅度、正常速度**可省略**。写成自然英文动作句，不要堆标签：

> ✅ `The camera pushes in with small amplitude at slow speed toward the subject.`
> ❌ `Camera: push in. Amplitude: small. Speed: slow.`

**轴心点**（`with Subject 1 as the pivot`）只在**弧形 / 环绕 / 多主体推拉**时补，其他场合是冗余。

⚠️ 官方区分 `Zoom In/Out`（变焦，机身不动）与 `Push In/Pull Out`（推拉，机身移动）。写混会得到"假推镜"。

## 七b、多镜头台词预算（本套独有）

中文按 **4.5 字/秒** 估算口播时长，逐镜核对，每镜还要留 **≥1.2s** 给动作/反应。

> 实测：某 15 秒三镜头短剧，末镜只有 `10–15s`（5 秒）却塞 41 字台词（需 9.1s），
> 必然截断或语速失真。修法：砍台词到 30 字 + 切点重排为 `2.5s / 4s / 8.5s`。

## 九、32 条铁律

1. 六段顺序不可变
2. 英文元素用英文（字段名 / 标签 / 保留标记 / Negative）
3. 不中英混写
4. 4–15 秒 / ≤7000 字符 / 素材 9+3+3 总数 ≤12
5. 角色图进 Subject，不单独建 Picture
6. 场景也要定义为 Subject
7. 参考图有纯色棚拍背景必须显式否定并换场
8. 删除全部内心独白
9. 用具体动作代替情绪标签
10. 动作写全七要素，**收势必写**
11. Negative ≤ 10 个英文词
12. 运镜写官方三维度：类型 + 幅度 + 速度
13. 说话的角色给稳定 ID `(S1)`/`(S2)`，跨镜头一致
14. 多镜头：首镜无时间戳，后续切点严格递增
15. 中文台词按 4.5 字/秒核算，每镜留 ≥1.2s 给动作
16. **BGM 一律写 `N/A`（V1.8）**，音乐后期配；用户明确要求时才写乐器/速度/力度，禁抽象情绪词
17. **有参考图时，提示词前先写「图片上传顺序」**
18. **禁模糊词**（震撼/高级感/唯美/氛围感/丝滑）；
    ⚠️ `cinematic` 作首句风格标签时**官方允许**
19. **转场必须写明可见匹配元素**
20. **对白要交代口型**
21. **多段切点只能落在可见变化上**
22. **多段每段写「本段尾帧 + 下段切点」**，四锚点全程不改
23. **装不下时按序降级**：减动作 → 简运镜 → 砍台词 → 最后才拆段
24. 忽略源图不良元素（水印 / 界面文字 / 压缩噪点 / 姿势）
25. **有图必先读图**：外观一律以图片实际内容为准，剧本文字只管动作与台词；
    必须走完「读图 → 列校准表 → 重写 Subject」，校准表随提示词交付
26. **无图不许静默出稿**：先要图 → 不发警告不许进无图模式 → 确认后每个 Subject
    标注「无参考图，由文字描述定义」→ 交付附「上线前必须补图」清单
27. **镜头几何锁（V1.6）**：机位在哪 + 人物面朝哪必须显式写；「拍哪里」≠ 机位
28. **含群众场景禁写「无其他人」（V1.6）**：改「背景虚化、无清晰面部、不开口」，
    Negative 用 `no sharp background faces`
29. **压长度不删几何/一致性锚点（V1.6）**：机位、朝向、光源、说话人 ID、
    去污染、背景人群处理是保护项
30. **带音色默认混合版，交付时给选项（V1.7）**：英文只保留 `<Audio N>` 标签/定义、
    `reference` 标记、任务前缀、说话人 ID；timbre 描述中文化，台词行
    `→(S1)角色名用 <Audio 1> 的音色说"……"`；三选：混合版（默认）/ 整段英文官方版 / 无音色中文版
31. **背景人群三锁定：面部+服装+行为（V1.8）**：群像服装必须显式锁定并挂主角锚
    （`every classmate wears the same X as <Subject N>`）+ 反向禁 + Negative
    `no dark blazers on background students`；背影剪影也要写服装颜色——
    不锁就会被主角服装锚带偏（实测全班被穿成深色西装）
32. **BGM 默认 N/A（V1.8）**：`non_diegetic_music` 一律 `N/A`，音乐后期配
33. **生成画面确立的服装/道具必须回写（V1.8）**：已生成画面新增的细节
    （如双肩包）立即写进该角色 Subject，后续场次逐场继承，维护「外观增量台账」

## 八b、镜头几何与背景人群（V1.6 新增，真实翻车复盘）

### 机位 + 朝向必须显式写

`A medium shot frames the front of the classroom` 只说了**拍哪里**，没说**镜头站在哪**、人物面朝哪
→ 模型自由发挥，造出「老师正面 + 学生也正面」的几何不可能构图。

```text
✅ The camera is placed at the rear of the classroom among the students, looking toward the front.
✅ <Subject 2>, standing behind the lectern, facing the camera and the class.
✅ 前景最近处学生的背影呈虚化剪影，不出现清晰面部。
```

### 含群众的场景，禁写「无其他人」+ 服装必须锁定

教室全班、街道行人这类场景：retention 写「背景人群全程虚化、无清晰面部、不开口说话」，
Negative 用 `no sharp background faces`（不用 `no other people`）；
正文也别出现 `the class settles into quiet attention` 这类必然引入群众的句子去和「无其他人」打架。
**服装也要锁（V1.8）**：群像服装不写就会被主角服装锚带偏——
场景 Subject 挂「same tracksuit as <Subject N>」+ 正文反向禁 + Negative `no dark blazers on background students`；
前景背影剪影也要写服装颜色（背影看不到脸，看得到衣服）。

### 压缩保护清单（压长度时只删修饰词，不删这些）

**机位 / 人物朝向 / 光源方向 / 说话人 ID / 去污染声明 / 背景人群处理**。
实测教训：`facing the class` 在两轮压长度中被删掉，直接导致生成翻车。

### 其他两条 V1.6 实战规则

- **删 `<Audio N>` 四处全清**：上传顺序块、subject_definitions、retention、正文 timbre 措辞，
  漏一处即判错；音色特质改普通形容词直述，前缀降为 `[reference generation]`。
- **中文版多镜头格式**：台词行必须行首 `→` 独立成行；切点写 `At 00:03.000`
  （写「在 00:03.000」校验器解析不出切点）。
- **英文版是条件触发不是默认**：仅精确音画对齐 / 台词跨切镜两种情况必须英文；
  纯图片参考 + 多人对白，中文版够用；带音色默认「中文叙述 + 英文音频骨架」混合版（V1.7）。

## 八c、模糊词替换表（V1.3 新增）

| ❌ 模糊词 | ✅ 换成（挑 2–3 个维度） |
