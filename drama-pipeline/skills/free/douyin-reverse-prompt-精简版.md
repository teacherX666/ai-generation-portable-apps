# 抖音短视频反推提示词 · 精简版

> **一句话定位**：发一个链接，走完「下载 → 密集抽帧 → 逐张看图 → 反推提示词 → 二创建议 → 案例入库自学习」六步，一次性交付。
>
> 本文件为**免费分享的精简版**（约完整版 1/4）。完整版（会员）含：四个 Python 脚本、十维反推框架全文、详细四段式模板与完整范例、二创路线库、案例库 schema。

---

## 一、五条铁律

1. **一键到底** — 用户只发链接时，不反问、不中途确认，直接跑完全流程，最后一次性交付。
2. **画面必须真看** — 反推前必须抽帧并**逐张用 Read 工具实际查看**关键帧（至少 6 张，覆盖开头/中段/结尾）。**禁止仅凭标题或想象编造提示词。**
3. **短视频必须密集抽帧** — 时长 **≤ 30 秒**一律每 0.5 秒一帧，且**最后 5 秒额外加密**。
   > 短视频镜头少、动作密度高，等间隔稀疏抽帧极易漏掉关键动作，**尤其是结尾的收尾动作**（停下/转身/抬手/合十/回眸）—— 那是全片高潮，漏了二创就复刻不出来。
4. **当前模型不支持读图时** — 明确告知"需要切换到多模态模型"，交付已完成部分 + 基于标题的**初步框架**（标注"待视觉确认"）。**绝不假装看过画面。**
5. **下载失败不撒手** — 按三级降级链一路试到能用，每级失败说明原因再进入下一级。

## 二、标准流程

### Step 1 · 下载
主方案：真浏览器（`agent-browser`）提取 CDN 直链 + 元信息。
降级链：**真浏览器 → yt-dlp → 老接口**。

**Step 2 · 抽帧（密集优先）**

| 时长 | 策略 | 产出 |
|------|------|------|
| **≤ 30 秒** | 密集模式，每 0.5 秒一帧 | 19 秒 → 38 帧 |
| **> 30 秒** | 约 12 帧均分 | — |
| **任何时长** | 最后 5 秒额外加密到每秒 6 帧 | `tail_*.jpg` |

常用参数：`--dense`（强制密集）、`--no-tail`、`--tail-seconds 8`、`--tail-fps 8`、`--interval 1.4`

**看图顺序（重要）**：
1. 先按 `f_001 → f_038` 快速过一遍，建立全片印象
2. 再**逐张细看 `tail_*.jpg`**，把结尾动作拆成「几秒 → 什么动作」
3. 有转身、抬手、道具交接等关键节点时，回到 `f_*.jpg` 定位精确时间码

记录维度：主体、服饰/道具、场景、光线、色调、景别、运镜、构图、节奏。

### Step 3 · 反推提示词 — 先判断档位

| 条件 | 用哪套 |
|------|--------|
| **≤ 30 秒** 或 **单镜头** 或 用户要求「详细/逐秒/复刻/保持一致」 | **详细模板**（四段式） |
| 其他（长视频、多镜头、只要个大概） | 十维提取法 + 中英文提示词 + 分镜表 |

**详细模板四段式（≤30 秒必用）**

```
【一、视频结构摘要】  总时长/画幅/类型/人物/场景数/镜头数/核心事件
                     + 四阶段（开端·发展·转折·结尾）
                     + 情绪转折与画面证据
【二、全片设定】      角色固定锚点 / 场景固定锚点 / 视觉风格锚点 / 声音锚点
【三、分场设定】      场景01：名称｜00:00.0—00:19.3｜总时长
【四、分镜生成稿】    镜头01：按动作节拍分段（不按等分时长）
                     + 结尾固定约束句
```

**硬性要求**：
- 时间段按**动作节拍**划分，不按等分（✗ 0-6/6-12/12-18）
- 每段都写**摄影机行为**与**声音状态**
- 结尾必须写**定格画面**与**精确动作**
- 结尾固定约束句必带（防人物变形/换装/水印）

**十维提取法（长视频或简版）**产出：中文通用版（可直粘即梦/Seedance/可灵/海螺/万象）+ 英文精修版（可选）+ 分镜拆解表 + 可复用关键词表。

### Step 4 · 爆款二创建议
- 爆点诊断（这条为什么能火）
- 三条二创路线：**换皮 / 换视角 / 换叙事**，每条给出可直接用的提示词
- 避坑清单（版权、同质化、平台规则）

### Step 5 · 案例入库 + 自动学习
案例写入 `assets/cases/`，`learn.py` 统计全部案例并重写 `references/learned-patterns.md`（高频场景/运镜/色调/爆款结构）。**下次生成时优先读这个文件** —— 这就是自动学习。

### Step 6 · 交付
一次性呈现：视频文件 + `反推提示词.md` + `反推提示词.txt` + 代表性关键帧 2~3 张。

**交付前自检（短视频必查）**
- [ ] 结尾 5 秒的动作已逐个拆解并写进分镜稿（不能只写"氛围收尾"）
- [ ] 每段都写了摄影机行为与声音状态
- [ ] 结尾固定约束句已带上
- [ ] MD 与 TXT 双文件都已生成

## 三、产物目录规范

```
output/<视频ID>/
├── video.mp4               # 原视频（无水印优先）
├── meta.json               # 元信息
├── frames/
│   ├── f_001.jpg ...       # 全片（短视频每 0.5 秒一帧）
│   └── tail_01.jpg ...     # 结尾 5 秒加密帧（关键！）
├── 反推提示词.md
└── 反推提示词.txt
```
