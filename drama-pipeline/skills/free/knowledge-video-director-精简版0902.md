# 知识教学视频生成 SOP · 精简版

> **一句话定位**：一段知识点文本进去，走「共创定方案 → 首镜试产验证 → 批量出提示词 → 云端批量生成 → 取回命名交付」，全程六阶段，方案定稿后**全自动执行到交付**。生成通道二选一：**仙宫云自建实例**（通道 A）或 **RunningHub 云端托管**（通道 B，按任务计费、免部署、支持 1~5 并发）。
>
> 本文件为**免费分享的精简版**（约完整版 1/4）。完整版（会员）含：H3 提示词方法论全文、仙宫云通道调用规范与四条工作流路由表、调度策略、错误处理与恢复、讲师资产准备指南（附录 A）。

---

## 一、总流程

```
① 输入采集 + 内容诊断与共创（多轮对话式，每轮聚焦一个议题）
② 知识理解 → 教学分镜方案 → ⛔ 方案定稿（交互终点）
③ 首镜试产（自动验证通道，通过即放行，不等人工确认）
④ 海螺 H3 方法论 → 批量结构化提示词
⑤ 仙宫云批量生成（双实例并行 + 状态跟踪 + 断点续跑）
⑥ 取回 + 按序命名 + srt 附属物 → 交付核对清单
```

## 二、阶段一：输入采集与共创

### 必需输入
知识文本（任意长度，短则一段话，长则整篇文章）。

### 可选输入（缺省走默认值）
| 项 | 默认 | 备注 |
|---|---|---|
| 参考音频 | 无 | **LECTURER 轨必需**：10~30s 干音口播。**禁止用生成视频自提音轨当参考**（含混响/压缩痕迹，会污染音色克隆形成退化循环） |
| 讲师形象图 | 无 | **LECTURER 轨必需**：半身、视线平视镜头、中性偏暖表情 |
| 讲师姿态资产库 | 无 | 可选增强：同一讲师 3~5 张不同手势/角度图 |

### 内容诊断（Agent 主动职责，不等问题）
通读后立即诊断并向用户报告（这是共创的第一议题）：
- **内容量 × 目标时长匹配度** — 过薄给补全方向建议（案例/数据/背景故事/易错点/对比论证，各附简例）或建议下调时长；过厚给删减优先级建议（保主线砍枝蔓 / 拆成上下集），明确推荐其一
- **内容缺口清单** — 缺定义、缺案例、缺数据、逻辑断链，逐项标注
- **超纲风险** — 对目标受众过深/过浅，建议升级或降级

结论一律以「**问题 + 我的建议（含推荐项与理由）+ 备选项**」格式呈现。

### 共创提问机制
- **比例与分辨率是第一议题且必答** — 用户明确答复前**不得进入分镜设计**
- **首问四件套一次问完（例外于"单议题"规则）**：画面比例/分辨率、算力通道（A 仙宫云 / B RunningHub）、算力档位（B 通道 standard 24G / **plus 48G 推荐** / ultra）、并发数（1 试产 / 2~5 批量）——四题一屏，答完本会话锁定不重复问
- **每轮只聚焦一个议题**（首问四件套之后），逐项过，不一次抛一堆问题
- **每问必带建议与选项** — Agent 先给推荐项及理由，再列备选；用户可回"听你的"快速通过
- 用户说"剩下的你定"→ 未讨论议题走默认值 —— **但比例与分辨率不适用此规则**

### 共创议题清单

| 议题 | 默认值 | 可选范围 |
|---|---|---|
| **画面比例** ⚠️必答 | 无默认（推荐 16:9） | 16:9 / 9:16 / 1:1 |

## 三、阶段二：知识理解与教学分镜方案

### 教学结构模板（标准六段式，按时长占比）

| 段落 | 占比 | 目的 | 首选画面轨 |
|---|---|---|---|
| **HOOK** 钩子引入 | ~10% | 抛问题/反常识/痛点场景，3 秒抓住注意力 | METAPHOR 或 LECTURER |
| **CONCEPT** 概念拆解 | ~25% | 主概念定义，拆成 2~3 个子要点 | LECTURER + TEXTCARD |
| **VISUAL** 图解演示 | ~25% | 抽象概念具象化 | DEMO / METAPHOR |
| **EXAMPLE** 示例应用 | ~20% | 真实场景用例，展示"怎么用" | DEMO |
| **PITFALL** 易错点 | ~10% | 常见误解与纠正 | METAPHOR |
| **RECAP** 总结回顾 | ~10% | 要点复述 + 一句行动指引 | LECTURER + TEXTCARD |

### 🎯 画面类型枚举（分轨是本 SOP 的核心机制）

| 类型 | 含义 | 生成通道 | 说明 |
|---|---|---|---|
| `LECTURER` | 数字人讲师口播 | **工作流 03 全能参考**（讲师形象 + 参考音频，多参考锁定跨段一致性） | 仅讲师模式开启时使用；音色精确统一 |
| `DEMO` | 过程/操作/流程演示 | **工作流 02 图生视频**（首帧参考图锚定关键元素），备选 01 | 台词写进提示词音频线索 |
| `METAPHOR` | 类比/情景/氛围画面 | **工作流 01 T2V 加速版**（自由度最高）；需构图锚定时切 02 | 台词写进提示词音频线索 |
| `TEXTCARD` | 术语卡/公式/步骤列表 | **不生成视频**，输出图卡文案 | 精确文字靠后期字幕/图卡呈现，**规避乱码** |

### ⚠️ 分轨使用约束（决定成品质量下限）
- **DEMO 轨高风险，严格限用** — T2V 生成"看起来像、但过程逻辑错"的概率高。约束：单段**只演示一个完整的具体动作**（如"水滴落入水面漾开涟漪"），**禁止抽象过程**（如"细胞分裂的全过程"）；复杂过程必须拆成多个单动作分镜连续呈现，或降级为 TEXTCARD
- **默认分镜配比建议** — METAPHOR ≥ 40%、DEMO ≤ 25%、LECTURER 按讲师模式、TEXTCARD 按需。保证成品定位为"**氛围型知识分享**"，而非"精确演示型教学"
- visual 描述只写模型可想象的具体画面（主体/动作/环境），**抽象逻辑放 narration 台词里讲**

### 时长预算换算
- H3 T2V 单段时长：**6s 或 10s**
- `TEXTCARD` 不占生成时长，从总预算先扣除（每张按 4s 阅读时间预留）
- **分镜总数 ≈（总时长 − TEXTCARD 预留）÷ 8s**。3 分钟约 18~22 个生成段

### 分镜方案字段（定稿呈现用的 MD 表格）

| 字段 | 说明 |
|---|---|
| `seq` | 两位序号 01~99，**全流程主键**：方案 #03 → 提示词 #03 → 任务 #03 → shot_03.mp4 |
| `段落` | HOOK/CONCEPT/VISUAL/EXAMPLE/PITFALL/RECAP |
| `type` | LECTURER / DEMO / METAPHOR / TEXTCARD |
| `duration` | 该段时长；TEXTCARD 填预留阅读时长并标注"(图卡)" |
| `visual` | 画面描述：主体 + 动作 + 镜头 + 光影，具体可拍 |
| `narration` | 讲解台词。**字数硬约束：≤ duration × 4.5 字**（中文口播 4~5 字/秒，超长会导致 AI 语音压缩、赶读或截断）；超长先精简，仍超则拆段 |
| `sfx / bgm` | 音效 / BGM 情绪标记 |
| `style_ref` | 风格锚定 ID（统一为 STYLE-A） |

### 风格锚定
产出一段约 **50 字**的风格锚定描述（视觉风格 + 色调 + 质感 + 镜头基调），作为所有 T2V 分镜提示词的**统一前缀**。**定稿后冻结，批量生成期间不再修改**。

## 四、⛔ 方案定稿（交互终点）

向用户呈现：分镜方案 MD 表 + 风格锚定块 + 时长预算汇总。
- 用户提修改意见 → 修订后再呈现，**可多轮**
- 用户回复"通过/OK/开始吧" → **冻结方案，此后全自动执行到交付，不再请示**

仅以下特殊情况允许暂停请示：知识内容缺口在共创阶段未能补全、生成中暴露逻辑断链且无法自动修复等。

## 五、阶段三～六（定稿后全自动）

**③ 首镜试产** — 先用一镜验证通道（含 ffprobe 校验分辨率是否符合共创承诺值），通过即放行，**不等人工确认**。

**④ 批量提示词** — 按海螺 H3 官方方法论产出结构化提示词。

**⑤ 云端批量生成** — 状态跟踪 + 断点续跑 + 失败重试。四种分镜类型按上表路由到不同工作流。通道选择：
- **通道 A 仙宫云**：自建容器双实例并行，按实例租时计费，适合长片批量主力
- **通道 B RunningHub**：按任务计费（RH 币），plus 48G 实例实测：6s 段 117~143 币/5~6 分钟、10s 段 224~258 币/9.5~11 分钟——**60s 级短片按 6~10s 切段单价更优**；并发 1~5，"完成 1 个补 1 个"补位调度保持满负荷
- **服装锚定前置铁律（出镜段强制）**：参考图复刻服装是概率性行为，不写锚定必然随机漂移（实测同片 4 段讲师 3 深红 1 米白）。每段出镜段提示词必须在双位置写同一句服装锚定：subject_definitions（"She wears exactly the {颜色+材质} shown in <Picture 1>."）+ detailed_description（"[Shot 1] ... wearing the {同一描述} from <Picture 1>"），全片统一，先看参考图定颜色材质再动笔
- **生成后必做抽帧目检（100% 覆盖，禁止跳段）**：每段抽 3~5 帧逐段目检——抽样跳段会放走漂移段（实测 6 段检 5 段恰好漏掉漂移的那段）；且必须拿首镜基准帧做**跨段对照**（服装颜色/发型/道具），发现漂移就地修复——该段提示词双位置补锚定句 + 换 seed 重提，实测一次修复

**⑥ 取回与交付** — 按 `seq` 主键**按序命名**（`shot_01.mp4`…），生成 srt 附属物（零成本白捡项），输出交付核对清单向用户报告。
