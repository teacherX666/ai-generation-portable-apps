# 真实感 AI 人物提示词 · 精简版

> **一句话定位**：把"AI 假脸 / 油腻磨皮脸"的根因（空泛赞美词）换成六段式皮肤物理描述，产出真人感人物提示词。
>
> 本文件为**免费分享的精简版**（约完整版 1/4）。完整版（会员）含：六段式每段完整词库、反面案例对照集、各平台参数速查、变体模板库。

---

## 一、核心原则（三条）

1. **避免空泛词汇** — "8K""超高清""真人皮肤""完美无瑕"这些词会让模型生成油腻磨皮脸。
2. **所有描述必须具体、可视化、符合真实皮肤的物理规律。**
3. **物理瑕疵是必选项，不是可选项** — 不允许"完美皮肤 + 完美对称"。

---

## 二、六段式皮肤公式（技能的核心）

按固定顺序组织皮肤描述：

```
① 物理状态 → ② 区域纹理 → ③ 克制瑕疵 → ④ 高光分布 → ⑤ 光线/表情驱动 → ⑥ 时间连续性
```

### ① 物理状态（一次只选一组）
| 选项 | 适用 |
|---|---|
| 自然半哑光 | 日常、干净但不假 |
| 运动出汗 | 额头、鼻尖、颈侧有细汗，毛孔微张 |
| 风尘 / 擦伤 | 带灰尘、细小伤口，适合战损、旅途角色 |
| 淋雨 / 湿润 | 皮肤表面有水膜，高光连成线 |
| 精致底妆 | 均匀、控油，适合时尚、广告风 |

### ② 区域纹理（分区差异化，这是去 AI 味的关键）
> 额头毛孔细密，鼻翼毛孔略明显，眼下是细薄纹理而非粗大毛孔，嘴唇有纵向唇纹，中心略湿唇缘偏干。

**不同区域纹理必须不同** — 全脸一个描述 = 塑料感。

### ③ 克制瑕疵（分三档）
- 轻度：肤色微不匀、鼻翼泛红，几乎无斑
- 中度：可见色斑、眼下细纹、轻微痘印
- 重度：明显皱纹、晒斑、疤痕（老年或饱经风霜）

### ④ 高光分布
只写**骨骼凸点的局部破碎高光**：鼻梁、颧骨、下唇中央、下巴。下颌保持低反射。

### ⑤ 光线/表情驱动
- 自然光（窗光/户外，柔和过渡）
- 电影光（单侧硬光，强调骨骼结构）
- 夜景/霓虹（彩色反光，皮肤染环境色）
- 逆光/轮廓光（边缘发光，面部细节弱化）

### ⑥ 时间连续性
视频必需 — 描述皮肤状态在镜头时间内的连续变化（如"汗珠沿颈侧缓慢下滑"）。

## 三、两种输出结构

### A. 人物模板提示词（文生图）
```
[人物身份] + [物理状态] + [区域纹理] + [克制瑕疵] + [高光分布] + [光线/表情驱动] + [时间连续性]
```

✗ 反面：`完美无瑕` `精致五官` `8K 超高清真人皮肤`
✓ 正面：`轻微肤色不匀` `鼻翼泛红` `眼下微细纹`

### B. 视频提示词（图生视频 / 文生视频）— 三层结构
```
第一层：身份锁定   → "她/他"或角色名，不重复描述皮肤
第二层：光线如何经过皮肤 → "窗光从左侧扫过，在颧骨留下移动的光斑"
第三层：镜头能看见的表演动作 → "她眨了一下眼，睫毛在光里投下阴影"
```
⚠️ 第三层**不写情绪词**（不写"害羞""真实"），只写看得见的物理动作。

### 景别适配（重要）
| 景别 | 写什么 |
|---|---|
| 全身 | 只写整体肤色与衣服反光差异 |
| 近景 | 才写毛孔、绒毛、唇纹 |
| 微距特写 | 一次只抓一个重点（如仅写"鼻翼毛孔在光下张开"） |

## 四、交互流程（不要一次性输出结果）

收到创意后**先提问，让用户决定方向**，每个选择项给 2-4 个具体选项并说明视觉差异：

| # | 必问项 | 说明 |
|---|---|---|
| ① | 人物基础设定 | 性别 / 年龄段（皮肤状态差异极大）/ 角色气质 |
| ② | 皮肤物理状态 | 六段式第 1 段，一次只选一组 |
| ③ | 瑕疵程度 | 克制是关键 |
| ④ | 光线环境 | 决定高光与阴影逻辑 |
| ⑤ | 使用场景 | 文生图模板 / 图生视频 · 文生视频 |

生成后**至少提供 2-3 个变体**（更自然日常 / 更电影感 / 更强情绪），每个附一句视觉差异说明。用户选后可继续微调（"要不要把汗改成雨水？""瑕疵再少一点？"）。

---

## 五、输出要求

每次输出完整提示词（中英文均可，按使用平台定），并**附一句设计逻辑说明** —— 为什么这样写能避免假脸。
