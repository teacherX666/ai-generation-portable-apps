## Phase 3 — 清理体系（新调度 + 脚本升级）✅ 2026-08-24 完成

实现方式说明（与计划的偏差）：
- 新建独立脚本 `tools/cleanup_daily.py` 专供定时任务（不动 `cleanup_old_media.py`，避免影响手动工具与 cleanup_server）
- **安全设计**：只有命中飞书 `synced` 表指纹（与 sync.py 同口径，实测验证精确命中）才直接删除；未同步文件一律移回收站
- 首轮执行：删 1404 个超龄 workspace 参考素材（4.0GB）、11 个旧产物入回收站（69.7MB）、剪 335 个失效 token、截断 135MB agent 日志
- 调度：`com.ai-portal-cleanup.plist`（每日 03:47）已 load + kickstart 验证；日志 `~/Library/Logs/ai-portal-cleanup.log`
- 已知现象：运行中的 seedance/vp 会在新下载时把内存里的旧 download 映射全量写回（失效 token 复活），portal 重启后内存映射从已剪枝文件重建即消失；每晚剪枝兜底，无害
- 跳过的内容：cloudflared 隧道日志（属于其他应用）；usage-*.jsonl（portal 自带 30 天剪枝）；feishu agent runs/（需走 delete_run 接口，待定）
