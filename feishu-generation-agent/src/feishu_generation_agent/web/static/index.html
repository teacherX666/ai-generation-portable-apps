        修改只影响之后领取的新任务

        这里设置新任务默认模型；每个任务下方的视频模型 / 出图模型才是该任务实际使用的模型。

        规划方式：默认「逐张看图描述后规划」—— 先用 Claude 逐张分析图片，再拿描述去规划。切到「原图/视频一起交给模型规划」后，原图和文档一次性交给规划模型（ds4.1）自己看，不再单独跑一遍图片分析：少一次模型调用，也少一层「别人转述这张图有什么」的信息损耗。失败会自动回退到现有方式。

        分镜候选图：规划阶段就为每个时间段并发生成这么多张关键帧，审批页每段挑一张（默认第一张）。选中的图会作为关键帧参考一起提交，画面严格对齐它 —— 比只给文字稳定得多。数量越多越费额度、规划等待越久。
