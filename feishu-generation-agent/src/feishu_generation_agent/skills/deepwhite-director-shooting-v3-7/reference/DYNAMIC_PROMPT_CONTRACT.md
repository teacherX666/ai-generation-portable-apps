# 动态场景提示词契约

本文件只控制 `DYNAMIC_MODE` 和 `MIXED_MODE` 中的动态区间。最终提示词必须先写：

```text
【全局声音与字幕约束】
不要BGM、不要字幕，只保留音效。
```

其后再写素材、【全局视觉设定】、初始位置和全局连续性/结尾约束；本文件不得省略首行声音约束或【全局视觉设定】。

## 1. 多镜头字段

每镜头按以下顺序：

```text
{起始}—{结束}秒｜镜头{N}
画面动作概述：本镜头的单一视觉目标及其结果。
画面构图：景别、前中后景、主体位置、地标和运动留白。
拍摄方式：固定/手持/肩扛/轨道/稳定器/航拍；实时或按需短微升格；镜头内部是否连续。
摄影机：一个主运镜、运动路径、速度、焦段感、轴线和切入状态。
连续动作：用一至三句概括本镜头内连续发生的跑动、攻防、追逐、闪避或通过障碍，不逐拳逐脚列清单。
关键接触与反馈：仅在记忆点接触出现；写接触点、主要运动变化、2—3个可见后果和余势。
表情/表演：使用描述性可见动作，避免成语；只写当前机位可见部分。
对白：逐字台词或无。
声音：与动作、接触和空间对应的对白、环境声和拟音。
衔接：切点及下一镜继承的位置、方向、速度、道具、破坏、地标和摄影机侧位。
```

没有关键接触时省略该字段，不写“无”。VFX写入连续动作或关键接触，不建立独立特效展示段。

## 2. 一镜到底字段

只建立一个镜头，在镜头开头写唯一摄影机总体路径。内部路径节点使用：

```text
{起始}—{结束}秒｜路径节点{N}
连续动作：...
关键接触与反馈：...（按需）
表情/表演：...
对白：...
声音：...
节点衔接：继承位置、速度、方向、道具、地标和状态，摄影机沿原路径继续。
```

路径节点不能暗示切镜、瞬移、换机位或速度归零。

## 3. 概括与细化的比例

- 一段连续运动只写一次总目标和路线。
- 普通动作合并描述，例如“她沿祭坛外环疾跑，连续侧身避开低空飞剑，并用剑鞘格开逼近肩侧的剑锋”。
- 只对决定战术、空间或结果的接触具体化。
- 不重复同类动作，不把“左拳—右拳—踢腿—后撤”写成独立回合，除非它们是剧本指定的记忆点。

## 4. 动作切镜

允许切在动作中间，但衔接必须可执行：

```text
衔接：剑锋即将触及屏障时沿运动方向切到同侧贴地近景；下一镜继承剑锋向北下压、女主向南后滑和外环刚开始凹陷的状态。
```

不要只写“硬切”“快速切换”。

## 5. 反馈语言

推荐：

```text
剑锋压中屏障南侧，接触点短促白金闪光；屏障沿受力方向向内凹陷，女主双脚在黑岩上连续后滑，雪与碎屑向两侧喷开。她屈膝改印卸力，剑锋余势仍向北擦过。
```

避免：

```text
巨剑猛烈撞击，爆发华丽特效，冲击感十足。
```

## 6. 动态负向控制

只保留当前高风险项，并尽量先写正向要求：

- 连续运动，不在每招完成后停住；
- 不自动添加翻滚、空翻、瞬移和剧本外招式；
- 关键地标持续存在，不被雪、烟、法术或构图删除；
- 人物不进入禁入区、不站上未授权地标、不穿模；
- 比例、手位、伤势、运动方向和破坏跨镜连续；
- 镜头震动短促且只绑定关键接触，不持续乱抖。
