# 文戏镜头任务与动势连续性

本文件只改变文戏和混合戏中文戏区间的导演判断，不改变 `PROMPT_PATTERNS.md` 的最终提示词字段、顺序和排版。先完成这里的内部设计，再把结果压入原有的 `画面动作概述、画面构图、机位、动作/表演、对白、声音、转场` 字段。

## 1. 核心原则

文戏多镜头不是静态构图的顺序排列，而是行为、视线、摄影机和声音共同形成的动势链。

- 每个镜头只有一个主要视觉任务，但镜头内部可以有多个相互驱动的连续动作。
- 不把“一个主要视觉目标”误写成“一个静态动作”。
- 先分别设计主体运动、摄影机运动、构图变化和表演变化，再写提示词。
- 摄影机运动必须有戏剧职责；没有职责时保持克制，不为电影感添加无意义运镜。
- 切镜只发生在信息焦点、表演节拍、空间关系、观察对象或主动权发生明确变化的位置。
- 切镜后继承人物、道具、摄影机、环境和声音的进行中状态，不让人物停住等待剪辑。

## 2. 镜头主任务

写每个镜头前，从以下任务中选择一个主要任务：

- 建立空间：让观众理解人物、道具、出入口和地标关系。
- 交代关系：让距离、视线、遮挡、地位或对峙关系可读。
- 承载对白：让说话行为、倾听反应和台词节奏成为重点。
- 捕捉反应：让新信息进入人物并产生可见变化。
- 展示道具：让关键物件、文字、状态或接触关系清楚可见。
- 推进移动：让人物穿越空间、接近、远离、转身或停步形成剧情推进。
- 制造揭示：控制观众何时发现人物、道具、信息或空间变化。
- 段落收束：把视线、动作、声音或摄影机落到可连接的结束状态。

主任务控制景别、焦点、摄影机距离、运动复杂度和信息密度。次要信息只能支持主任务，不能与其争夺画面。

## 3. 视觉目标与连续动作链

每镜头先写一句内部目标：

```text
主要视觉目标：观众在本镜头结束前必须看清或感受到什么。
```

再把原剧本已有动作组织为连续链：

```text
触发 → 即时反应 → 身体或道具运动 → 构图/距离变化 → 结果或未完成余势
```

示例：

```text
主要视觉目标：人物第一次发现桌上的照片。
连续动作链：行走中余光触及照片 → 步伐减慢 → 视线锁定 → 重心前倾 → 右手抬起接近照片 → 指尖尚未接触时进入下一镜。
```

规则：

- 一个镜头可以包含多步连续行为，但只能有一个主要视觉目标。
- 动作之间必须由前一步触发后一步，不写互不相关的动作清单。
- 简单行为能在同一构图中清楚完成时合并；只有信息任务变化时才拆镜头。
- 静止必须是主动的戏剧节拍，例如观察、拒绝、压迫或消化信息；不能是生成停摆。
- 人物不说话时仍保持呼吸、视线、重心、倾听或手中事务的连续生命，但不添加随机小动作。

## 4. 镜头运动四段式

每个多镜头在内部确定以下四项；必要时压缩成 `机位：` 中的一至三句，不新增提示词字段。

```text
起始运动：第一帧摄影机静止、已经移动，还是正在承接上一镜动势。
主体跟随：摄影机跟随哪个人物、视线、手势、道具或空间移动。
运动变化：由什么触发推进、后移、横移、绕行、摇镜、减速、停止或受控转焦。
结束动势：切镜时摄影机和主体是否仍在运动，最终落点和方向是什么。
```

运镜必须有戏剧职责：

- 跟随：维持人物行动与空间的连接。
- 推进：压缩心理距离，突出发现、压力或决定。
- 后移：让空间、关系或逼近力量进入画面。
- 横移/绕行：改变前后关系、遮挡或权力位置。
- 摇镜/转焦：把注意力从触发源转到反应或结果。
- 固定：制造观察、压力、拒绝或不可逃离感。

每镜头通常只使用一个主运镜。允许一次由明确动作、视线、台词或信息触发的运动变化；不要堆叠多个无关运镜。

不要只写“缓慢推进”“轻微手持”。写清起点、跟随对象、触发变化和落点。简单镜头可以简写，但四项判断仍需在内部完成。

## 5. 切镜判断与动势继承

### 切镜必要性

每次切镜前先回答：为什么不能继续在同一镜头完成？

允许的理由：

- 主要信息从人物转到道具、从说话者转到倾听者；
- 表演节拍或关系发生明确转折；
- 当前构图无法清楚展示下一项必要信息；
- 需要改变主观距离、制造揭示、隐藏或冲击；
- 连续摄影机路径在空间上不可实现或会明显跳轴；
- 当前镜头的主任务已完成，下一任务需要不同景别或视点。

如果没有明确理由，优先合并为一个连续镜头或一镜到底路径节点。不要只为换景别而切镜。

### 动势继承

多镜头的 `转场：` 除切法外，必须按需写明下一镜继承：

- 人物位置、运动方向、当前速度和重心；
- 视线方向、头部转动或手势进行到的阶段；
- 道具所在手、接触状态和运动方向；
- 摄影机所在轴线一侧、切入方向和主体屏幕方向；
- 门、窗帘、衣摆、雨、烟、车辆、背景人物等持续环境运动；
- 对白尾音、呼吸、环境声或动作声的声音桥。

优先在动作、视线或声音尚未结束时切镜，让下一镜接住余势。不要让人物先完全停住，再等待切镜，除非停顿本身是剧情节拍。

## 6. 第一帧与结束帧

每个镜头内部先锁定：

```text
第一帧：人物、道具、地标、摄影机侧位、动作阶段和已有速度。
结束帧：主任务完成到何处，人物姿态、视线、道具、摄影机落点和未消失的余势。
下一镜接入：哪些状态必须从结束帧直接继承。
```

第一帧应直接包含当前镜头的重要主体和空间锚点，除非空画面进入本身承担明确的揭示任务。结束帧必须可作为下一镜或下一工作段的连续性依据。

## 7. 可行性否决

导演设计出现以下冲突时，保留剧本和主要视觉目标，调整镜头设计：

- 广角远景同时要求细微眼神、口型和道具小字全部清楚；
- 近景同时要求人物完成长距离空间移动；
- 复杂多人调度同时要求摄影机频繁绕行且保持精确轴线；
- 一个连续镜头承载过多重大事件、关系变化和道具信息；
- 同一镜头同时要求严格稳定和明显不规则手持；
- 构图锁定、焦点锁定和大量防错要求完全抵消必要运动；
- 摄影机在现实空间中没有足够距离或可行路径；
- 多个主运镜争夺同一短镜头。

调整优先级：

1. 合并或拆分镜头任务；
2. 调整景别和摄影机距离；
3. 简化运镜；
4. 降低次要画面信息；
5. 调整焦段倾向或构图；
6. 时长仍不足时返回规划 Gate，不删改剧本。

## 8. 无故事板内部判断表

不使用故事板时，每个文字分镜在写正式提示词前内部填写；默认不向用户展示，用户要求审查导演设计时再输出。

```text
镜头/节点：
主要视觉任务：
观众必须获得的信息：
焦点人物或对象：
第一帧：
主体连续动作链：
摄影机四段式：起始运动 / 主体跟随 / 运动变化 / 结束动势
构图变化：
表演变化：
景别与机位理由：
切镜理由，或继续一镜到底的理由：
结束帧：
下一镜继承：位置 / 速度 / 方向 / 重心 / 视线 / 道具 / 轴线 / 环境 / 声音
```

使用故事板时，故事板提供构图、站位、动作方向和摄影路径依据；仍需补做镜头主任务、运动四段式、切镜理由和动势继承判断。

## 9. 提示词压缩规则

保持 `PROMPT_PATTERNS.md` 的字段顺序不变：

- `画面动作概述`：写主要视觉任务及其结果。
- `画面构图`：写第一帧关系和随动作发生的必要构图变化。
- `机位`：写物理位置、景别/焦段倾向，以及运动四段式的可执行压缩。
- `动作/表演`：写相互驱动的主体动作链和表演变化。
- `对白`：逐字保留，并与动作节拍绑定。
- `声音`：写持续声、触发声和跨镜声音桥。
- `转场`：写切点、切镜理由的可见结果和下一镜动势继承。

不要新增“摄影机运动”“第一帧”“结束帧”等最终字段；把内部判断压回原格式。

## 10. 自检

- 每个镜头是否只有一个主要视觉任务？
- 镜头内部是否有连续动作链，而不是一个静态姿势？
- 主体运动、摄影机运动、构图变化和表演变化是否分别想清楚？
- 摄影机是否有起点、跟随对象、触发变化和结束动势？
- 运镜是否有戏剧职责，并通常只有一个主运镜？
- 每次切镜是否有必要理由？没有理由的镜头是否应合并？
- 切镜后是否继承位置、速度、方向、重心、视线、道具、轴线、环境和声音？
- 第一帧和结束帧是否明确、可生成、可衔接？
- 是否存在景别、微表演、空间移动、构图锁定和运镜之间的可行性冲突？
- 最终是否仍严格使用 v3.6 的提示词字段、顺序和格式？
