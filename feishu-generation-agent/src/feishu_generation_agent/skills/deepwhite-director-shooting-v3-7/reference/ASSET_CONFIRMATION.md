# 资产策略与映射 Gate

资产策略是最早的用户确认节点。先判断参考图是否有价值，再询问用户；不要等到文字分镜完成后才补问。

如果用户尚未提供足以判断的剧本或剧情范围，只请求必要的剧本内容；收到后立即执行资产策略 Gate，不先进入故事板、时长或分镜设计。

## 资产需求判断

出现以下任一情况，通常建议使用资产图：

- 固定角色身份、脸部、发型、服装、伤势或跨段状态需要连续；
- 场景有特定布局、建筑、地形、出入口、轴线或关键地标；
- 道具的形态、尺寸、文字、持握关系或落点影响剧情；
- 动作、姿势、构图或风格有明确视觉标准；
- 使用多宫格故事板且人物/场景一致性重要；
- 多个工作段需要保持相同人物、场景和物件。

抽象画面、无固定身份的泛化人物、纯环境氛围或用户明确接受模型自由发挥时，可以判断为可选或不需要。

最早询问格式：

```text
资产需求判断：建议使用 / 可选 / 本次可以不使用。
判断理由：...

请确认本次资产策略：
1. 使用资产参考图；
2. 不使用资产参考图，直接依据剧本设计。
```

用户在当前请求中已经明确“使用/不使用”时，记录选择即可，不重复询问。用户未选择时停止，不先问故事板方式。

## 用户选择不使用

记录：

```text
已确认资产策略：不使用资产图。
一致性提醒：{只写实际风险；没有明显风险则写“低”}。
```

尊重用户选择，不继续索要图片。后续提示词完全省略素材句柄和空资产占位。

## 用户选择使用

先输出当前剧本真正需要的资产清单：

```markdown
## 资产准备清单

**人物**
- 角色名：需要锁定的身份、服装和状态

**场景**
- 场景名：需要锁定的布局、地标和光线方向

**道具**
- 道具名：尺寸、材质、文字和剧情用途

**动作/姿势（仅必要时）**
- 用途：只控制什么动作，不控制什么身份或画风

**风格（仅必要时）**
- 用途：只控制色彩、灯光、材质或媒介中的哪些项
```

等待用户上传后再做映射确认。

## 资产映射

- 按上传顺序编号，不按猜测的文件名重排。
- 每项分别写 `参考什么`、`不参考什么` 和 `用于哪个工作段/镜头`。
- 只列当前项目会使用的资产；额外素材标为“暂不使用”。
- 文件名、主体、用途或顺序不明确时询问，不自行假定。

```markdown
## 资产映射确认

| 上传序号/句柄 | 文件名或来源 | 识别为 | 类型 | 参考什么 | 不参考什么 | 用于 | 状态 |
|---|---|---|---|---|---|---|---|
| @图片1 | heroine.png | 女主 | 人物 | 脸部身份、发型、当前服装 | 原图姿势、背景、光线、文字 | SEG-01—02 | 已匹配 |
| @图片2 | office.png | 办公室 | 场景 | 空间布局、桌椅、窗户位置 | 图中人物、天气、文字 | SEG-01 | 已匹配 |
| @图片3 | pose.png | 抬手动作 | 姿势 | 右手抬起的动作轮廓 | 身份、服装、背景、画风 | SEG-01/SB-06 | 需要确认 |

缺失资产：无 / ...
额外暂不使用：无 / ...

请回复“确认资产”，或逐项告诉我修改。
```

句柄使用用户实际 Seedance 界面名称，如 `@图片1`、`@素材1` 或 `@视频1`。

## 故事板返图

- 故事板方式由后续独立 Gate 决定，不能在资产策略中替用户选择。
- 每个工作段的完整 `N` 格宫格返图登记为一个资产；`N` 由剧情需要决定且不超过16，按已确认阅读顺序映射 `SB-01...SB-{N}`。
- 视频只参考故事板的构图、动作、站位和路径，不参考格框、编号、文字和黑白简笔画火柴人画风。

## 停机与变更

用户新增、替换、删除资产或改变参考边界时，更新映射并再次确认。进入后续阶段时记录：

```text
已确认资产策略：使用 / 不使用
已确认资产映射：是 / 不适用
```
