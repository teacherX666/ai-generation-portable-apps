# 动态场景诊断与质检

## 1. 常见失败及原因

| 现象 | 常见原因 | 修正方向 |
|---|---|---|
| 一卡一卡、一招一式 | 动作被拆成过多微节拍；每招都要求完整起落和停顿 | 合并普通攻防为连续动作，只细化关键接触；余势直接接下一动作 |
| 很慢、像回合制 | 频繁“站稳、停住、固定、慢推进”；切点在动作结束后 | 删除冻结措辞，在加速、接触或重心改变中切，维持速度继承 |
| 特效多但没冲击 | VFX没有接触点、受力者和环境后果 | 把光效绑定接触，补主要运动变化和2—3个物理反馈 |
| 画面漂亮但像展示法术 | 写了阵法展开和光环层次，却没有压迫、应对和战术变化 | 明确运动目标、受阻、关键接触、临场反制和结果 |
| 场景像固定舞台 | 人物始终停在中心，只有镜头移动 | 建立跨地标路线，用近/远/高/低尺度跳位表达空间推进 |
| 关键地标消失 | 雪、烟、法术或“中央空地”重构了场景；未声明地标持续存在 | 锁定结构、覆盖边界、可见轮廓和不可删除条款 |
| 人物站到祭坛/屋顶等错误位置 | “来到中央/阵心”等抽象词覆盖了真实几何；未设禁入区 | 把位置解析为台阶下、外环或台面，并写不可进入/站立/穿过 |
| 人物与地标比例漂移 | 近远景没有尺度锚点；场景结构被重生 | 写人物—台阶—祭坛比例，切镜继承同一地标尺度 |
| 模型自动翻滚或空翻 | 只写“躲避/快速移动”，模型用常见动作补全 | 若不需要，明确沿哪条路线以何种方式避让，并禁止自动添加翻滚空翻 |

## 2. 内容质检

- 剧情目标、胜负、伤势、破坏和结局是否与 `EV/LOCK` 完全一致？
- 是否擅自新增敌人、招式、翻滚、空翻、瞬移或结果？
- 普通动作是否概括，只有少数记忆点动作被具体化？
- 每个关键接触是否有接触点、一个主要运动变化、可见后果和余势？
- 动作是否连续驱动下一动作，而不是轮流出招后停住？

## 3. 镜头与空间质检

- 每镜头是否只有一个主运镜？
- 切点是否服务动作因果，下一镜是否继承位置、速度、方向和动作阶段？
- 是否至少用一个稳定地标维持方向和尺度？
- 关键结构是否持续存在，天气/VFX覆盖是否越界？
- 人物是否始终在允许区域，比例是否稳定？

## 4. 语言质检

- 是否用“连续近身攻防”“沿外环疾跑并连续闪避”等概括语句建立流动？
- 是否避免“激烈打斗、速度感十足”等空泛词单独承担动作？
- 表情是否写成脸部和身体可见变化，而不是大量成语？
- 是否删除“绝对静止、完成后停住、固定锁死”等减速/冻结措辞？
- 白闪、残影、速度线和震动是否只在有因果的位置出现？

## 5. 最终判定

只有同时满足以下条件才通过：方向清楚、动作连续、关键接触有重量、战术或运动目标有变化、空间与比例稳定、剧情结果不变。动态感不是镜头数量或特效数量本身。
