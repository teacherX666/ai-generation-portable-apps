# 交付格式

默认交付完整 Markdown 文件，不询问格式，不设置停机 Gate。

## 默认 Markdown

保存为：

```text
Shotlist_<范围>_Seedance2_5_ZH.md
```

建议结构：

```markdown
# 项目名｜Seedance 2.5 分镜与视频提示词

## 1. 项目与范围摘要
## 2. 剧本锁定清单与用户改动授权
## 3. 资产需求判断、用户选择与资产映射
## 4. 故事板方式
## 5. 用户目标时长、忠实估算与动态宫格工作段方案
## 6. 全剧本EV/DLG覆盖表
## 7. 空间调度
## 8. 各工作段文字分镜表（注明实际格数N、多行多列排版与阅读顺序，N≤16）
## 9. 多宫格故事板生成提示词、返图映射、审查摘要与修改记录（仅故事板分支）
## 10. Seedance 2.5 视频提示词
## 11. 跨工作段连续性与生成风险
```

每个视频提示词用独立可复制代码块，标题包含生成单元、实际时长和拍摄形式。

## 可选格式

只有用户明确提出时才改为或追加：

- HTML 网页：读取 `HTML_QA.md`、`PLAN_TYPES.md` 与 `../templates/HTML_TEMPLATE.md`，生成并检查页面。
- DOCX：使用文档技能，并保留与 Markdown 相同的信息结构。
- 聊天纯文本：直接输出，不创建文件。
- 其他格式：按用户要求转换，不删除已确认的关键信息。

格式变化不要求重新确认剧情、资产或分镜，除非转换过程中必须改变内容结构。
