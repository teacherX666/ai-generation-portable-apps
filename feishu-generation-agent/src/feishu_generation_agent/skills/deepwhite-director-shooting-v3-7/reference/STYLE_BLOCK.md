# 风格控制规则

风格服务于当前画面，不使用固定导演组合，也不强制每条提示词填满四个风格模块。

## 来源优先级

1. 用户当前明确要求。
2. 用户提供的参考图、样片、旧提示词、导演阐述、视觉手册或风格说明。
3. 从剧本的题材、年代、地点、人物心理、节奏和视觉母题中推断。

信息足够时直接提炼并在文字分镜中说明来源，不额外设置确认 Gate。只有不同风格选择会显著改变结果且无法合理推断时，问一个简短问题。

## 按需提取

只选择会影响生成结果的项目：

- 媒介与真实度：实拍、纪录片、广告、动画、游戏影像、插画等。
- 色彩：冷暖、饱和度、对比度、主色和局部点缀色。
- 光线：主光方向、软硬、明暗比、实景光源、背景层次。
- 摄影：手持或稳定、焦段倾向、景深、运动方式、颗粒或快门感。
- 人物材质：皮肤、头发、汗、水、伤口等当前镜头真正看得见的细节。
- 环境材质：雨、水、烟、尘、火、玻璃、金属或织物的物理表现。
- 表演尺度：自然主义、克制、戏剧化、喜剧节奏等。
- 明确禁令：只保留与用户要求和当前镜头相关的项目。

## 写入位置

把精炼后的风格写在提示词 `【全局补充 / 结尾约束】` 中。复杂项目可按需增加小标题，例如：

```text
影像与光线：低饱和写实电影质感，冷色窗光为主，暖色台灯只作人物轮廓点缀。
人物材质：近景保留真实皮肤纹理、细小绒毛和眼眶水光，不过度磨皮。
物理效果：雨水必须有重力、溅落、衣料吸水和接触反光。
```

简单镜头可以合并成一句：

```text
低饱和自然主义实拍质感，阴天窗光，皮肤不过度磨平，室内保留真实暗部层次。
```

不要为了形式完整而加入与画面无关的“人物材质”或“核心特效”。

## 与素材参考的关系

- 风格参考图只控制已声明的色彩、光线、构图或媒介质感，不自动控制人物身份和场景内容。
- 人物参考图只控制身份、发型、服装等声明项，不自动继承原图画风和灯光。
- 故事板只控制已确认的构图、动作、站位或路径，不继承简笔画火柴人画风，除非用户明确要求。
- 多张风格图冲突时，按上传顺序列出各自功能，并明确优先级。

## 灯光

必要时写清：

- 主光从哪里来；
- 人物哪一侧受光，眼神光是否需要；
- 辅光、负补光或轮廓光是否存在；
- 背景光如何与人物分离；
- 画内灯、屏幕、窗户、霓虹、车灯是否为实际光源。

不要默认“只用实景光”。广告、MV、舞台或超现实项目可使用造型光，只要符合已确认风格。

## 负向要求

默认：

```text
每条最终视频提示词的开头先写：不要BGM、不要字幕，只保留音效。若用户明确要求BGM或字幕，再按用户要求覆盖；剧本对白仍按剧本保留。
```

用户要求相反时覆盖默认。其他禁令按风险选取，例如身份漂移、空间镜像、漂浮道具、过度磨皮、游戏CG感或焦点漂移；不要机械复制长串禁令。

## 自检

- 风格是否来自用户、素材或剧本，而非无依据套用？
- 是否只写当前画面可见且有控制价值的内容？
- 是否错误继承了参考图的姿势、背景、画风或光线？
- 是否与素材映射、空间调度和用户负向要求冲突？
