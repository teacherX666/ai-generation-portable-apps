# 文戏与动态场景路由

本文件只在 `SKILL.md` 第6步“编写视频提示词”时使用。它决定具体镜头使用 v3.4 文戏逻辑，还是动态动作逻辑；不参与剧本锁定、资产确认、故事板选择、空间确认、时长规划或故事板生成。

## 1. 判定单位

- 优先按 `SEG-xx` 判定。
- 一个工作段同时包含稳定对话和高运动时，标为 `MIXED_MODE`，再按连续时间区间判定。
- 不因一句台词夹在追逐中就把整段改成文戏，也不因人物挥一次手就把文戏改成动态戏。

## 2. 三种模式

### DRAMA_MODE

满足以下多数特征：

- 核心目标是传递信息、情绪、关系或观察结果；
- 人物以站、坐、慢走、小幅转身、拿取、注视等低幅运动为主；
- 没有持续高速位移、反复接触避让或连续受力；
- 摄影与表演微节拍比动作路径更重要。

### DYNAMIC_MODE

不要求出现“战斗”关键词。以下信号中出现两项或更多，通常切换动态逻辑：

1. 主体在场景内持续位移，路线跨越多个空间锚点；
2. 速度、方向、高度或姿态连续快速变化；
3. 存在反复攻击、防御、追逐、避让、碰撞或障碍通过；
4. 一个接触会引发后滑、旋转、跌落、偏航、破坏或环境连锁反应；
5. 画面可读性依赖动作起因、接触、结果和余势；
6. 摄影机需要动作中切、方向匹配或沿路线接力才能保持冲击与清晰。

典型内容：近身战、兵器战、法术对抗、枪战、追逐、逃跑、跑酷、攀爬、翻越、跳跃、坠落、载具追逐/碰撞、爆炸撤离、建筑崩塌中的移动、大型物体高速运动。

### MIXED_MODE

同一段包含两套明显不同的运动任务，例如“老人说话—巨剑突袭—女主挡剑—战后喘息”。按时间区间分别使用对应字段，但以下信息必须连续：人物身份、伤势、服装、道具手位、地标、空间轴、光线、破坏和VFX残留。

## 3. 边界案例

- 单次耳光、推门、摔杯：通常仍是文戏；只对该关键接触补物理反馈。
- 边走边长对白：若路线简单且无追逐/障碍，仍是文戏一镜到底。
- 角色原地结印、能量环逐层展开：若主要是展示法术，没有压迫、接触和受力链，属于文戏/奇观展示，不自动当作战斗。
- 飞剑持续围攻、角色边跑边闪避并反制：属于动态模式。
- 战后停顿：可切回文戏逻辑，但衣摆、呼吸、烟尘、碎屑和余势不能冻结。

## 4. 提示词阶段的内部记录

在内部工作段表中记录：

```text
运动模式：DYNAMIC_MODE
判定依据：持续跨空间位移；连续避让与接触；受力结果决定下一动作。
模式区间：0—3秒 DRAMA_MODE；3—13秒 DYNAMIC_MODE；13—15秒 DRAMA_MODE（仅MIXED_MODE填写）。
```

模式是提示词写作策略，不是 Gate，也不是新的用户确认环节。不要输出状态机表或额外确认问题；只在 v3.4 前置流程和用户确认完成后，内部选择对应的镜头字段。
