# Seedance 2.5 视频提示词结构

每条提示词遵循：`全局声音与字幕约束 + 素材说明 + 一句话概述 + 全局视觉设定 + 详细情节 + 全局连续性与结尾约束`。按拍摄要求选择单镜头一镜到底或多镜头剪辑模板，不按时长档位选择模板。所有文戏和动态戏统一使用这一结构；动态模块只改变 `【详细情节】` 内的动作字段。

## 写作前置状态

```text
已锁定剧本：是；本工作段EV/DLG覆盖：完整
已确认资产策略：使用 / 不使用
当前工作段SEG-xx故事板方式：使用 / 不使用
已确认资产映射：是 / 不适用
已确认位置：是 / 本次无需位置图，原因：...
已确认文字分镜与时长：是
故事板审查：通过；已确认故事板：是（仅故事板分支）
```

缺少当前分支必需状态时，返回相应 Gate。不要先写正式提示词。

## 通用结构

```text
【全局声音与字幕约束】
不要BGM、不要字幕，只保留音效。

【素材说明】
@图片1：参考……；不参考……。
@图片2：参考……；不参考……。
{仅故事板分支：@图片N为本工作段整张{N}格故事板；参考SB-01至SB-{N}的……；不参考格框、编号、箭头、文字和简笔画火柴人画风。}

【一句话概述】
{人物}在{地点}完成{核心事件/情绪变化}；采用{单镜头一镜到底 / N镜头剪辑}，预计{X}秒。

【全局视觉设定】
全局风格：{媒介、真实度、色彩、摄影质感和表演尺度}。
关键材质与受光表现：{人物、场景、道具的可见材质、重量感和受光结果}。
灯光基线：{有动机光源、方向、软硬、色温、轮廓分离和曝光优先级}。
{动态段可补充整体动作速度、物理真实度和VFX基线；不要写具体镜头运镜。}

【详细情节】
{使用连续整数秒时间戳写画面、构图、机位、动作/表演、对白和声音。}

【全局连续性与结尾约束】
{人物、空间、道具和轴线连续性；结束画面；必要防错。}
```

首行约束为默认值。若用户明确要求 BGM 或字幕，按用户要求改写或删除冲突部分；如果剧本有对白，仍按剧本保留对白。

用户已确认不使用资产图时，完全省略 `【素材说明】` 和素材句柄，不写“无素材”占位；仍从首行声音约束开始，随后进入 `【一句话概述】`。用户选择使用资产但映射未确认时，不写正式提示词。

## 剧本锁定

- 提示词中的剧情、动作结果、人物关系和结局必须与当前锁定剧本一致。
- 每句对白逐字复制对应 `DLG-xx`，保持说话人、字词和顺序；不得润色、缩短、同义替换、合并、补写或改成旁白/字幕。
- 一句话概述只能概括本段，不能代替详细情节中的原剧本事件和逐字对白。
- 导演微节拍只能表现剧本情绪，不能改变人物态度、信息量和因果。
- 时长或生成稳定性不足时拆工作段，不能删减 `EV/DLG`。
- 可复制提示词外保留本段 `EV/DLG` 覆盖表，交付前与 `SCRIPT_FIDELITY.md` 逐项核对。

## 素材说明

按上传顺序声明当前生成单元实际使用的素材：

```text
@图片1：参考女主的脸部身份、发型和黑色风衣；不参考原图姿势、背景、光线和文字。
@图片2：参考旧公寓的客厅布局、红色电视墙和窗户位置；不参考图中人物与天气。
@图片3：只参考拍立得的尺寸、白色边框和底部手写“NOV 14”；不参考持有者的手部外观。
```

规则：

- 精确参考图已清楚呈现外观时，不重复堆砌所有细节。
- 状态变化可能被参考图覆盖时，明确写当前状态及优先级。
- 姿势参考只控制动作，不控制人物身份、服装和场景。
- 构图参考只控制画面关系，不自动控制画风。
- 不使用某项素材时不要把它列入本条提示词。

## 多镜头剪辑模板

```text
【全局声音与字幕约束】
不要BGM、不要字幕，只保留音效。

【素材说明】
...

【一句话概述】
Roko进入旧公寓并发现冰箱上的照片，情绪从警觉转为迟疑；采用3个镜头的连续剪辑，预计14秒。

【全局视觉设定】
全局风格：低饱和写实电影质感，冷色窗光为主，暖色室内残光只作局部点缀。
关键材质与受光表现：湿风衣吸水变深，旧木地板保持哑光磨损，照片白边受光清晰但不过曝。
灯光基线：冷色阴天窗光从人物右后方进入，室内暖色残光只作局部轮廓分离；左侧负补光保留暗部，曝光优先保住人物轮廓和照片细节。

【详细情节】
0—4秒｜镜头1
画面动作概述：Roko推门进入，湿靴跨过门槛，先建立空间与警觉状态。
画面构图：人物位于左三分之一，门框形成前景遮挡，客厅在右侧中远景留出负空间。
机位：门内南侧35mm广角低机位，轻微手持后移；保持入口在人物背后、客厅在他面前。
动作/表演：肩膀略抬，呼吸短促，眼神先扫客厅深处再落向冰箱。
对白：无。
声音：门轴轻响、湿靴落地声、远处城市低频。
转场：4秒处随他的视线硬切近景。

4—9秒｜镜头2
画面动作概述：他停步发现照片，右手缓慢抬起。
画面构图：侧脸位于左中部，照片在右下方前景；两者保持同一视线轴。
机位：人物右前侧50mm中近景，极慢推进，不跳轴。
动作/表演：喉结吞咽一次，指尖悬停后触碰照片边缘，眼眶微湿但不落泪。
对白：无。
声音：纸张轻响、被压住的鼻息；城市低频延续。
转场：9秒处用手部动作匹配切到道具特写。

9—14秒｜镜头3
画面动作概述：照片文字清晰可见，随后焦点落回人物眼睛。
画面构图：照片占画面中央偏右，人物眼睛位于上方虚化区域。
机位：85mm近摄，先锁定照片；只在文字可读后做一次受控焦点转移。
动作/表演：拇指压弯照片边缘；转焦后人物瞳孔短暂收紧，呼吸停顿。
对白：无。
声音：纸张受力声；环境声保持连续。

【全局连续性与结尾约束】
严格保持人物脸、服装、照片所在右手、房间左右关系和三镜头视线轴一致；全段严格3个镜头，不自动补镜头。结尾停在人物眼部近景与照片边缘同框。
```

多镜头规则：

- 每个镜头必须有独立连续时间段。
- 固定字段顺序：`画面动作概述 → 画面构图 → 机位 → 动作/表演 → 对白 → 声音 → 转场`。
- 最终字段和顺序保持不变；文戏在写入这些字段前必须完成 `DRAMA_SHOT_MOMENTUM.md` 的内部导演判断。
- 每镜头只有一个主要视觉任务，但镜头内部必须保留相互驱动的连续动作链，不能退化成静态姿势等待切镜。
- `机位` 不只写景别和一个运镜词；按复杂度写清摄影机起始状态、跟随对象、触发变化和结束动势。每镜头通常只有一个主运镜。
- 无对白时可写“对白：无”，也可在简单段落省略；有对白必须写台词前、台词中和台词后表演。
- 写清切镜方式和跨镜连续性，限制镜头数量。没有信息焦点、表演节拍、空间关系或主任务变化时，不只为换景别切镜。
- `转场` 按需继承人物位置、速度、方向、重心、视线、道具手位、动作阶段、摄影机侧位、环境运动和声音桥；优先让下一镜接住尚未结束的动作、视线或声音。
- 使用故事板时，在对应镜头标题后增加 `故事板：参考SB-xx的……；不参考……`。

## 单镜头一镜到底模板

```text
【全局声音与字幕约束】
不要BGM、不要字幕，只保留音效。

【素材说明】
...

【一句话概述】
女主从办公室门口穿过走廊并在主管面前停下完成质问；全程单镜头一镜到底、无剪辑，预计18秒。

【全局视觉设定】
全局风格：低饱和写实职场短剧质感，表演克制，摄影运动贴近人物心理。
关键材质与受光表现：皮肤保留真实纹理，文件纸张保持哑光折痕，玻璃隔断只产生受控反射。
灯光基线：走廊冷白顶灯提供环境基线，办公室窗光从女主左前方进入；右侧负补光增加面部塑形，曝光优先保留脸部和文件细节。

【详细情节】
全程单镜头、无剪辑、不中断、不跳轴；以下时间段仅表示连续摄影机路径节点。

0—5秒｜路径节点1
画面动作概述：女主推门进入并向走廊深处快步移动。
画面构图：女主位于中央偏左，门框从右侧前景滑出，主管在远景轴线末端。
机位：摄影机从女主右后方35mm中景跟随，距她约1.5米，保持同侧运动轴。
动作/表演：步速快但上身克制，右手攥紧文件，呼吸压低。
对白：无。
声音：鞋跟、纸张摩擦、办公室环境声。

5—11秒｜路径节点2
画面动作概述：女主减速转身面对主管，摄影机连续绕到她正面。
画面构图：主管始终留在女主左肩后方远景，二人距离逐渐缩短。
机位：沿女主右侧顺时针小弧线绕行，不能穿越人物轴线，最终落到50mm感的中近景。
动作/表演：她先吞咽、抬眼，再松开一半攥紧的文件；主管反应延迟约1秒。
对白：无。
声音：脚步停下，环境声略显空旷但不中断。

11—18秒｜路径节点3
画面动作概述：摄影机极慢推进，她说完质问并维持视线。
画面构图：女主脸部从中近景逐渐占据画面，主管成为左后方虚化轮廓。
机位：沿原运动方向推进约20厘米，禁止变焦，最后停在近景。
动作/表演：台词前短促鼻吸气和一次吞咽；台词中重音落在“为什么”；台词后保持视线1秒，下颌轻微颤动后收紧。
对白：“你为什么一直瞒着我？”
声音：对白清楚，纸张轻响和办公室底噪持续。

【全局连续性与结尾约束】
摄影机运动必须是一条连续可实现路径，严禁硬切、跳切、瞬移、换机位或跳轴。保持人物身份、服装、文件所在右手和两人相对位置连续。结尾停在女主近景，她仍看向主管。
```

一镜到底规则：

- 只声明一个连续摄影机，不使用 `镜头1/镜头2`。
- 时间段命名为路径节点、阶段或节拍。
- 每个节点继承上一节点的人物位置、动作、视线、道具和摄影机方向。
- 每个节点只有一个主要视觉任务；摄影机路径要写清起始运动、跟随对象、触发变化和结束落点，不因时间段变化重置速度或构图。
- 禁止写任何暗示剪辑、瞬移或重新建立机位的词。
- 使用故事板时说明各面板是连续路径节点，不是剪辑镜头。

## 故事板引用写法

只在用户选择故事板、实际返图审查通过并经用户确认后使用：

```text
@图片4：本工作段整张{N}格故事板。本段参考SB-01至SB-{N}的人物站位、构图、动作方向与摄影机路径；不参考格框、编号、箭头、说明文字、简笔画火柴人画风和返图中的误生成细节。
```

对应时间段可进一步写：

```text
故事板：参考SB-02的前后关系和动作方向；人物身份、服装与场景材质仍以@图片1、@图片2为准。
```

不使用故事板时，完全省略故事板标签和相关禁令。

## 空间与表演

- 多人、道具或摄影机几何关系必须继承已确认的俯视调度。
- 用前后、左右、朝向、距离、遮挡、接触点描述关系；百分比坐标仅作可选辅助。
- 情绪必须转译为可表演事件。使用 `MICRO_BEATS.md`，但只选与当前情绪弧线相关的少数微节拍。
- 摄影机运动跟随情绪变化。使用 `CAMERA_EMOTION.md`，不要机械套焦段或晃动。
- 文戏先使用 `DRAMA_SHOT_MOMENTUM.md` 判断镜头任务、动作链、摄影机路径、切镜必要性和动势继承；情绪规则只负责调节运动质感，不能替代物理路径。

## 声音与负向要求

- 每条最终视频提示词的第一行写 `【全局声音与字幕约束】不要BGM、不要字幕，只保留音效。`
- 用户明确需要 BGM 或字幕时，按用户要求覆盖默认。
- 默认禁令不影响对白、画外音、环境声、拟音和关键道具声。
- 画内招牌、手机界面和道具文字需要保留时，明确其内容，避免用泛化“不要文字”误伤。

## 内容密度控制

不设置固定字符数上限。提示词长度由剧本完整性、镜头可执行性和生成稳定性决定；短剧情应保持简洁，复杂剧情可以保留必要细节。

内容重复或指令过载时依次整理：

1. 删除重复风格形容词与空泛质量词。
2. 将素材外观改为简洁指向，保留参考/不参考边界。
3. 合并重复的空间、声音和连续性描述。
4. 删除低风险负向条目。
5. 若仍过度复杂、存在互相争夺的镜头任务或生成稳定性风险，重新评估是否拆成多个生成单元。

不得为压缩而删除或改写任何 `EV/DLG`、时间戳、关键素材映射、空间关系、故事板偏差约束或结尾连续性。

## 最终自检

- 模型名是否为 Seedance 2.5？
- 本工作段的 `EV/DLG` 是否完整覆盖，所有台词是否逐字、说话人和顺序一致？
- 是否存在用户未授权的剧情、动作、人物关系或结局修改？
- 单元时长是否为 4—30 秒且由剧情决定？
- 拍摄形式是否明确且模板匹配？
- 时间戳是否位于正文、使用整数秒、连续覆盖完整时长？
- 是否包含一句话概述？
- 是否以【全局声音与字幕约束】开头，并且没有只在末尾重复该约束？
- 是否包含【全局视觉设定】，且明确写出全局风格、关键材质与受光表现、灯光基线？
- 【全局视觉设定】中是否没有混入具体镜头动作或运镜？
- 每个素材是否同时写参考与不参考内容？
- 使用故事板时是否为本工作段按剧情需要确定、最多16格，且已读取、审查通过并经用户确认的实际返图？
- 不使用故事板时是否彻底省略相关字段？
- 空间、表演、声音和结束状态是否可执行？
- 文戏镜头是否有明确主任务、连续动作链、第一帧和结束动势，而不是静态构图排列？
- 多镜头切点是否有必要理由，下一镜是否接住位置、速度、方向、重心、视线、道具、摄影机侧位、环境和声音？
- 默认负向要求是否与用户要求冲突？
- 正文是否没有重复堆砌、互相冲突或与当前镜头无关的控制语言？
