# 动态动作与物理因果核心

本文件用于战斗及高运动场面。先在内部把动作想清楚，再压缩为自然、连续、可生成的提示词。

## 1. 动作合同

每个记忆点动作至少应能回答：

1. 谁执行，目标或障碍是什么；
2. 双方当前距离、相对方向和运动状态；
3. 执行者的意图与发力来源；
4. 接触或险避发生在哪里；
5. 接触后只突出一个主要运动变化；
6. 哪些可见后果证明力量真实发生；
7. 余势把人物、道具和摄影机带到什么结束状态。

推荐因果链：

```text
执行者/目标/距离/方向/意图/发力
→ 接触点或最小避让距离
→ 一个主要运动变化
→ 2—3个可见物理后果
→ 余势与下一动作起点
```

## 2. 只具体化少数关键动作

- 普通过招、连续跑动、追赶、闪避和小幅调整使用概括性描述，例如“双方沿祭坛外环连续近身攻防”“她穿过连续落下的剑阵向北侧台阶疾跑”。
- 只具体化战术转折、关键命中、险些命中、重击、环境互动和结局动作。
- 同一种拳脚、挥剑、翻滚或VFX不重复逐次描写。
- 目标是“方向清楚的连续运动”，不是逐帧动作说明书。

## 3. 物理反馈

一次关键接触选择最有辨识度的 2—3 项，不要全部堆叠：

- 身体：重心偏移、后滑、旋转、屈膝卸力、肩髋扭转、呼吸中断；
- 道具：剑路偏转、枪口上跳、盾面凹陷、碎片飞散、绳索绷紧；
- 环境：雪被犁开、尘土沿受力方向喷出、岩面裂开、积水被切向掀起；
- 服装与头发：稍晚于身体跟随，体现惯性和风压；
- 摄影：短促冲击震动或后撤，只发生在接触瞬间并立即恢复可读性；
- 光效：一帧白闪、火花或冲击波必须绑定接触点和方向。

VFX不能代替接触、受力者反应和环境后果。

## 4. 非战斗高运动

把“攻击者/受击者”替换为：

- 运动主体；
- 障碍、地形、载具、坠落重力、爆炸冲击或崩塌物；
- 通过、绕开、撞上、抓住、失衡、恢复或脱离的目标。

例如不是只写“她快速逃跑”，而是概括连续逃跑，再具体化一次关键越障：她从南侧断墙疾跑到祭坛外环，爆炸从右后方追近；脚掌踩上倾斜石板边缘时石板下沉，她借下沉反力跃过缺口，落地屈膝前冲，雪和碎石沿原速度方向继续越过她。

## 5. 禁止倾向

- 抽象词代替动作：激烈、超快、冲击感十足；
- 每一拳、每一步都独立编号，造成回合制与卡顿；
- 动作完成后“站定不动”“画面停住”“绝对静止”；
- 无因果地自动翻滚、空翻、瞬移或新增招式；
- 同时要求多个主运动变化，例如既被击退又向前突进又原地旋转；
- 为了炫技而忽略原剧本结果、空间路线和地标。
