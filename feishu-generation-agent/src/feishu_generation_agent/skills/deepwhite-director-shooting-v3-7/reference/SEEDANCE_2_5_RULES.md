# Seedance 2.5 提示词规则基线

本文件只记录本技能需要的 2.5 视频提示词规则，不覆盖复刻、白模或编辑工作流。

## 目录

0. 剧本优先
1. 时长
2. 基础结构

## 0. 剧本优先

- Seedance 提示词是对用户剧本的视听转译，不是自动改编。
- 未经用户明确指示，不删减或改写剧情、动作、人物关系、因果、结局和台词。
- 台词逐字保留说话人、原文和顺序。时长不足或内容超量时增加工作段，不牺牲剧本。
- 导演补充只增加镜头、构图、调度、表演和声音控制，不改变剧本事实。

## 1. 时长

- 单次生成支持 4—30 秒。
- 4 秒是下限，30 秒是上限；二者都不是默认目标。
- 不按 10 秒、15 秒、30 秒建立固定提示词类型。
- 先根据动作完成度、对白长度、表演弧线、摄影路径和镜头数量判断自然时长，再检查是否在 4—30 秒范围内。
- 内容超过 30 秒时，按场景变化、动作目标、情绪转折或生成稳定性拆为多个生成单元；每段还必须能由一张不超过16格的宫格图完整表达。

## 2. 基础结构

每条视频提示词按以下逻辑组织，首行约束不可遗漏：

```text
全局声音与字幕约束 + 素材说明 + 一句话概述 + 全局视觉设定 + 详细情节 + 全局连续性与结尾约束
```

- `素材说明`：说明每个上传素材参考什么、不参考什么。
- `一句话概述`：概括人物、事件、地点、视觉目标和拍摄形式。
- `详细情节`：按时间线或清晰故事线写画面、摄影机、动作、对白、声音。
- `全局补充/结尾约束`：写风格、连续性、结束状态和真正必要的负向要求。

这是一套信息结构，不要求机械写成四个冗长模块。复杂内容用明确标题，简单内容可以自然合并，但顺序和信息功能要保留。

## 3. 时间戳

- 需要精确安排事件时，在提示词正文中直接使用时间戳。
- 相邻时间段必须连续，不得重叠或留空。
- 使用整数秒，最小粒度为 1 秒。
- 不要切得过少，导致一个时间段塞入多个无法区分的动作；也不要切得过多，造成指令碎片化。
- 时间戳用于安排剧情和镜头事件，不用于强迫模型在一秒内重复某动作若干次。
- 多镜头：时间段可以对应镜头或剪辑节拍。
- 一镜到底：时间段对应连续摄影机路径、动作或构图阶段，不代表切镜。
- 文戏多镜头的时间段不是静态画面停留。每段应有一个主要视觉任务和连续动作链，并写清摄影机从起始状态到结束动势的可执行路径。
- 相邻多镜头优先在进行中的动作、视线或声音上切换，下一镜继承位置、方向、速度、重心、道具和摄影机侧位；不要让人物无理由停住等待切镜。

示例：

```text
0—4秒：人物推门进入，广角建立空间；摄影机从门内低位缓慢后移。
4—9秒：硬切人物近景；他发现桌上照片，呼吸停顿，右手伸向照片。
9—14秒：切照片与眼睛的同轴特写；焦点保持在照片文字，现场声延续。
```

一镜到底示例：

```text
全程单镜头、无剪辑。
0—5秒：摄影机在人物右后方跟随进入走廊。
5—11秒：人物停步转身，摄影机沿同一运动轴绕至正面中近景，不跳轴。
11—18秒：摄影机极慢推进，他完成一句对白和压抑反应，最后停在眼部近景。
```

## 4. 素材映射

- 按素材上传顺序编号，避免错位。
- 每个素材同时写明“参考什么”和“不参考什么”。
- 精确参考素材已清楚呈现的信息，用简洁指向性描述，不重复堆砌。
- 只将素材用于被声明的功能。人物图不能自动控制场景，姿势图不能自动控制身份，故事板不能自动控制画风。

示例：

```text
@图片1：参考女主的脸部身份、发型和当前服装；不参考原图姿势、背景、光线和画面文字。
@图片2：参考办公室空间布局、桌椅材质和窗户位置；不参考图中人物及其服装。
@图片3：只参考照片道具的尺寸、边框和手写内容；不参考持有者的手部外观。
```

## 5. 故事板

- 故事板可帮助控制镜头顺序、构图、动作、站位和摄影机路径，但不是逐像素复现保证。
- v3.4 工作流由剧情与拍摄需要决定每个工作段的实际格数 `N`，通常为2—16格；16格是项目上限，不是固定目标，也不是 Seedance 官方时长分类。详细容量判断以 `PLANNING_CAPACITY.md` 为准。
- 每个工作段先确认 `N`、多行多列排版和阅读顺序，再一次只生成一张完整宫格故事板，不逐格分别生成。
- 本技能默认使用白底黑线简笔画火柴人故事板：人物采用圆头、单线躯干和单线四肢，按需增加简化发型、眉眼、手势或标志性饰件；场景和关键道具可以略具体；无彩色、文字和水印。
- 生成或收到返图后必须实际逐格审查；硬性项失败时修改当前完整原图并复审。内部审查通过后仍需等待用户确认。
- 实际 `N` 格必须覆盖该工作段全部锁定剧情事件和台词归属，不得因画面容量擅自删改，也不得为了填满16格新增或重复内容；超过16个有效节点时新增工作段。
- 多镜头故事板的一格表示一个镜头/剪辑节拍；一镜到底故事板的一格表示连续路径节点。
- 提示词需说明故事板参考哪些内容，以及不参考其编号、箭头、边框、文字、简笔画火柴人画风等内容。

## 6. 负向要求

默认使用：

```text
提示词第一行必须写：不要BGM、不要字幕，只保留音效。
```

这是可覆盖默认值，不是不可变规则：

- 用户明确要 BGM 或字幕时，删除冲突禁令。
- 剧情需要画内屏幕文字、路牌或道具文字时，不得用“不要文字”误伤它们。
- 默认禁 BGM 不等于禁对白、环境声和动作声。

## 7. 内容密度

- 不设置固定字符数上限；提示词长度由剧本完整性、镜头可执行性和生成稳定性决定。
- 短剧情应明显更简洁；复杂剧情可保留完成生成所需的空间、动作、表演和连续性信息。
- 指令重复或过载时先删重复风格词、重复素材外观、无关负向词和重复空间描述，不删核心剧情、时间戳、素材边界、关键动作、对白和连续性约束。
