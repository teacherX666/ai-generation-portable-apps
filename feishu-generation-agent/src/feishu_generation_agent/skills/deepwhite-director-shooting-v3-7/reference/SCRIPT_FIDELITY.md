# 剧本与台词忠实规则

用户最新确认的剧本是唯一剧情源。分镜和提示词负责视听化，不负责改编；只有用户明确要求修改的内容才能改变。

## 锁定优先级

1. 用户对具体剧情或台词的最新明确修改指示。
2. 用户提供的原始剧本正文。
3. 已确认文字分镜和故事板只控制视听表达，不得反向改写剧本。

用户的模糊评价或“节奏更快”等目标，不自动等于授权删台词、删事件或改结局。需要改编时单独询问。

## 建立锁定清单

读取剧本后建立：

- `EV-01...`：必须出现的剧情事件、动作结果、人物进出、道具变化、因果和结局。
- `DLG-01...`：每句台词的说话人、逐字原文和原始顺序。
- `LOCK-xx`：人物身份、关系、地点、时间、关键道具、伤势、胜负等不能改变的事实。

示例：

```markdown
| ID | 类型 | 原剧本内容 | 锁定要求 |
|---|---|---|---|
| EV-01 | 事件 | 林岚推门进入会议室 | 人物、动作、地点不可改 |
| DLG-01 | 台词 | 林岚：“你早就知道，对吗？” | 逐字保留，说话人不变 |
| LOCK-01 | 状态 | 照片始终在林岚右手 | 跨镜头和跨段保持 |
```

## 禁止的擅自修改

- 删除、缩写、改写、润色、同义替换、合并或新增台词。
- 改变说话人、对白顺序、对白与动作的先后关系，或把对白改成旁白/字幕。
- 删除、合并、替换剧情事件和关键动作。
- 改变人物动机、情绪方向、关系、胜负、伤势、因果或结局。
- 为了适配目标时长、30秒上限、最多16格的宫格容量或生成稳定性而牺牲剧本内容。
- 把“一句话概述”当作具体剧情和台词的替代品。

## 允许的导演补充

在不改变剧本含义的前提下可以补充：

- 景别、焦段、机位、运镜、剪辑和构图；
- 人物站位、朝向、距离、遮挡、视线和符合原动作的移动路径；
- 与原情绪一致的呼吸、眼神、肌肉和姿态微节拍；
- 环境活动、现场声、动作声和不新增剧情信息的声音桥；
- 灯光、色彩、材质和生成防错约束。

补充内容如果可能改变角色态度、信息量或因果，就不再属于导演补充，必须询问用户。

## 时长冲突

先用自然语速估算全部台词，再加入必要动作、停顿、表演反应和摄影机时间。

如果用户目标时长不足：

```text
忠实保留全部剧本和逐字台词，估算至少需要约X秒；你要求的是Y秒，相差约Z秒。
请选择：
1. 将总时长调整到约X秒，并按多个工作段拆分；每段故事板按剧情需要确定实际格数，最多16格；
2. 你明确指出允许删改的具体台词或剧情，我再制作改编版。
```

用户未授权时只能选择忠实版，不得自行决定删什么。

## 分段覆盖表

分段完成后输出：

```markdown
| 原剧本ID | 原文/事件 | 工作段 | 故事板面板 | 时间段 | 最终提示词 | 状态 |
|---|---|---|---|---|---|---|
| EV-01 | 推门进入 | SEG-01 | SB-01 | 0—2秒 | P-01 | 已覆盖 |
| DLG-01 | “你早就知道，对吗？” | SEG-01 | SB-08—SB-10 | 12—17秒 | P-01 | 逐字覆盖 |
```

不使用故事板时将“故事板面板”列改为“文字分镜节点”。每个 `EV/DLG` 必须恰好映射到正确位置；剧本明确重复的内容可以多次出现，但要注明。

## 用户授权记录

用户明确要求修改时，记录：原内容、用户指示、新内容、影响的 `EV/DLG/LOCK`、确认时间点。只修改被授权的范围；“其余不变”是默认规则。

## 交付前逐项核对

- `EV` 是否全部覆盖且无擅自新增？
- `DLG` 的说话人、字词和顺序是否与锁定剧本逐项一致？
- `LOCK` 是否跨镜头、跨故事板和跨生成单元保持？
- 分段是否只移动内容，没有删除或重复内容？
- 导演补充是否仍在原剧情含义范围内？
- 所有授权修改是否有记录，未授权内容是否保持原样？

任一失败都要退回修正，不能交付。
