# 动态场景规划与连续性

本文件融合动作编排核心与 15 秒战斗故事板的目标、格数、连续性思想，但不固定时长、格数或敌人数量。

## 1. 先建立动作骨架

为每个动态工作段内部填写：

```text
剧情目标：本段必须发生什么，结果是什么。
运动目标：主体要接近、脱离、穿越、压制、防守还是改变方向。
动作风格：角色或载具的重量、速度、技巧、攻击/移动偏好。
空间路线：从哪个锚点，经哪些区域，到哪个结束点。
障碍/对手：阻止目标的力量是什么。
优势或受阻变化：谁在何处取得、失去或重新获得主动。
关键接触：只列决定战术与结果的少数接触。
连续动作段：哪些普通动作合并概括。
结束状态：人物、道具、地标、伤势、破坏和摄影机侧位。
```

## 2. 回合不是“一招一停”

战术回合可以存在，但每个回合必须由动作相互驱动：

```text
行动 → 对方在同一运动中反应 → 接触/险避 → 受力或位置变化 → 余势直接触发下一行动
```

不要使用“甲出招，停；乙出招，停”的轮流展示。普通攻防应合并为一段连续动作，只在主动权变化处切镜或具体化。

## 3. 格数与镜头数

- 故事板格数用于表达重要空间或动作转折，不等于每格一个完整招式。
- 镜头数由可读性、时长和模型容量决定，不机械追求12—16镜或固定4—9格。
- 动态密度高时可增加短镜头，但一个短镜头只承担一个视觉目标，不等于只允许一个肢体动作。
- 一镜到底用路径节点组织连续路线；节点不是切镜，不得重置人物位置或动作速度。

## 4. 动作中切与空间跳位

可在加速开始、接触前后、屏障凹陷、重心改变、武器路线偏转或擦身瞬间切镜。切后继承：

- 人物位置与屏幕运动方向；
- 当前速度、重心、朝向和动作阶段；
- 武器所在手、挥动路线和接触状态；
- 伤势、雪尘、碎屑、裂纹、烟雾和VFX残留；
- 摄影机仍位于已确认轴线的同侧，除非明确设计可读的越轴过程。

贴脸、贴地、高空、远景和俯冲之间可以跳位，但每次跳位都服务接触、速度或空间升级，并保持地标作为参照。

## 5. 动态节奏

优先形成速度差：短起势 → 连续高速段 → 短暂受阻但仍在运动 → 关键爆发 → 有余势的结果。慢动作只用于极少数关键接触，随后立即恢复正常或高速运动；战后安静不等于冻结。
