# 动态空间、地标与比例锁定

动态场景比文戏更容易因雪、烟、法术、镜头跳位和大幅位移而丢失场景结构。本文件与 `SPATIAL_BLOCKING.md` 同时生效。

## 1. 持久地标

从场景图和剧本中列出必须持续存在的结构：祭坛、台阶、桥、门、塔、车辆、悬崖、雕像、阵眼平台等。每项写清：

- 形状、层级与大致尺寸；
- 相对场景中心和其他地标的位置；
- 是否可进入、可站立、可穿过、可破坏；
- 首帧是否必须可见，哪些镜头允许暂时离画；
- 天气、积雪、烟尘、火焰、水或VFX可以覆盖到什么程度。

默认规则：参考图中的关键结构持续存在；环境效果可附着表面但不得擅自删除、掩埋、替换、缩小或改成平地。

## 2. 占用与禁入区域

对容易误解的地标明确写正向路线和禁令：

```text
祭坛是直径约12米、高约1.2米的三层黑岩圆台，位于场景中央，外环与人物身高比例保持不变。
女主全程沿祭坛南侧外环地面移动，直到剧本明确登坛前都不进入台阶、不站上台面、不穿过祭坛实体。
积雪只薄覆周围地面和台阶边缘，黑岩台面与轮廓持续可辨，不得被雪填平或删除。
```

“中央”“阵心”“中间”等抽象词必须解析到具体区域：中央地面、祭坛台面、外环、台阶下或法阵投影，不能让模型自行选择。

## 3. 比例锁

- 写一个稳定尺度锚点，例如人物身高 : 祭坛高度 : 祭坛直径。
- 人物移动到远处时只能因透视变小，不能改变与同平面地标的真实比例。
- 近景切回全景时，依据台阶高度、栏杆、门框或武器长度恢复人物尺寸。
- 禁止为构图方便把人物放大到地标尺寸、把巨剑缩成人物武器或让角色站到不允许的物体上。

## 4. 动态连续性账本

每个镜头结束记录：

```text
人物所在区域 / 朝向 / 屏幕运动方向 / 速度与重心
道具所在手与运动路线
地标是否在画、相对方位与遮挡
积雪、烟尘、裂纹、破坏和VFX残留
摄影机所在轴线侧与下一镜切入尺度
```

下一镜必须从该状态继续，不能因为镜头跳位重置场景。

## 5. 动态空间自检

- 关键地标是否仍存在、形状与位置不变？
- 环境效果是否只改变被允许的表面，没有覆盖成新地形？
- 人物是否沿确认路线移动，没有误入、误站、穿模或瞬移？
- 人物与地标、兵器、载具的比例是否跨镜一致？
- 远近景切换是否仍能通过至少一个地标识别方向和尺度？
